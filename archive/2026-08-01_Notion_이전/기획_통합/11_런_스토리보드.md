# 11. 런 1회 완주 스토리보드 (10층 정식 기준 · 씬 단위)

> **문서 상태**: 기획 `초안` · 현재 범위 `참조 시나리오` · 구현 `HANDOFF에서 별도 추적` · 수치 `참조` · 미결 `[15 A]에서 통합 관리`
> **버전**: v0.1 (2026-07-27) — 기획안 발표용 척추 문서
> **작성 배경**: 00 §5 스토리보드가 3줄 요약뿐이라 "플레이어가 앉아서 일어날 때까지"를 씬 단위로 상세화. 발표 슬라이드 = 씬 1장 원칙으로 바로 전환 가능.
> **기준**: [03 §1 10층 분기 맵](03_노드_용병소_보상_메타.md) (1층 시작 / 9층 화톳불 / 10층 보스 고정) · 텍스트는 전부 [07](07_서사_텍스트_풀.md)·[06](06_이벤트_노드.md)·[04 §3](04_튜토리얼.md)의 **현재 원문을 인용**하며, 각 출처가 초안인 경우 해당 문구도 팀 확정 전으로 본다.

## 1. 대표 시연 경로 (데모 시드)

10층은 층당 3갈래 랜덤이므로, 발표·시연용으로 **모든 콘텐츠 타입이 1회 이상 노출되는 대표 경로**를 고정 시드로 정의한다 (시연 빌드는 이 배열 강제 생성 권장).

```text
1층 시작 → 2층 전투 → 3층 `?` 선택지 이벤트 → 4층 용병소 → 5층 전투(저장)
→ 6층 엘리트 → 7층 전투(동료 사망) → 8층 교회 → 9층 화톳불(고정) → 10층 보스
```

- 노출 콘텐츠: 전투 3회 + 엘리트 1 + 이벤트 노드 결과 4종 전부(`?` 선택지/용병소/교회/엘리트) + 막간 텍스트 + 화톳불 + 보스
- 감정 곡선 목표: `학습(2~4) → 안정(5) → 긴장 상승(6) → 상실(7) → 회복(8~9) → 절정(10) → 여운(에필로그)`

## 2. 씬 시트

> 표기 — **화면**: 무엇이 보이나 / **연출**: 카메라·사운드·이펙트 / **텍스트**: 실제 표시 문구(출처) / **행동**: 플레이어 입력 / **감정**: 이 씬의 목표 감정

### 막 0 — 오프닝 (최초 실행, 길이 미정 / 즉시 스킵 가능)

**S00 타이틀**
- 화면: 키 아트 배경 + 로고 + [시작하기] / [처음이신가요?]
- 연출: BGM `Title`. 정적, 커서 깜빡임만.
- 텍스트: 없음 (로고만)
- 행동: 시작 클릭 → 감정: 불길한 고요
- 비고: ✅ 키 아트는 [디자인_UI/01 §1](../디자인_UI/01_제출용_이미지_프롬프트.md)

**S01 실패 요원 보고서** (04 §3, 길이 미정)
- 화면: 검은 바탕, 타자기 폰트로 직전 임무에 실패한 요원의 보고서가 한 글자씩 작성됨
- 연출: 타자기 소리, 행정 문서의 무감정한 문체, 필요 시 붉은 [실패]·[기밀] 도장. 아무 키나 → 즉시 스킵
- 텍스트: 실패 원인·요원 신원·사망 여부를 포함한 전문은 미결
- 행동: 읽기/스킵 → 감정: 한 사람의 실패가 기록 한 장으로 축소된다

**S02 후속 투입 통보** (04 §3, 길이 미정)
- 화면: 종이가 넘어가거나 보고서 뒷면이 드러난 뒤 `후속 투입 인원` 항목에 현재 플레이어가 기재됨
- 연출: 실패 보고와 인원 배정 사이에 감정적 추모나 정지 없이 곧바로 타자 입력이 이어짐
- 텍스트: 플레이어를 이름·식별번호·직책 중 무엇으로 표기할지는 미결
- 행동: 읽기/스킵 → 감정: "나는 실패한 사람의 다음 번호다"

**S03 작전 개시 연결부 후보**
- 화면: `작전 개시. 교전을 허가한다.` 단문 → 블랙 아웃 → 노드맵 또는 튜토리얼 진입
- 상태: 문구 포함 여부와 튜토리얼·본 런 중 어디로 연결할지는 [15 A3](15_미결_안건표.md)에서 결정
- 감정: 행정 절차가 끝나는 즉시 현장 투입

### 막 1 — 진입과 학습 (1~5층)

**S04 1층 · 노드맵 첫 진입 + 마석 강화 패널**
- 화면: 10층 노드맵(3갈래), 초록 시작 노드, 계정 공용 영구 스탯 강화 패널([03 §4] — 항목·수치·UI 상세 미결)
- 연출: BGM `NodeMap`. 노드 아이콘에만 미세 발광
- 텍스트: ✅ "탐사 개시. 오늘도, 어제처럼." (07 §2-5) / 2회차+: "또 왔다. 아니, 떠난 적이 없었다."
- 행동: (보유 마석이 있다면) 영구 스탯 강화 → 2층 분기 선택
- 감정: 지도 앞의 선택 — 통제감의 환상

**S05 2층 · 첫 전투** (인카운터: 고블린 ×2 — [08 §1] 전반 풀)
- 화면: 숲은 비교적 정상이나, 우측의 채집민은 얼굴과 바구니가 왜곡된 고블린으로 보이는 전투 화면 — 좌 파티 4 / 우 적 / 하단 손패·공용 스택
- 연출: BGM `Battle`. 카드 드로우 SFX → 스킬 이펙트 → 영혼석 드롭 자동 수거([03 §3-3])
- 텍스트: ✅ "적대 개체 감지. 교전을 허가한다." (07 §2-1) / 승리: "구역 정리 완료. 회수분을 수거하라." (07 §3-4)
- 행동: 카드 플레이 → 자동 전투 관전 → 승리 후 찢어진 바구니에서 약초·열매·땔감이 쏟아짐
- 감정: "카드를 냈는데 내가 아니라 동료가 싸운다" — 장르 차별점의 첫 각인

**S06 3층 · `?` 선택지 이벤트** (✅ [06 EVT-01 식어 있는 야영지] 고정 추천)
- 화면: 이벤트 패널 — 상단 삽화([디자인_UI/01 §4]) + 본문 + 선택지 3버튼
- 연출: BGM 저음 유지. 선택 확정 시 결과 텍스트 1줄 타이핑
- 텍스트: ✅ EVT-01 전문 + 결과 텍스트
- 행동: 리스크-리턴 첫 선택 (물자/지나침/조사)
- 감정: 전투 밖에도 대가가 있다

**S07 4층 · 용병소**
- 화면: 용병소 UI — 후보 3인, 고용/리롤/파티 편집 ([03 §2])
- 연출: BGM `Mercenary`. 고용 확정 시 SFX `Recruit`
- 텍스트: ✅ 진입 "여기 모인 것들은, 한때 당신 같은 무언가였다." / 고용 확정 "형체가 모인다. 두 번 깜빡이는 눈 — …" (07 §2-3)
- 행동: 영혼석 소비 모집·편성 변경
- 감정: 동료를 "산다"는 위화감

**S08 5층 · 전투 2 + 자동 저장** (고블린 ×2 + 약탈자 — 강타 리스크 도입)
- 화면: 전투 + 우상단 저장 아이콘 점멸([03 §1] 5층 세이브)
- 텍스트: ✅ 후반 진입 풀 시작 — "개체 수가 기록과 맞지 않는다. 매번 그랬듯이." (07 §2-1)
- 감정: 관리하던 전투가 막판에 흔들릴 수 있다 (약탈자 도끼 던지기)

### 막 2 — 상실과 회복 (6~9층)

**S09 6층 · 엘리트 전투**
- 화면: 전투 화면 + 엘리트 전용 표식
- 연출: ✅ **엘리트 진입 초안 (2026-07-27 — 팀 컨펌 대기)**: ① 이벤트 노드 결과가 엘리트로 확정되는 순간, 노드맵의 해당 노드가 **붉게 1회 맥동**(state/danger `#B3263E`) + 낮은 진동음 ② 진입 시 화면 미세 흔들림 1회(0.3s) 후 진입 문구 표시 ③ 전투 화면의 적 이름표에 엘리트 표식(기존 UI 확장). 보스 컷인(3초)과 달리 **1초 미만** — 위계 차이를 연출 길이로 표현
- 텍스트: ✅ "통로 끝에 형체가 서 있다. 당신이 들어서기 전부터." (07 §2-3C)
- 행동: 고난도 전투 → 승리 시 **오브제 드롭 연출** ([09 §1] — 시연 시드는 드롭 확정)
- 감정: 위험을 골랐고, 희소한 것을 얻었다

**S10 7층 · 전투 3 — 동료 사망**
- 화면: 전투 중 동료 1인 HP 0 → 아래로 퇴장([01 §1-5]) → 남은 동료 앞당김 → 좌패널 슬롯 축소
- 연출: SFX `FellowDeath`. 전원 스트레스 +20 상승 이펙트 → 압박 진입 동료의 상태 칩
- 텍스트: ✅ "요원 소실. 기록 말소 처리." + 희귀 "…이름이 뭐였더라. 아무도 적어두지 않았다." (07 §3-1) / 압박: "[동료]가 대답을 안 했다. 못 들은 게 아니다." (07 §4-1)
- 행동: 빈 슬롯을 안은 채 전투 마무리
- 감정: **상실 — 이 게임의 스트레스는 숫자가 아니다**

**S11 8층 · 교회**
- 화면: 교회 UI — 무료 관리(🧠 −25) / 유료 부활·회복 분리([03 §1-3])
- 연출: BGM `Rest`. ✅ **부활 연출 초안 (2026-07-27 — 팀 컨펌 대기)**: ① 부활 확정 → 영혼석 소모 SFX(`CoinSpend` 변주) + 제단 위에서 영혼석이 청록빛(`#4CB3B3`)으로 부서짐 ② 빛 파편이 모여 실루엣 재조립(용병소 고용 이펙트 재사용·색만 통일) ③ 완성 순간 0.5s 정지 후 부활 문구 표시 → 파티 슬롯 복귀. 총 2~3초, 신규 에셋 최소(기존 고용 연출 변주)
- 텍스트: ✅ 진입 "촛불이 켜져 있다. 심지의 길이가 전부 같다." / 부활 "형체가 완성되고 구현체가 눈을 뜬다. 미소 짓는 입매가 조금 다르다." (07 §2-3B)
- 행동: 죽은 동료 부활 or 새 모집과 저울질
- 감정: 되돌릴 수 있다 — 하지만 "돌아온 것"이 같은 존재인가

**S12 9층 · 화톳불 (고정) + 기시감 사건**
- 화면: 낡고 방치된 것처럼 보이는 큰 나무 아래 돌 쉼터. 장작이 줄지 않는 불은 권속의 모습을 드러내지 않음
- 연출: 진입 시 기본 회복 적용 + BGM `Rest`. ✅ "불길에 손을 뻗는다. 상처는 아문다 — 아문 자리에, 처음 보는 흉터가 남는다." (07 §2-2) / 노드를 떠날 때 불이 조용히 꺼짐
- **1회성 삽입**: ✅ 00 §8-3 기시감 사건 — "처음 온 장소인데, 돌바닥에 네가 아직 흘리지 않은 피가 말라 있다."
- **무작위 이벤트**: ‘잘못된 그림자’가 선택되었을 때만 파티원보다 하나 더 많은 그림자를 표시. 일반 방문에서는 추가 그림자 없음
- 행동: 자동 회복 → 보스 앞 마지막 정비(파티 편집) → 퇴장과 함께 보호의 불 소멸
- 감정: 안전한 곳에서 가장 불길한 암시 — 보스 직전 정적

### 막 3 — 절정과 여운 (10층~에필로그)

**S13 10층 · 보스 조우**
- 화면: ✅ **보스 등장 컷인 초안 (2026-07-27, 총 3초 — 팀 컨펌 대기)**
  1. (0.0~0.8s) 노드 진입 즉시 **완전 암전** — BGM 무음, 발소리 여운만
  2. (0.8~2.0s) 암흑 속 **보스 실루엣 1컷** (수확자: 낫의 윤곽만, 화면 대각선) + 고유 SFX 1회 (수확자: 낫질 소리) — 텍스트·UI 없음
  3. (2.0~3.0s) 실루엣이 어둠에 녹아 사라지며 전투 화면 페이드 인, BGM `Boss` 시작 → 조우 텍스트 표시
  - 구현: 전용 풀스크린 오버레이(BattleResultScreen 스타일 재사용) + 데이터화 — **보스당 {실루엣 스프라이트 1장 + SFX 1개}만 추가하면 신규 보스도 동일 컷인** (차원 테마 확장 대비, 13 §3B)
  - 스킵: 클릭 시 즉시 3단계로. 엔딩 게이트 진입([13 §3C]) 시엔 이 컷인을 **생략** — 재인식이 꺼진 시야엔 "등장 연출"이 없다 (그냥 거기 있었던 존재)
- 연출: BGM `Boss`. 조우 텍스트 정지 연출
- 텍스트: ✅ "그것은 서두르지 않는다. 이미 결과를 알고 있으니까." (07 §5)
- 감정: 벽을 만났다

**S14 보스전 중반 — 까마귀 / 순간이동**
- 화면: 까마귀 2마리 소환 → (미처치 시) 폭발 / 파티 배치 역전 연출([02 §7-3])
- 텍스트: ✅ 까마귀 부름·순간이동·처치·폭발 — 07 §5 트리거 표 (기본/변형 랜덤)
- 행동: 까마귀 우선 처치 vs 보스 집중의 자원 배분
- 감정: 지금까지의 운영이 뒤집힌다

**S15 보스전 후반 — 수확 → 처치**
- 화면: HP 50% 수확(전체 50 + 흡수) 순간 거대한 외형 안에 작은 낫을 든 어린 신이 한 프레임 겹침 → 마지막 페이즈 → 영혼 전체 추출
- 텍스트: ✅ "거두는 자가 낫을 들었다. …" → 처치: "그것이 쓰러졌다. 그런데 낫질 소리는, 아직 멈추지 않았다." (07 §5)
- 연출: 유혈 없이 마른 곡식과 빛의 입자로 무너진 뒤 영혼석만 남음. `FILTERED` 화면에는 주민 없이 비어 있는 둥지만 표시
- 감정: 승리 — 그러나 방금 본 작은 형상이 무엇이었는지 설명되지 않는다

**S16 에필로그 · 임무 완료**
- 화면: 검은 화면에 타자기 출력 (S01과 동일 양식 — **수미상관**)
- 텍스트: ✅ 00 §6-5 엔딩 초안 — "임무 완료. 영혼석 회수량: 정상. 다음 탐사 브리핑이 발송되었습니다. 출발 기한: **즉시**" + ✅ "— 그런데 '완료'는, 몇 번째인가." (07 §6-2)
- 감정: 클리어했는데 해방이 아니다 — 루프의 자각 씨앗

**S17 런 종료 리포트 → 새 런**
- 화면: ✅ **탐사 보고서 화면 — [12_런_종료_리포트](12_런_종료_리포트.md)** (샘플 전문 §3 — 발표 목업 그대로 사용 가능). 이후 마석 영구 스탯 강화 패널 → 노드맵 재생성([03 §4-1])
- 행동: 마석 소비 → [다음 탐사] 클릭
- 감정: "한 번 더"의 이유 — 메타 성장 + 서사 의문

**S-ALT 전멸 분기** (어느 전투에서든)
- 화면: 패배 연출 → **런 종료 리포트** → 런 상태 리셋 → 마석 영구 스탯 강화 선택 → 새 런([03 §4-1], [12](12_런_종료_리포트.md))
- 텍스트: "탐사대 전멸. 다음 탐사대가 이미 편성되었다." (07 §3-4) → 리포트 전환 시 "기록 말소 완료. 같은 얼굴의 대체 인원이, 이미 배정되었다." (07 §6-3)
- 감정: 죽음조차 시스템의 한 절차

## 3. 확정·미결 관리

오프닝의 실패 요원 보고서 → 현 플레이어 후속 투입 통보는 핵심 방향으로 유지한다. 동료 배치 보고서를 다시 포함할 경우 사진란은 공란 + `사진 생략` 도장을 사용한다. 엘리트 진입, 교회 부활, 보스 컷인과 런 종료 리포트의 제안 내용은 각 씬 본문에서 관리한다. 시연 시드, 시연용 오브제 드롭, 튜토리얼·오프닝 순서와 감정 곡선 검증은 [15 A](15_미결_안건표.md)에서 결정한다.
