## 1. 전투 시스템 명세 (2026-03-15 확정)

### 1-1. 턴 구조

1. **드로우 페이즈**: 사용한 손패만큼 재드로우 (탈진 체크 여기서 진행)
2. **플레이어 카드 플레이**: 공용 스택 생성
3. **선공 판정**: 카드 플레이 후 전투당 1회 실행. 아군 스택 합계와 적 QuickStackCost 합계를 비교
4. **선공 측 행동**: 동료 또는 적 순차 행동
5. **후공 측 행동**
6. **결과 처리**: 스트레스 / 사망 판정 / 전투 종료 확인

> 동료/적 모두 **턴당 1회 행동** (적 3명이면 적이 순차로 3회 행동).

### 1-1-1. 선공 판정 복원 기준 (2026-07-24)

- `InitiativeCheck` 페이즈는 카드 플레이가 끝난 시점에 진입한다.
- 선공 결과는 **전투당 1회** 결정하고, 이후 턴에는 같은 순서를 유지한다.
- 아군 점수 = 현재 딜러·탱커·서포터 스택의 합.
- 적 점수 = 살아있는 적의 `attackCost(=QuickStackCost)` 합. `isPassive` 소환체는 제외한다.
- 아군 점수가 높으면 아군 선공, 적 점수가 높으면 적 선공으로 결정한다.
- 동점이면 50:50 코인 토스로 선공 진영을 결정한다.
- 이 결과는 해당 전투의 모든 후속 턴에 유지한다.

### 1-2. 스킬 규칙

- 동료의 스킬은 **모집 시 랜덤으로 결정**되며, 진행중에는 변경되지 않는다.
- 동료는 스킬을 **2개를 고정으로** 가지며, 스킬마다 코스트가 다를 수 있다.
- 체력이 50% 이하일 때 실드/힐 스킬을 보유했다면 그 스킬을 먼저 사용한다.

### 1-3. 스택 소비 & 스킬 발동 규칙

- 동료는 배치 순서대로 자신의 역할 스택을 소비하여 스킬을 발동한다.
- **스킬 선택 기준**:
  1. 체력 50% 이하면 힐/실드 스킬 최우선 사용
  2. 본인 직업 타입에 맞는 스킬 판정 후 사용
	  1. 직업 타입에 따라 선 판정 (딜러=데미지, 탱커=실드, 서포터=힐).
  3. 가장 높은 스킬 코스트 우선
- 발동 시 공용 스택에서 해당 값을 차감, 잔여 스택은 다음 동료에게 이어진다.
- 어떤 스킬도 발동 불가하면 → **미행동 보상** 적용.

### 1-4. 전투 종료 조건

| 조건    | 결과  |
| ----- | --- |
| 적 전멸  | 승리  |
| 아군 전멸 | 패배  |

### 1-5. 동료 사망 처리

- HP 0 이하 → **즉시 전투에서 이탈**.
- 사망 시 덱과 손패에서 해당 동료로 생성된 카드를 제거한다.
  - **예외**: 손패가 사망 동료가 아닌 다른 동료 카드로만 구성된 경우, 즉시 파괴하지 않는다.
    - *"턴 종료 시 랜덤으로 (사망 동료 수)개의 카드가 파괴됩니다."* 팝업/툴팁 표시.
    - 손패 상한은 현재 배치된 동료 수와 같으므로, 사망 후 다음 드로우부터 자동으로 줄어든다.
    - 해당 손패 카드에 별도 시각 표시 (레퍼런스: **하스스톤 주문제작카드**).
    - 그 턴에 사용하지 않으면 결과 처리 단계에서 (사망 동료 수)개를 랜덤 파괴.
- 사망 시 별도 스프라이트 없이 **아래로 퇴장**하는 느낌 (레퍼런스: 포켓몬스터).
- 사망 후 남은 동료들이 **앞으로 당겨서 정렬**.
- 사망으로 생긴 빈 슬롯은 전투 종료 후 파티 편집에서 관리하고, 새 동료 충원은 용병소·교회·이벤트 등 허용된 획득 경로에서 처리한다.
- 사망 시 **나머지 동료 전원 스트레스 +20**.

### 1-6. 동료 역할

- 기본: 딜러 / 탱커 / 서포터, **중복 허용** (예: 딜러 3 + 서포터 1).
- 파티: 최소 1명~최대 4명 배치 가능.
- 모집으로 교체. 자동행동 우선순위는 [00 코어루프](00_게임_개요_정식_서사.md) 참조.

### 1-7. 예외 처리 규칙

**① 덱 고갈 (Burn & Survival)**
- 덱 카드가 모두 소진되면 더 이상 드로우하지 않는다 (턴 종료 시 리셔플/재사용 없음).
- 드로우할 카드가 없으면 모든 동료가 **탈진 디버프**를 받아 각 각 데미지 5 받음 (현재 테스트값).
- 핵심: 카드를 못 써도 이전에 쌓아둔 **[미행동 보너스 스택]** 으로 스킬을 발동해 턴을 넘긴다.

**② 처리 및 사후 처리 (Death & DoT)**
- 체력 0이 되는 순간 즉시 제거 (동시 사망 판정 없음).
- 아군 사망해도 전투는 중단되지 않고 빈칸으로 진행.
- 도트 데미지 처리 기준은 각 턴 시작 시 적용
	- 1턴에 중독 디버프 걸릴 경우 2턴 시작할때 중독 데미지가 들어갑니다.
	- 시전자가 사망하더라도 디버프가 적용되어 있는 경우 해당 턴 동안 데미지가 들어갑니다. 
	- 3턴 진행되는 디버프의 경우 디버프 적용 후 잔여 턴이 1턴씩 감소합니다.
		- 예시) 3턴 진행 중독 디버프를 2턴에 걸린 경우 3턴, 4턴, 5턴에 중독 데미지를 받은 후 디버프가 제거 됩니다.

**③ 자동 타겟팅 (아군)**
- 아군 지원: 기본 `현재 체력이 가장 낮은 아군` 우선.
- 아군 공격: 기본 `전열(앞)에 배치된 적` 우선. (일부 스킬은 `최저 HP 적` 등 고유 로직)
- 자신 우선(Self-Target): 유효 대상이 자신뿐이면 자동으로 `자신`으로 전환 (예: 힐러 혼자 생존).

**④ 적 타겟팅 (아군 피격 순서)**
- **피격 순서 = 배치 순서** (빠른 유닛부터 피격). 예: `1→2→3→4`.
  - 의도: 앞자리 유닛은 먼저 행동하지만 먼저 맞는다 (리스크-리턴 구조).
- **빈칸 건너뜀**: 사망 자리는 타겟에서 제외, 다음 배치 순서 유닛이 피격.
- **미행동 보상 연계**: 미행동 동료는 다음 턴 스택 +1 + 배치 순서를 앞으로 당김 → 먼저 행동하는 메리트와 먼저 피격되는 디메리트를 동시에 감수. HP 낮은 딜러/서포터의 미행동은 치명적일 수 있음.
- *예외*: 일부 적 스킬은 `최저 HP 아군 우선` 등 고유 타겟팅.

> 스트레스는 반드시 **데미지 계산이 끝난 후** 적용된다.

## 2. 카드 설계 프레임

> 확정 원칙 (2026-03-09 / 2026-04-07 갱신)

- 카드 표현은 **할리갈리식의 직관적 속성/수치 읽기** 방식을 우선 채택.
- 카드 템플릿 풀은 역할 3종 × 10장씩 = **30종**이다. 실제 시작 덱은 배치된 각 동료가 자기 역할 템플릿에서 10장씩 생성해 구성한다.
- **카드는 스택 생성 전용. 카드 사용으로 스킬은 발생하지 않는다.**
- 스택 수치는 카드가 아닌 **동료의 성향**이 결정한다.

### 2-1. 카드 구조

- **역할(CardType)**: Dealer / Tank / Support 3종
- **카드 이미지(cardArt)**: 역할별 3종 (역할당 1종 유력)
- `cardPower`는 **현재 범위 제외**다. 스택 가중치 카드·시너지 확장 시 백로그에서 재검토한다.

```
카드 사용 → 동료 성향 범위 내에서 스택 수치 랜덤 확정(사용 순간) → 공용 스택에 반영
```

> 손패에 든 시점에는 수치가 숨겨져 있고, 사용 순간 동료 성향 규칙으로 즉시 확정 → 매 전투마다 다른 스택 결과를 만드는 핵심 변수.

### 2-2. 덱 구성 규칙

- 덱은 **배치된 동료의 역할과 성향**을 바탕으로 자동 등록.
- **1단계 (역할 필터)**: 동료 역할에 맞는 카드만 후보군. (예: 탱커 동료 → 탱커 카드 10장)
- **2단계 (성향 적용)**: 후보군 카드에 동료 성향 스택 범위 적용. (예: 탱커+도박사 → 탱커 카드 10장, 사용 시 −5 또는 +5)
- 동료 1명당 **10장**을 등록한다. 시작 덱 크기는 `배치 동료 수 × 10장`이므로 1~4인 파티에서 **10~40장**이다.

### 2-3. 손패 / 드로우 규칙

- **손패 유지량**: 배치된 동료 수와 동일 (4인 → 4장).
- **드로우 시점**: 턴 시작 시 사용한 수만큼 재드로우. (4장에서 3장 사용 → 다음 턴 3장 재드로우, 1장 유지)
- **턴당 사용 제한**: 없음.
- **시작 손패 = 배치 동료 수**, **시작 덱 = 배치 동료 수 × 10장**. 최대 4인일 때 손패 4장·덱 40장이다.

### 2-4. 탈진

- **조건**: 드로우 단계에서 덱에 드로우할 카드가 없는 상태.
- **번 데미지**: 전체 동료 대상 5 데미지.
- **위치**: 드로우 페이즈 (턴 구조 1단계).

## 3. 동료 성향 (Affinity) 4종

> 구현 파일: `Assets/Scripts/Card/CardAffinity.cs`

성향은 해당 동료 카드의 **스택 기여량 생성 범위**를 결정한다. 카드 사용 전까지 수치는 숨겨져 있으며, 사용 시 성향 규칙에 따라 즉시 확정된다.

> **핵심 원칙**: 모든 성향의 기대값은 **≈+0.6**으로 수렴 (도박사만 0). 차별점은 **기대값이 아니라 분산(리스크)**. **모든 범위는 0을 제외**한다.

| 성향 | enum | 범위 (0제외) | 생성 방식 | 기대값 | 분산 | 특징 |
| ----- | ------------- | ---------------------- | --------- | ------ | --- | ---------------- |
| 도박사 | `Gambler` | −5 또는 +5 | 극단값 50:50 | 0.0 | 극대 | 큰 위험·큰 보상 |
| 안전주의자 | `Safety` | −1, 1, 2 | 균등 확률(3개) | ≈+0.67 | 작음 | 가장 안정적 |
| 기회주의자 | `Opportunist` | −2, −1, 1, 2, 3 | 균등 확률(5개) | +0.60 | 중간 | 균형 |
| 낙천가 | `Optimist` | −3, −2, −1, 1, 2, 3, 4 | 균등 확률(7개) | ≈+0.57 | 큼 | 완전 랜덤 |

### 생성 규칙
- **독립시행 균등확률** 원칙 (2026-03-09 확정).
- 카드를 들고 있는 시점에는 값이 숨겨져 있다.
- 사용 시 `AffinityHelper.GenerateStack(affinity)` 호출로 즉시 확정.
- 도박사만 예외: 균등 범위가 아닌 극단값 2개 중 하나 선택.

```csharp
int stack = AffinityHelper.GenerateStack(companion.affinity);
// Gambler     → -5 또는 +5
// Safety      → -1, 1, 2 중 하나
// Opportunist → -2, -1, 1, 2, 3 중 하나
// Optimist    → -3, -2, -1, 1, 2, 3, 4 중 하나
```

> 안전주의자는 작고 확실한 변화, 낙천가는 크고 예측 불가능한 변화. 도박사만 기대값 0의 고위험·고수익 포지션.

## 4. 스트레스 디버프 표

> 현재 기획 원칙: 구간 효과를 단순화하고, 패닉 분기는 공포 경직·과호흡을 기본으로 사용한다. 오발·폭주 확장은 [08 §4](08_밸런스_난이도_아키타입.md) 기준으로 검토한다.

### 4-1. 기본 범위: `0 ~ 100`

**상승 조건**

| 원인 | 증가량 |
|---|---|
| 피격 시 | `(데미지 × 0.25) − stressResist` (최소 0) |
| 치명타 피격 시 | `(데미지 × 0.40) − stressResist` (최소 0) |
| 동료 사망 시 | 전원 +20 |

> `stressResist`는 동료별 스트레스 저항력.
> 예: 데미지 50 피격, stressResist 10 → `(50×0.25)−10 = +2.5`
> 예: 데미지 20 피격, stressResist 5 → `(20×0.25)−5 = 0` (최소 0)

**기본 회복**

| 방법 | 회복량 |
|---|---|
| 교회 노드 무료 관리 | −25 |
| 화톳불/휴식 노드 | −15 |
| 전투 승리 | −10 |

### 4-2. 구간별 상태

| 구간 | 상태 | 효과 | 현행 |
| ---------- | ---- | ---- | --- |
| 0 ~ 50 | 안정 | 효과 없음, UI 정상 표기 | ✅ |
| 51 ~ 99 | 압박 | 피격 시 추가 스트레스 **+10%** (×1.10) · 스킬 퍼포먼스 **−10%** (power ×0.90) | ✅ |
| 100 | 패닉 | 즉시 1회 패닉 판정 → 이후 스트레스 50으로 감소. **100 도달마다 매번 재발동** | ✅ |
| 역할별 중증 디버프 | 패닉 이후 전투 종료까지 유지 | ❌ 백로그 |

> ✅ **압박 수치 확정 (2026-06-02)**: 권장범위 −5%~−15%의 중앙값 −10%. 인스펙터 조정: `BattleManager.pressureSkillPenaltyPercent`(스킬 −%), `BattleManager.pressureStressGainPercent`(피격 스트레스 +%). 기본 10.

**패닉 결과 (2종)**
- **공포 경직**: 해당 턴 행동 불가
- **과호흡**: 스택 요구량 +1

> 🟡 패닉 결과 4종 확장(오발·폭주 추가) 제안은 [08 §4 스트레스/패닉 확장](08_밸런스_난이도_아키타입.md). 스트레스는 게임 핵심 차별점(00 §2)이나 현재 콘텐츠 부피가 얇아 보강 대상.

### 4-3. 역할별 중증 디버프 ⚠️ 후속 확장
- **딜러**: 화력 유지하되 불안정성 증가 → 받는 피해량 증가
- **탱커**: 버티는 역할 유지하되 방어 신뢰도 하락 → 보호 효과 수치 하락
- **서포터**: 지원 기능 남기되 안정성 감소 → 광역 회복보다 단일 회복 우선

### 4-4. 밸런싱 메모
- 스트레스는 체력보다 늦게 터지되, 무시하면 전투 계획이 흔들리는 수준이 적당.
- 역할별 패닉 디버프는 숫자보다 행동 우선순위 변화가 더 잘 보이게 설계.
