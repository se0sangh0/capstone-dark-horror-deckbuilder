# 제출용 이미지 생성 프롬프트 (메인화면 · 인게임 예시)

> **2026-07-28 안내**: 이 문서는 제출 화면 구성과 개별 이미지 사용처를 관리한다. GPT 이미지 생성의 공통 그래픽 풍, 스타일 잠금, 장면별 최신 프롬프트는 [00_컨셉_아트_GPT_프롬프트_가이드](00_컨셉_아트_GPT_프롬프트_가이드.md)를 우선한다.
> 작성 2026-07-21 / **v0.2 같은 날 개정** — 1차 생성 결과가 스팀펑크·사이버펑크로 치우쳐 기계 요소 축소. 공간은 "뒤틀린 일상 + 다세계 봉합"으로 전환(§0-5).
> 기준: [00_피그마_디자인_톤앤매너_가이드](00_피그마_디자인_톤앤매너_가이드.md) · [00_컬러_스타일_토큰_가이드](00_컬러_스타일_토큰_가이드.md) · 캐릭터는 16비트 픽셀아트([00_캐릭터_디자인_프롬프트](00_캐릭터_디자인_프롬프트.md)와 동일 스타일 어휘).

## 0. 제출 이미지 전략 (프롬프트보다 먼저)

> ✅ **제출 구성 확정 (2026-07-27, 7장)**: 시작 화면 / 노드 화면 / 보스 전투 / 용병소 / 화톳불 — 5종은 **인게임 구현 완료 → 실스크린샷 리터치**로 제출. AI 생성은 **`?` 선택지 이벤트 2종(EVT-18/19, §4-3·4-4)만** 사용. 아래 §1~3, §5~6의 AI 컨셉 프롬프트는 리터치 참고/예비용으로 보존.

| 이미지 | 방식 | 이유 |
|---|---|---|
| 시작/노드/보스 전투/용병소/화톳불 (5종) | **실제 스크린샷 + 리터치** (색보정·음영, 필요 시 AI 컨셉을 배경 보강 소재로) | 구현 완료 — 실물이 컨셉 아트보다 심사 신뢰도 높음 |
| `?` 선택지 이벤트 화면 2종 (EVT-18/19) | AI 삽화 + **실제 이벤트 텍스트**([06](../기획_통합/06_이벤트_노드.md)) + 피그마 UI 프레임 | 미구현 기능을 "설계된 목업"으로 제시. 기존 톤 유지하되 **야외 배경**으로 차별화 |

**공통 원칙**
1. AI에 **한글 텍스트/정확한 HUD를 그리게 하지 않는다** (글자 깨짐). 배경·일러스트만 뽑고 텍스트/UI는 피그마 오버레이.
2. 컨셉 아트는 제출물에 **"컨셉 이미지"** 라벨 표기 (실플레이 오인 방지).
3. 한 번에 4장 이상 뽑아 최고 1장 선별. 팔레트 HEX를 프롬프트에 그대로 유지해 이미지 간 통일감 확보.
4. 비율: 16:9 (1920×1080). 이벤트 삽화만 후보정 크롭 여지 두고 넉넉히.
5. **공간 연출 원칙 (v0.2)**: 금속·기계(철판/황동 리벳/톱니/배선/스캔라인)는 **UI 프레임의 언어**다([톤앤매너 §2](00_피그마_디자인_톤앤매너_가이드.md) "구조는 스팀펑크"는 UI 얘기). 인게임 **공간 자체**는 [00 §6-1](../기획_통합/00_게임_개요_정식_서사.md) "비현실이 침범한 지구 2.0" — **뒤틀린 일상 공간**(교실·예배당·사당·도로표지판·휴게실)이 여러 세계관 파편으로 어긋나게 봉합된 모습. 기계 요소는 '현대' 양념 수준(케이블 한 가닥, 부서진 표지판)으로만. 황동색(#C39A52)은 기계가 아니라 낡은 돌·나무·마른 짚에 얹는다.

**공통 팔레트 (모든 프롬프트에 삽입됨)**
charcoal black `#0F1115` / brass `#C39A52` / relic teal `#4CB3B3` / warning red `#B3263E` / rune purple `#7B5EA7`(비술 장면만)

## 8. 재생성 팁

- 결과가 팔레트를 무시하면: 프롬프트 맨 앞에 "strictly limited dark palette:" 를 붙이고 HEX를 반복.
- 픽셀이 뭉개지면: "no pixel filter look, real pixel art resolution, chunky pixels" 추가.
- 화면이 밝게 나오면: "70% of the frame is near-black darkness" 추가 (톤앤매너 §4 "화면의 70% 어두운 중성색" 규칙).
- 캐릭터 얼굴이 자세히 나오면: 이 게임 캐릭터는 별도 초상 프롬프트가 있으므로 씬에서는 "small sprites, faces not detailed" 유지.
- **기계/SF 느낌이 여전히 강하면 (v0.2)**: 말미의 "no machinery, no gears, no pipes, no sci-fi elements"를 프롬프트 **맨 앞에도** 반복하고, "ordinary places twisted wrong (school corridor, early harvest sanctuary, shrine, road sign)" 같은 일상 공간 명사를 추가. 반대로 판타지가 과해지면 "no castles, no ornate fantasy decoration"으로 눌러준다.
