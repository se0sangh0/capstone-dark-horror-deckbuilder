# 30초 시연 영상 제작 기준

> 최신 기획 원문:
> [16-F. 30초 시연 영상 제작 명세](https://app.notion.com/p/3c86aef5baac81109a6aceee14273f4e)
>
> 작성일: 2026-08-30 · 상태: 보스 마감 방식·EVT-01 선택 확정, 연결 자막 승인 후보 추가

## 1. 확정한 영상 범위

- 영상은 약 30초로 제작한다.
- 한 런을 처음부터 끝까지 보여 주지 않는다.
- 전투 일부, 선택지 일부, 보스 콘셉트 순서로 구성한다.
- 선택지 장면에서는 `흩어져서 살펴보기`를 누른다.
- 마지막은 실제 보스전이 아니라 `거두는 자` 키아트로 마감한다.
- 마지막 장면은 키아트를 유지하지만, 프로토타입 그래픽 전면 재제작 범위에는 인게임 보스 스프라이트와 보스 배경도 포함한다.
- 게임 이름은 첫 장면 또는 마지막 장면에 짧게 표시한다.

마지막 장면에는 아래 선정 자산을 사용한다.

`art/exhibition/2026-08-12/source/03_거두는자_대치_키아트.png`

Notion 16-F에는 거두는 자 키아트와 전투 비주얼 참고 이미지 2장의 원본 PNG를
멘토 공유용으로 직접 삽입했다. 같은 원본과 생성 기록은 저장소에도 보존한다.

## 2. 편집 구성 초안

| 구간 | 장면 | 전달할 내용 |
|---|---|---|
| 0~11초 | 카드 입력과 자동 전투 | 카드가 공용 스택을 만들고 동료가 자동 행동한다. |
| 11~20초 | `EVT-01 · 흩어져서 살펴보기` | HP 20 감소 → 스트레스 15 증가 → 영혼석 15 획득 |
| 20~30초 | 거두는 자 키아트 | 첫 테마의 보스와 성소 콘셉트로 마감한다. |

각 구간은 촬영 결과에 따라 2초 안에서 조정할 수 있다.
음향, 해상도와 자막은 아직 확정하지 않았다.

### 2-1. 연결 자막 승인 후보

아래 문구는 Claude Sonnet 5 최대 추론 초안을 Codex가 T0 공개 경계에 맞춰 선별한
후보다. 영상 전체에 여섯 줄을 모두 넣지 않고, 실제 편집에서는 3~4줄만 골라
장면 사이에 짧게 사용한다.

| 구간 | 자막 후보 |
|---|---|
| 오프닝 | `명령은 오늘도, 어제와 같다.` |
| 2층 전투 | `패를 내면, 대열이 움직인다.` |
| 3층 선택 | `이 길의 끝엔, 무엇이 있을까.` |
| EVT-01 | `식은 자리에도, 온기는 남아 있었다.` |
| 5층 회고 | `세 장의 기록이, 하나의 질문으로 모인다.` |
| 키아트 직전 | `서두르지 않는 무언가가, 기다리고 있다.` |

현재 30초 구성에는 `2층 전투 → EVT-01 → 키아트 직전` 세 줄을 우선 권고한다.
오프닝·3층·5층 문구는 해당 장면을 실제 영상에 넣을 때만 사용한다.

## 3. 영상 전에 만들 그래픽

### 필수

1. 일반 전투용 빈 사이드뷰 배경 1장
   - 캐릭터와 UI가 없는 16:9 이미지
   - 초기 농경 신앙의 목석 구조와 `FILTERED` 인식 사용
   - 현재 `Assets/Resources/BackGround/Battle_Normal.png`는 최종 영상에서 제외
2. EVT-01 상단 삽화 1장
   - 선택지별 썸네일 3장이 아니라 사건을 보여 주는 공용 삽화 1장
   - 화면 순서는 `삽화 → 본문 → 선택지 3개 → 결과 1줄`

### 현재 자산을 임시 사용

- `Assets/Resources/Animators/Fellows/`의 아군 애니메이션
- `Assets/Resources/Animators/Enemies/`의 일반 적 애니메이션
- 현재 카드·스킬·상태 아이콘과 읽기 쉬운 이펙트 1종
- 마지막 장면의 거두는 자 키아트

위 아군·적·카드·스킬·상태는 새 그래픽이 연결되기 전 촬영 리허설에만 사용한다. 최종 영상의 게임 플레이 구간에는 승인된 전면 재제작 세트를 사용한다. VFX는 별도 작업이 끝나기 전까지 기존 효과 1종을 임시 사용한다.

### 영상만을 위해 별도로 만들지 않음

- 정식 21개 경로별 전용 일러스트

핵심 단서 9종과 나머지 프로토타입 노출 그래픽은 영상의 특정 한 장면만을 위한 자산이 아니지만, CH1-U08에 따라 모두 전면 재제작한다. 수량·규격·제작 순서는 [08 그래픽 전면 재제작 마스터](08_프로토타입_그래픽_전면_재제작_마스터.md)를 따른다.

`Assets/Resources/ResultImage/Forest_Barricade.png`에는 현재 제외한 수레
소재와 큰 조사관 구도가 남아 있고 최신 문안의 흰 천 표식도 맞지 않는다.
영상에는 사용하지 않으며, 크롭보다 재제작을 권고한다. 최종 재제작 여부는
사용자 결정으로 남긴다.

## 4. 촬영 전 구현 체크리스트

- [ ] Unity 6000.3.9f1에서 현재 `main`을 컴파일한다.
- [ ] 시작부터 탐사 보고서까지 6층 런을 한 번 완주한다.
- [ ] 개발 빌드 전용 `EVT-01 바로 열기`를 추가한다.
- [ ] EVT-01에서 `흩어져서 살펴보기`를 바로 선택할 수 있게 한다.
- [ ] 일반 전투와 보스 구간 직접 진입 기능을 확인한다.
- [ ] 새 런에서 `EventCatalog.ResetRun()`을 호출한다.
- [ ] 이벤트 화면의 회색 더미를 상단 삽화 1장 구조로 바꾼다.
- [ ] EVT-01 결과와 `ChoiceResolved`가 한 번만 생기는지 확인한다.
- [ ] 2·3·4층 경로 카드 3택과 경로 기록을 확인한다.
- [ ] 클리어와 전멸이 모두 탐사 보고서로 이어지는지 확인한다.

현재 저장소에는 자동 테스트와 검증 빌드가 없다. 정적 코드 연결만으로
플레이 가능 상태를 확정하지 않는다.

## 5. 프로토타입과 정식 범위 구분

- `prototype_demo_v1`: 2·3·4층 경로 선택, 5층 화톳불, 6층 보스
- 정식 10층·탐사 도감: 2·5·8층 단서, 9층 화톳불, 10층 보스

프로토타입의 층 번호와 정식 도감의 9종 목표를 같은 에셋 목록으로 섞지 않는다.

## 6. 영문 지원 순서

영문판은 영상과 테스트 가능한 프로토타입 뒤에 진행한다. 실제 번역 전에 다음
기반부터 만든다.

1. 한국어 표시 문자열을 게임 로직의 ID와 분리한다.
2. 한국어·영어 Locale과 문자열 테이블을 만든다.
3. 언어 선택 위치, 적용 시점과 저장 키를 정한다.
4. 전투·EVT-01·보스 화면에 긴 시험 문장을 넣어 잘림을 확인한다.
5. 한국어 원문 확정 뒤 전체 영어 번역과 톤 검수를 진행한다.

영어 Locale, 기본 언어, 미지원 언어의 대체 규칙과 런 도중 전환은 아직
결정하지 않았다. 영문 용어, 서체와 최소 글자 크기도 결정하지 않았다.

## 7. 영상 완료 조건

- [ ] 최종 영상은 28~32초다.
- [ ] 전투, 선택지, 보스 콘셉트가 순서대로 보인다.
- [ ] 마지막 장면은 선정한 거두는 자 키아트다.
- [ ] 선택지 장면에 회색 더미 이미지가 보이지 않는다.
- [ ] `흩어져서 살펴보기` 뒤 HP 20 감소, 스트레스 15 증가와 영혼석 15
  획득이 순서대로 보인다.
- [ ] 모든 공개 화면은 `FILTERED`를 유지한다.
- [ ] 보류한 수레 이미지와 숨겨진 진실을 노출하지 않는다.
- [ ] 사용한 기존 캐릭터·배경·효과음의 라이선스 근거를 확인한다.
- [ ] 최종 게임 플레이 구간에 기존 밝은 산길·범용 1비트 아이콘·레거시 캐릭터가 남지 않는다.
