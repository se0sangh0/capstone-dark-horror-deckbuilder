## 0. 결정

기존 `Forest_Barricade.png` 한 장만 고치는 것이 아니라 전투 맵·배경·경로·단서·사건·아이콘·카드·상태·캐릭터·적·보스와 UI 표면을 **새 통합 스타일로 전면 재제작**한다. 전투 VFX는 CH1-U10에 따라 별도 작업으로 분리한다.

- 기존 파일을 바로 덮어쓰지 않는다.
- 생성 원본·검토본·생성 기록은 `art/production/graphics-remake/`에 저장해 Git으로 추적한다.
- 반려한 중간 결과만 `_workspace/graphics-remake/rejected/`에 분리하며 Git에 올리지 않는다.
- 승인된 최종본만 `Assets/Resources/RemakeV1/`로 복사하고 소비 경로를 바꾼다.
- 구 자산은 교체·플레이 검증이 끝날 때까지 복구용으로 보존한다.
- 범용 `1-bit_Pixel_Icons` 원본 1,476개는 직접 노출 자산이 아니므로 다시 만들지 않는다. 실제 런타임에서 읽는 복사본만 교체한다.

## 1. 통합 시각 문법

### 1-1. 환경·단서·사건 삽화

- 고밀도 시네마틱 픽셀 호러를 사용한다.
- 차콜·젖은 회색 돌·죽은 갈색 식생·무광 청동을 중심으로 하고, 청록은 탐사국의 제한적인 보조광으로만 쓴다.
- 최초 테마의 고대 말기~중세 초기 목석·가죽·사슬·비늘 재질을 사용한다.
- 고딕 성당, 스테인드글라스, 후기 판금 갑옷, 기계·톱니·파이프·네온은 사용하지 않는다.
- 인물보다 물건·배치·방향·소모 상태를 먼저 보여 준다.
- T0/FILTERED 화면에서 숨겨진 주민·침략·수탈·어린 토착신의 진실을 직접 노출하지 않는다.

### 1-2. 전투 캐릭터·아이콘·VFX

- 엄격한 16비트 픽셀 스프라이트와 제한 팔레트를 사용한다.
- 작은 크기에서도 역할·무기·상태가 실루엣만으로 구분돼야 한다.
- 동료는 실제 생활·노동 도구의 형태를 유지하고 가면·번호표·작은 청록 결합부·얇은 표적선만 FILTERED 오버레이로 추가한다.
- 캐릭터 몸·무기 동작과 VFX를 한 이미지에 합치지 않는다.
- 아이콘은 64×64 공통 캔버스, 같은 선 굵기와 8px 이상 투명 여백을 사용한다.
- 노드·상태·스킬 아이콘은 `Sprite / Single`, 투명 PNG, Point 필터를 기본으로 한다.

### 1-3. UI 표면

- 블랙·차콜 패널, 낡은 목재·가죽·무광 청동 테두리를 사용한다.
- 오래된 스팀펑크 가이드의 톱니·밸브·파이프는 최신 최초 테마에 적용하지 않는다.
- 청록은 선택·기록·영혼석의 작은 강조에만 쓰고, 배경 전체를 네온으로 물들이지 않는다.
- 패널과 버튼은 9-slice가 가능한 단순한 모서리 구조로 만든다.

## 5. 파일·교체 규칙

| 상태 | 경로 |
|---|---|
| 생성 원본·검토본·생성 기록 | `art/production/graphics-remake/` |
| 반려한 중간 결과 | `_workspace/graphics-remake/rejected/` · Git 제외 |
| 승인된 Unity 최종본 | `Assets/Resources/RemakeV1/` |
| 기존 런타임 자산 | 검증 종료까지 현재 경로에 보존 |

- 새 에셋은 안정 `assetId`, 파일명, 프롬프트, 참조 이미지, 생성 방식, SHA-256과 승인 상태를 매니페스트에 기록한다.
- 승인 전 기존 파일을 삭제·덮어쓰기·GUID 재사용하지 않는다.
- 배경은 1672×941 16:9 RGB PNG를 기본으로 한다.
- 새 배경을 연결할 때 현재 `BattleBackground.backgroundBrightness=0.3`을 재조정한다. 새 스타일 앵커는 0.75~1.0 범위에서 먼저 검증한다.

### 캐릭터 시트 공통 규격

- 프레임: `384×512` RGBA, 한 동작 4프레임
- 시트: `1536×512`, 한 줄 가로 배열
- 순서: `중립 → 준비 → 핵심 동작 → 복귀`
- Idle: 같은 4칸 안에서 호흡·천·손의 미세 변화만 사용
- 기준선: 네 칸의 발 위치와 캐릭터 크기를 고정
- 분리: 몸·무기만 포함하고 VFX·배경·텍스트·UI는 제외
- 임포트 전제: `Sprite / Multiple`, Point 필터, 시트 승인 뒤 슬라이스
