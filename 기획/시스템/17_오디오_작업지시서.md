# 오디오 작업지시서 (BGM / SFX)

> 상태: **에셋 지정 대기** — 기획 변동 + 신규 오디오 에셋 추가됨.
> 기획자가 각 트리거에 사용할 에셋을 지정하면 그때 일괄 반영한다. (지금은 코드 트리거 지점만 정리)
> 작성: 2026-06-08

---

## 1. 사용 방법 (개발 메모)

- BGM 변경: `AudioManager.Instance.PlayBgmById(BgmId.XXX)`
- SFX 재생: `AudioManager.Instance.PlaySfxById(SfxId.XXX)`
- 에셋 매핑: `Audio/AudioDatabase`(또는 SoundDatabase) ScriptableObject 의 BgmId/SfxId → AudioClip 슬롯에 연결.
- **신규 에셋이 들어오면 이 표의 "지정 에셋" 칸을 채우고, DB SO 의 해당 슬롯에만 연결하면 코드 수정 없이 반영됨.**

---

## 2. BGM 트리거 지점 (BgmId)

| BgmId | 재생 시점 | 코드 위치 | 지정 에셋(기획자) |
|---|---|---|---|
| Title | 메인 메뉴 | MoveScene.cs:36 | (대기) |
| NodeMap | 노드맵 진입 / 패널 나가서 복귀 | NodeSystem.cs (진입·복귀) | (대기) |
| Battle | 전투 노드(일반/엘리트/보스) 진입 | NodeSystem.cs (Combat 분기) | (대기) |
| Rest | 화톳불 / 교회(이벤트) | NodeSystem.cs (Rest·Church) | (대기) |
| Mercenary | 용병소 진입 | NodeSystem.cs (Shop·이벤트→용병소) | (대기) |

> 참고: 보스 전용 BGM 분리가 필요하면 BgmId 에 `Boss` 추가 후 NodeSystem Boss 분기에서 호출 (현재는 Battle 공용).

## 4. 기획자 전달 양식 (지정 시)

각 항목에 대해 아래만 알려주시면 됩니다:
```
BgmId.Battle  → 파일명.wav (또는 추가된 에셋 이름)
SfxId.Heal    → 파일명.wav
...
```
→ 개발이 AudioDatabase SO 슬롯에 연결(코드 수정 없음).
