## 1. 안내 문구(텍스트) 수정 — 가장 자주 하는 작업 ⭐

**파일**: `Assets/Scripts/Tutorial/TutorialManager.cs`
**위치**: `DialogueMessages` 배열 (147~184행)

아래처럼 큰따옴표 `" "` 안의 글자만 고치면 됩니다. **번호(주석 `// 0 — …`)가 곧 표시 순서**입니다.

```csharp
private static readonly string[] DialogueMessages = new[]
{
    // 0 — NodeMapIntro   (첫 노드맵 화면)
    "환영합니다.\n\n화면 좌측의 노드맵에서 다음 노드를 클릭해 진행해보세요.",

    // 1 — CombatIntro    (첫 전투 진입)
    "전투 노드입니다.\n\n손패의 카드를 클릭해 ... 자동으로 스킬을 사용합니다.",
    ...
};
```

### 규칙 (꼭 지켜주세요)
- ✅ **고쳐도 되는 것**: 큰따옴표 `"…"` **안쪽 글자**.
- ⛔ **건드리면 안 되는 것**: 큰따옴표 자체, 줄 끝 **쉼표 `,`**, 대괄호 `[ ]`/`{ }`, `// 0 — …` 주석의 번호.
- **`\n` = 줄바꿈 1번**입니다. 한 줄 띄우려면 `\n\n`. (엔터로 줄을 나누지 말고 `\n`을 쓰세요.)
- 문장이 길어 `"…" +` 처럼 **`+`로 이어진 줄**(5·6·7·8번)도 있습니다. 이때도 각 `"…"` 안쪽만 고치면 됩니다. 줄 끝의 `+`와 마지막 줄의 `,`는 그대로 두세요.
- 따옴표를 글 안에 쓰고 싶으면 `\"` 처럼 앞에 `\`를 붙입니다. (가능하면 작은따옴표 `'`로 대체 권장)

### 예시 — 0번 문구를 바꾸기
```
(전)  "환영합니다.\n\n화면 좌측의 노드맵에서 다음 노드를 클릭해 진행해보세요.",
(후)  "괴이탐사대에 오신 걸 환영합니다.\n\n노드맵에서 빛나는 노드를 눌러 출발하세요.",
```

## 3. 그 외 진행값 (개발자와 함께 권장)

- `Tutorial/TutorialManager.cs:33` → `public const int TutorialSoulstoneGrant = 400;`

## 4. 수정 후 — 테스트(다시 보기) 방법

튜토리얼은 **최초 1회만** 자동으로 뜨고, 완료/스킵하면 `tutorial_completed = 1`로 저장돼 다시 안 뜹니다. 수정본을 다시 보려면:

- **방법 A (권장)**: 메인 메뉴의 **[처음이신가요?]** 버튼. (완료한 적 있으면 노출됨 — `MoveScene.cs:40`)
- **방법 B (QA)**: 개발자에게 "튜토리얼 플래그 리셋" 요청 → `TutorialManager.ResetCompletedFlag()` 실행 또는 PlayerPrefs의 `tutorial_completed` 삭제. 다음 [게임 시작] 시 자동 재진입.

> 진입/재진입 로직: `MoveScene.cs:53`(자동 진입), `MoveScene.cs:77`(`StartTutorialAgain`, [처음이신가요?] 버튼).

## 5. 주의 / 자주 하는 실수
- 문구 수정 후 **Unity가 자동으로 다시 컴파일**합니다(몇 초). 콘솔에 빨간 에러가 뜨면 보통 **따옴표/쉼표/괄호**를 건드린 것이니, 고치기 전 상태와 비교하세요.
- 문구 **개수(9개)** 와 **번호 순서**는 바꾸지 마세요. 줄을 통째로 지우거나 추가하면 트리거 번호와 어긋납니다. (문구 추가/삭제는 개발자와 함께)
- 모달 박스 **크기/위치**는 텍스트가 아니라 씬 UI(GamePlayScene의 `Canvas/TutorialCanvas`) 설정 → 개발자 영역.
