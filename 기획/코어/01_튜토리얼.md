# 튜토리얼 설계 (단계별)

> 노션 "AI 브랜드 시각화" 템플릿의 단계별 접근법을 차용. 각 단계가 이전 단계의 산출물을 기반으로 쌓아간다.

---

## 1단계: 학습 목표 정의

**핵심 질문**: 이 게임에서 플레이어가 반드시 알아야 할 것은 무엇인가?

### 학습 목표 (우선순위 순)

| 우선순위 | 학습 목표 | 난이도 | 설계 방향 |
|---|---|---|---|
| ★★★ | **카드 → 스택 → 스킬 자동 발동** | 최상 | 직접 체험 + 시각적 강조. 카드 사용 → 스택 바 변동 → 동료 스킬 발동까지 한 흐름으로 각인 |
| ★★☆ | **미행동 = 전략적 선택** | 중 | "일부러 한 턴 쉬어보라"는 유도. 단순 텍스트 설명이 아닌 체험으로 전달 |
| ★☆☆ | **스킬 사용 순서** | 하 | 배치 순서 → 미행동자 우선 재정렬. 툴팁 한 줄로 충분, 본 게임에서 자연 학습 |

### 설계 원칙

- **패러다임 전환 지점 집중**: "카드를 썼는데 왜 내가 공격을 안 하지?" — 이 게임의 가장 큰 낯섦을 튜토리얼에서 해소
- **체험 > 설명**: 텍스트만으로 가르치지 않고, 플레이어가 직접 손으로 겪게 한다
- **3순위는 과감히 생략**: 스킬 순서는 짧게 언급만, 게임 플레이 중 자연스럽게 익히도록

## 2단계: 세계관 연출 시나리오

**핵심 질문**: 플레이어에게 괴이탐사국이라는 세계를 어떻게 첫인상으로 각인시킬 것인가?

### 세계관 톤

> 괴이탐사국 내부는 **극도로 체계화되고 문서화된 무기질적 공간**이다.
> SCP 재단처럼 모든 것이 문서화되고, 요원조차 하나의 부품처럼 취급된다.
> 감정은 배제되고, 절차만이 존재한다.

### 연출 범위

| 구분 | 내용 |
|---|---|
| 연출 방식 | 텍스트 + UI 기반 (간단한 아트 리소스 포함) |
| 아트 리소스 | 업무지시서, 서류철, 업무 지침서 느낌의 문서 이미지 |
| 소요 시간 | 전문 읽기: 약 2분 / 스킵: 약 20초 |
| 진입 조건 | 최초 실행 시에만. 이후 재진입은 메뉴의 [처음이신가요?] |

### 오프닝 연출 시퀀스

#### S#1 — 기동 명령서 (약 40초)

- **연출**: 검은 배경 위로 괴이탐사국 공식 문서 양식이 한 줄씩 타자기로 찍히듯 출력된다.
- **문서 스타일**: 붉은색 [기밀] 도장, 문서 일련번호, 무감정한 관료적 문체
- **내용 예시**:

```
┌─────────────────────────────────────────┐
│  [기밀] 괴이탐사국 — 기동 지령서            │
│                                         │
│  문서번호: GRS-2026-0451                 │
│  등급: 제3급 — 현장요원 열람 가능           │
│                                         │
│  출동 요원: 제 7탐사분대                  │
│  대상: 미분류 괴이개체 (임시명: 고블린형)    │
│  위치: 구역 14-B                         │
│                                         │
│  지령:                                  │
│  해당 개체를 진압하라.                     │
│  요원의 생존은 보장되지 않는다.              │
│  탐사국은 결과만을 요구한다.                │
│                                         │
│  — 괴이탐사국 작전통제실                    │
└─────────────────────────────────────────┘
```

#### S#2 — 동료 배치 보고서 (약 30초)

- **연출**: S#1의 문서가 파일철에 끼워지는 애니메이션 후, 두 번째 문서로 전환.
- **문서 스타일**: 인사기록카드 느낌 — 요원 사번, 직무 코드, 배치 위치
- **내용 예시**:

```
┌─────────────────────────────────────────┐
│  [내부] 요원 배치 명세                     │
│                                         │
│  배치번호: DPL-7A-01                     │
│                                         │
│  슬롯 0 | 사번: CST-401 | 직무: 캐스터     │
│  슬롯 1 | 사번: PRS-218 | 직무: 프리스트   │
│  슬롯 2 | 사번: DEF-093 | 직무: 디펜더     │
│                                         │
│  ※ 4번 슬롯: 공석                          │
│  ※ 상기 요원은 본 작전에 한해               │
│    해당 배치로 고정된다.                     │
└─────────────────────────────────────────┘
```

#### S#3 — 작전 개시 (약 10초)

- **연출**: 문서가 닫히며 화면이 어두워짐 → 전투 화면으로 페이드 인.
- **텍스트**: 화면 중앙에 무미건조한 문구 하나만 짧게 출력 후 사라짐.

> "작전 개시. 교전을 허가한다."

### 디자인 가이드

| 요소 | 스타일 |
|---|---|
| 문서 양식 | 타자기 폰트, 고정폭 레이아웃, 붉은색 등급 도장, 문서번호 |
| 색감 | 검은 바탕 + 흰/회색 텍스트 + 붉은색 강조 (기밀 표시, 도장) |
| 애니메이션 | 한 글자씩 타자 출력, 문서 간 전환 시 파일 넘김 효과 |
| 사운드 | 타자기 키 입력음, 종이 넘기는 소리 (MVP: 무음도 허용) |
| 스킵 | 아무 키나 누르면 즉시 전투 화면으로 점프 (모든 문서 UI 표시 스킵) |

### 연출 의도

괴이탐사국이 **"너를 사람으로 보지 않는다"**는 걸 첫인상에서 각인시킨다. 요원은 부품이고, 생존은 보장되지 않으며, 오직 결과만이 중요하다는 무기질적인 분위기가 세계관의 축을 이룬다. 이 첫 경험은 이후 게임 전체의 톤을 결정한다.

## 3단계: 튜토리얼 전체 흐름 설계

**핵심 질문**: 오프닝 연출 이후, 전투 학습을 어떤 순서와 형식으로 전개할 것인가?

### 연출 형식: 괴이탐사국 교전 수칙

> 각 학습 포인트를 **"근무규칙 괴담"** 템플릿으로 제시한다.
> 번호가 매겨진 간결한 규칙 — 처음엔 평범한 업무 수칙처럼 읽히지만,
> 읽을수록 점점 불길하고 섬뜩한 조항들이 드러난다.
> 플레이어는 규칙을 읽고 [확인]을 누르면서 자연스럽게 게임 시스템을 익힌다.

### 전체 타임라인

```
[오프닝: S#1 → S#2 → S#3]
        ↓
[전투 튜토리얼]
  턴 1 ── 수칙 #1 (드로우) → 플레이어 확인 → 카드 플레이 가능
        ── 수칙 #2 (카드→스택) → 플레이어 확인 → 스킬 자동 발동 직전
        ── 수칙 #3 (스택→스킬) → 스킬 발동 시연
        ── 수칙 #4 (적 행동) → 적 턴 종료 후
  턴 2 ── 수칙 #5 (미행동) → 유도 메시지 → 미행동 보상 체험
  전투 종료 ── 수칙 #6 (특별 조항) → 페이드 아웃 → 메인 메뉴
```

### 교전 수칙 전문 (초안)

---

#### 수칙 #1 — 손패 보급

```
┌─────────────────────────────────────────┐
│  괴이탐사국 교전 수칙 — 제1조               │
│                                         │
│  매 턴 시작 시, 배치된 요원 수만큼           │
│  전술 카드가 손패로 보급된다.                │
│                                         │
│  ※ 손패는 곧 가용 전력이다.                 │
│  ※ 주의: 덱 소진 시 모든 요원에게            │
│    5의 탈진 피해가 발생한다.                 │
│  ※ 덱은 재보급되지 않는다.                  │
│    신중히 관리하라.                        │
└─────────────────────────────────────────┘
```

**연출**: 손패 영역에 외곽선 하이라이트. 카드가 한 장씩 패에 들어오는 애니메이션 강조.

#### 수칙 #2 — 전술 카드 운용

```
┌─────────────────────────────────────────┐
│  괴이탐사국 교전 수칙 — 제2조               │
│                                         │
│  전술 카드는 직접적인 공격 수단이 아니다.      │
│  카드는 전술 스택을 생성하며,               │
│  요원은 축적된 스택을 소비하여               │
│  자동으로 교전을 수행한다.                   │
│                                         │
│  ※ 카드의 효과는 요원의 성향에 따라          │
│    매번 달라진다.                          │
│  ※ 통제할 수 없는 것이 정상이다.             │
│    불확실성에 적응하라.                     │
└─────────────────────────────────────────┘
```

**연출**: 카드를 클릭하도록 유도 → 카드 사용 시 공용 스택 바가 변동하는 것을 시각적으로 강조.

#### 수칙 #3 — 요원 자동 교전

```
┌─────────────────────────────────────────┐
│  괴이탐사국 교전 수칙 — 제3조               │
│                                         │
│  스택이 축적되면 요원은 보유 스킬 중          │
│  발동 가능한 가장 높은 등급의 기술을          │
│  자동으로 사용한다.                         │
│                                         │
│  ※ 요원은 명령을 기다리지 않는다.             │
│  ※ 발동 가능한 스킬이 없는 요원은             │
│    이번 턴 행동하지 않는다.                  │
│    — 제5조 참조.                           │
└─────────────────────────────────────────┘
```

**연출**: 플레이어가 확인을 누르면 실제로 요원이 스킬을 발동. 스킬명 + 이펙트 강조.

#### 수칙 #4 — 적대 개체 대응

```
┌─────────────────────────────────────────┐

```

**연출**: 적(고블린)이 공격 → 아군 피격. HP 바 변동 강조.

#### 수칙 #5 — 행동 보류

```

**연출**: "이번 턴, 일부러 카드를 사용하지 말아보세요" 유도 → 실제 미행동 보상 발동. 배치 순서 재정렬 시각화.

│                                         │

```

**연출**: 승리 후 마지막 규칙이 타자기로 출력 → 서서히 페이드 아웃 → 메인 메뉴.

### 연출 규칙

| 항목 | 방식 |
|---|---|
| UI 형식 | 문서 템플릿 (테두리 박스, 타자기 폰트, [기밀]/[내부] 도장) |
| 진행 방식 | 각 수칙이 단계별로 표시 → [확인] 클릭 → 다음 단계 |
| 하이라이트 | 수칙에서 지칭하는 UI 요소에 외곽선 + 반투명 마스크 |
| 스킵 | [튜토리얼 스킵] 버튼으로 모든 수칙 생략 → 즉시 자유 전투 |
| 난이도 설계 | 적(고블린) HP를 낮춰 승리 보장. 단, 피격은 경험하게 |

### 설계 의도

전체 튜토리얼이 "괴이탐사국이 당신에게 건네는 업무 매뉴얼"이라는 콘셉트로 통일된다. 처음엔 평범한 교전 수칙을 읽는 기분이지만, 읽을수록 "요원 생존은 보장되지 않는다", "오늘도 당신은 출동할 것이다" 같은 불길한 문장들이 세계관의 무기질적인 공포를 전달한다. 시스템 튜토리얼과 세계관 각인이 동시에 일어나는 구조.

## 4단계: 전투 구성 설계

**핵심 질문**: 튜토리얼 전투의 파티, 적, 턴별 시퀀스를 학습 목표에 맞게 어떻게 구성할 것인가?

### 파티 구성 (고정)

| 슬롯 | 동료 | 직업 | 역할 | maxHp | 보유 스킬 |
|---|---|---|---|---|---|
| 0 | 디펜더 | Defender | Tank | 200 | 방어 준비 (cost 2, 전체 실드 20) |
| 1 | 캐스터 | Caster | Dealer | 100 | 매직 미사일 (cost 1, 단일 데미지 15) |
| 2 | 프리스트 | Priest | Support | 100 | 축성 (cost 1, 단일 힐 12) |
| 3 | 오펜더 | Offender | Dealer | 150 | 일섬 (cost 5, 단일 데미지 50) |

> 모든 스킬은 학습 목적에 따라 확정. 랜덤 스킬 할당 OFF.
> 각 동료당 **1개 스킬만** 보유 (튜토리얼 단순화).

### 적 구성 (고정)

| 적 | HP | ATK | 비고 |
|---|---|---|---|
| 고블린 (튜토리얼) | 65 | 10 | 매직미사일(15) + 일섬(50) = 정확히 65. 3턴 내 처치 보장 |

> ATK 10은 디펜더의 실드(20)에 1회 흡수되고, 이후 가장 낮은 HP(100) 기준으로도 생존에 충분한 수치.

### 튜토리얼 전용 규칙

| 규칙 | 내용 |
|---|---|
| 스택 생성 | 랜덤 OFF. 모든 카드는 고정값으로 스택 생성 |
| +카드 | 의도된 양수 스택 생성 (아래 표 참조) |
| -카드 | 의도된 음수 스택 생성 (아래 표 참조) |
| 손패 구성 | 매 턴 학습 시나리오에 맞는 카드 4장을 고정 드로우 |
| 덱 소진 | 튜토리얼 중 탈진 발생하지 않도록 충분한 덱 사이즈 유지 (또는 탈진 무효) |

### 카드별 스택 고정값

| 카드 구분 | 대상 동료 | 스택 타입 | 고정값 |
|---|---|---|---|
| 탱커 +카드 | 디펜더 | Tank | **+2** |
| 탱커 -카드 | 디펜더 | Tank | **-1** |
| 딜러 +카드 | 캐스터 | Dealer | **+1** |
| 딜러 -카드 | 캐스터 / 오펜더 | Dealer | **-1** |
| 딜러 +카드 (+5) | 오펜더 | Dealer | **+5** |
| 서포터 +카드 | 프리스트 | Support | **+1** |
| 서포터 -카드 | 프리스트 | Support | **-1** |

> 오펜더의 +카드는 +5로, 턴3에만 등장하며 누적 미행동 보상과 합쳐 cost 5에 도달하게 설계.

### 턴별 시퀀스 상세

#### 턴 1 — "카드 → 스택 → 스킬 자동 발동" 학습

```
[수칙 #1 표시] → [수칙 #2 표시] → 카드 플레이
```

| 순서 | 동료 | 손패 | 스택 생성 | 누적 스택 | 행동 |
|---|---|---|---|---|---|
| 1 | 디펜더 | 탱커 +카드 | Tank +2 | Tank = 2 | **방어 준비** 발동 (cost 2) → 전체 실드 20 |
| 2 | 캐스터 | 딜러 -카드 | Dealer -1 | Dealer = -1 | 미행동 |
| 3 | 프리스트 | 서포터 -카드 | Support -1 | Support = -1 | 미행동 |
| 4 | 오펜더 | 딜러 -카드 | Dealer -1 | Dealer = -2 | 미행동 |

| 이벤트 | 내용 |
|---|---|
| 수칙 #1 | 손패 보급 규칙. 카드 드로우 하이라이트 |
| 수칙 #2 | "카드는 공격 수단이 아니다". 카드 클릭 → 스택 바 변동 강조 |
| 수칙 #3 | 디펜더가 방어 준비 발동 → "요원은 스택을 소비해 자동 교전" 시연 |
| 수칙 #4 | 고블린 공격 (ATK 10). 디펜더 실드(20)에 흡수 → "적도 행동한다" 체험 |

**턴 1 종료 시점**: 캐스터·프리스트·오펜더 미행동 → 미행동 보상 적용

---

#### 턴 2 — "미행동 = 전략" 학습

```
[수칙 #5 표시] → 카드 플레이 (디펜더·오펜더는 -카드만 지급 → 자연 미행동)
```

| 순서 | 동료 | 손패 | 스택 생성 | 누적 스택 | 행동 | 비고 |
|---|---|---|---|---|---|---|
| 1 | 캐스터 | 딜러 +카드 | Dealer +1 | Dealer = 1 | **매직 미사일** (cost 1) | 고블린 HP 65→50 |
| 2 | 프리스트 | 서포터 +카드 | Support +1 | Support = 1 | **축성** (cost 1) | 아군 힐 12 |
| 3 | 디펜더 | 탱커 -카드 | Tank -1 | Tank = -1 | **미행동** | 스택 부족으로 스킬 발동 불가 → 자연 미행동 |
| 4 | 오펜더 | 딜러 -카드 | Dealer -1 | Dealer = -1 | **미행동** | 스택 부족으로 스킬 발동 불가 → 자연 미행동 |

> 턴 시작 전 미행동 보상으로 Dealer +2 (캐스터+오펜더 → 0), Support +1 (프리스트 → 0) 적용.
> 디펜더·오펜더의 손패는 -카드뿐: 사용해도 음수 스택이라 어떤 스킬도 발동 불가 → 시스템 규칙에 따라 자연스럽게 미행동.
> "일부러 쉬라"고 유도하는 대신, **손패 구성만으로 미행동이 발생하는 구조**를 보여준다.

| 이벤트 | 내용 |
|---|---|
| 수칙 #5 | "행동하지 않는 것도 전술이다". 미행동 보상(스택+1, 순서 우선) 규칙 설명 |
| 시스템 결과 | "디펜더와 오펜더는 발동 가능한 스킬이 없어 이번 턴 행동하지 않습니다. — 제3조에 의거, 제5조가 적용됩니다." |

---

#### 턴 3 — 마무리 + 종료

| 순서 | 동료 | 손패 | 스택 생성 | 누적 스택 | 행동 |
|---|---|---|---|---|---|
| 1 | 오펜더 | 딜러 +카드 (+5) | Dealer +5 | Dealer = 5 | **일섬** (cost 5, 데미지 50) → 고블린 처치 |

> 턴 시작 미행동 보상: Dealer +1 (오펜더), Tank +1 (디펜더). Dealer 누적 0 + 카드 +5 = 5 → 일섬 발동.
> 고블린 HP: 50 → 0. 전투 종료.

| 이벤트 | 내용 |
|---|---|
| 수칙 #6 | "오늘의 교전은 기록되지 않는다" — 마지막 규칙 타자 출력 후 페이드 아웃 |

### 승리 보장 설계

| 페일세이프 | 내용 |
|---|---|
| 고블린 HP | 65으로 고정. 최소 데미지(매직미사일 15) + 최대 데미지(일섬 50) = 정확히 65 |
| 아군 생존 | 디펜더 maxHp 200 + 실드 20로 절대 사망하지 않음. 타 동료도 ATK 10 수준에서 안전 |
| 튜토리얼 실패 | 플레이어가 의도와 다르게 카드를 써도, 매 턴 손패 리셋 + 고정 드로우로 시나리오 복원력 확보 |
| 전멸 방지 | 만약 모든 카드를 잘못 써서 전멸 직전이어도, 튜토리얼은 자동 재시작 (사망 시 처음부터) |

## 5단계: 단계별 가이드 상세

**핵심 질문**: 각 수칙을 어떤 방식으로 제시하고, 어떤 UI 요소를 강조하며, 어떤 타이밍에 진행할 것인가?

### UI 레이아웃

```
┌──────────────────────────────────────────────────┐
│ ┌─────────────┐                                   │
│ │             │                                   │
│ │  문서 패널   │          전투 화면                  │
│ │  (좌측 고정) │                                   │
│ │             │    ┌─────────────────────┐        │
│ │  수칙 텍스트  │    │    손패 (하단)       │        │
│ │             │    └─────────────────────┘        │
│ │  [확인]     │                                   │
│ │             │                                   │
│ └─────────────┘              [튜토리얼 스킵]       │
└──────────────────────────────────────────────────┘
```

- **좌측 패널**: 평상시 게임 정보가 표시되는 자리. 튜토리얼 구간에서는 문서 박스로 전환되어 **시종일관 유지**된다.
- **문서 박스**: 현재 수칙 텍스트 + [확인] 버튼. 배경은 검은색, 흰색 타자기 폰트, 상단에 붉은색 [기밀] 도장.
- **이전 수칙 아카이브**: 좌측 패널 하단에 이전 수칙들이 접힌 상태로 누적. "제1조▼", "제2조▼" 형태. 클릭 시 펼쳐서 재확인 가능.
- **전투 화면**: 기본 전투 UI 그대로. 하이라이트 대상 요소만 오버레이로 강조.

### 수칙별 연출 상세

| 수칙 | 시점 | 좌측 패널 내용 | 하이라이트 대상 | 확인 후 동작 |
|---|---|---|---|---|
| #1 — 손패 보급 | 턴1 시작 직전 | 제1조 전문 | 손패 영역 전체 (외곽선 + 반투명 마스크) | 문서 내용이 제2조로 갈아끼워짐 (자동 전환). 카드 드로우 애니메이션 재생 |
| #2 — 전술 카드 운용 | 턴1, 카드 플레이 전 | 제2조 전문 | 공용 스택 바 (깜빡임) | \"카드를 클릭해보세요\" 짧은 토스트 메시지. 모든 카드에 클릭 유도 표시 |
| #3 — 요원 자동 교전 | 턴1, 디펜더 카드 사용 직후 | 제3조 전문 | 디펜더 초상화 + 스킬명 팝업 + 스포트라이트 | 실제 스킬 발동 시연 (방어 준비). 주변 어둡게 → 스킬 이펙트 |
| #4 — 적대 개체 대응 | 턴1, 적 턴 시작 직전 | 제4조 전문 | 적(고블린) → 피격 방향 화살표 → 아군 HP 바 | 적 공격 애니메이션 재생. 아무 액션 강제 없음 — 자유 플레이 |
| #5 — 행동 보류 | 턴2 시작 직전 | 제5조 전문 + 유도문("의도적으로 디펜더와 오펜더를 쉬게 해보세요") | 디펜더·오펜더 초상화 (황색 외곽선 + \"미행동 유도\" 아이콘) | 유도 토스트 유지. 미행동 보상 발동 시 자동으로 제6조 전환 |
| #6 — 특별 조항 | 전투 종료 직후 | 특별 조항 전문 | 없음 (전체 화면 대상) | 페이드 아웃 → 메인 메뉴 |

### 진행 제어

| 항목 | 방식 |
|---|---|
| 수칙 전환 | 수칙 #1→#2는 자동 전환 (카드 드로우 시). 나머지는 [확인] 클릭으로 수동 전환 |
| 확인 버튼 | 좌측 패널 하단. \"[확인]\" 텍스트 (타자기 폰트). 클릭 시 현재 수칙 접힘 + 다음 수칙 출력 |
| 강제 대기 | 플레이어가 [확인]을 누르기 전까지 게임 로직(턴 진행)은 일시정지 |
| 스킵 | 우측 상단 [튜토리얼 스킵] 버튼 — 언제든 클릭 가능. 모든 패널·하이라이트 제거 → 일반 전투로 전환 |
| 수칙 아카이브 | 이전 수칙들은 좌측 패널 하단에 접힌 형태로 유지. 클릭 시 펼쳐서 재확인 가능 |

### 하이라이트 스타일

| 요소 | 효과 |
|---|---|
| 대상 UI (손패, 스택 바, 동료 초상화 등) | 황색 외곽선 + 주변 반투명 검정 마스크 (해당 요소만 밝게) |
| 깜빡임 | 0.5초 간격 3회 점멸 후 고정 하이라이트로 전환 |
| 스킬 발동 시 | 스킬명 팝업 + 해당 동료에게 스포트라이트 (주변 어둡게, 동료만 밝게) |
| 미행동 유도 | 동료 초상화 위에 작은 \"일시정지⏸\" 아이콘 오버레이 |

### 설계 의도

좌측 고정 패널에 문서 박스가 시종일관 남아있음으로써 \"너는 지금 교전 중이고, 규칙서를 옆에 펼쳐둔 채 싸우고 있다\"는 몰입감을 유지한다. 각 수칙과 실제 UI 하이라이트가 1:1로 대응되어, \"규칙을 읽는다 → 화면에서 확인한다 → 직접 겪는다\" 3단계 학습이 자연스럽게 이루어진다. 이전 수칙 아카이브는 플레이어가 언제든 다시 확인할 수 있게 하여, 학습 부담을 낮춘다.

## 6단계: 예외 처리

**핵심 질문**: 튜토리얼 중 발생할 수 있는 예외 상황을 어떻게 처리할 것인가?

### 예외 처리 원칙

- 튜토리얼은 **별도의 씬**에서 실행한다.
- 튜토리얼 중 발생한 진행 상태는 본 게임에 영향을 주지 않는다.
- 시나리오를 벗어나는 입력이 들어와도, 가능한 한 **미행동 보상 구조**로 복구한다.

### 예외 상황별 처리

| 상황 | 처리 방식 | 비고 |
|---|---|---|
| 앱 크래시 / 강제 종료 후 재접속 | 튜토리얼은 **처음부터 재시작** | 중간 저장 없음. 최초 실행 튜토리얼은 일회성 연출보다 학습 우선 |
| 플레이어가 의도와 다르게 카드 사용 | 허용 | 4단계에서 설계한 고정 드로우 + 미행동 보상으로 시나리오 복원 가능 |
| 스킵 직후 상태 꼬임 | 없음 | 튜토리얼을 별도 씬으로 분리하므로 본 게임 진입 상태와 무관 |
| 전투 중 사망 | 자동 재시작 또는 초기화 | 기존 `15_튜토리얼_명세.md`의 기본 정책 유지 |
| 플레이어가 [확인]을 누르지 않음 | 진행 정지 | 좌측 문서 패널 유지, 전투 로직은 멈춤 |
| 수칙 아카이브를 너무 많이 펼침 | 스크롤 유지 | 좌측 패널 내부 스크롤로 해결 |

### 설계 의도

튜토리얼은 정답을 맞히는 시험이 아니라, 규칙을 통해 시스템을 익히는 장치다. 따라서 플레이어가 예상과 다르게 행동해도 가능한 한 전투가 깨지지 않도록 설계하고, 깨졌을 경우에는 처음부터 다시 체험하게 해서 학습 흐름을 유지한다.

## 7단계: MVP 구현 가이드

**핵심 질문**: 이 설계를 실제로 구현할 때 필요한 최소한의 구성 요소와 흐름은 무엇인가?

### 씬 구성

| 항목 | 내용 |
|---|---|
| 씬 | `TutorialScene` — 본 게임과 분리된 별도 씬 |
| 진입 | `PlayerPrefs` `tutorial_completed` 확인 → 0이면 튜토리얼 씬 로드 |
| 종료 | `tutorial_completed = 1` 저장 후 메인 메뉴 씬으로 이동 |

### 필수 구현 요소

| 요소 | 설명 |
|---|---|
| TutorialController | 전체 튜토리얼 흐름 제어. 수칙 단계별 진행, 강제 대기, 스킵 처리 |
| DocumentPanel (좌측 패널) | 현재 수칙 텍스트 + [확인] 버튼 + 이전 수칙 아카이브. 타자기 출력 효과 |
| HighlightOverlay | 대상 UI 요소에 황색 외곽선 + 반투명 마스크. 깜빡임 효과 |
| TutorialBattleConfig | 확정 파티(4인), 확정 스킬, 확정 손패, 고블린(HP 65/ATK 10) 세팅 |
| TutorialSkipButton | 우측 상단 고정. 모든 수칙/하이라이트 제거 후 일반 전투로 전환 |

### 구현 참고사항

- 스택 생성 랜덤 OFF → 카드별 고정값 (4단계 표 참조)
