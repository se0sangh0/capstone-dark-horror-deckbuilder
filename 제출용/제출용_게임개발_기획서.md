### 3) 기획 의도
본 프로젝트는 기존 사랑받는 게임들의 핵심 재미를 재조합하여, **'설계'와 '운명'이 교차하는 새로운 덱빌딩 경험**을 실험하는 데 의의가 있다. 특히 다음과 같은 경험을 전달하고자 한다.

1. **장르 융합을 통한 '간접 전투'의 재발현**
   - 포켓몬 카드 게임의 턴제 자원 관리, 발라트로(Balatro)의 직관적 UI, 슬레이 더 스파이어의 덱빌딩 구조를 결합하여, 카드가 직접 타격을 입히는 것이 아니라 '전투의 변수'를 생성하는 독특한 **간접 전투 구조**를 구현한다.
     - 이미지1 : 포켓몬카드게임 에너지
     - 이미지2 : 발라트로 ui
     - 이미지3 : 슬레이 더 스파이어 손패 이미지
     - 이미지4 : "기존 덱빌딩은 카드가 직접 공격 → 우리 게임은 카드가 전투 변수를 생성 → 동료가 자동 행동"
   - 전투는 즉각적으로 읽히되, 숙련도에 따라 깊은 시너지 전략이 작동하도록 설계한다.

2. **단순한 규칙, 깊이 있는 플레이 (MVP 목표)**
   - 복잡한 룰보다는 플레이어가 카드를 사용할 때 느끼는 **직관적인 타격감과 즉각적인 피드백**에 집중한다. 과거 하스스톤이 증명했듯, 단순한 규칙 속에서도 리소스 운영의 손맛과 타격감이 충분하다면 핵심 재미를 전달할 수 있음을 검증한다.
   - MVP 단계에서는 콘텐츠의 **양적 완성(전투 루프 완주)**을 우선시하되, 최종적으로는 **플레이 로그가 서사가 되는 경험**을 제공한다. 전투 결과가 단순한 승패가 아닌 나만의 생존 기록으로 남아 여운을 주도록 한다.

3. **'괴이(怪異)' 컨셉과 소시민의 생존 서사**
   - SCP 재단 아카이브와 현대 장르 소설에서 영감을 얻어, 이계의 균열로 오염된 세계를 탐사하는 멀티버스 구조를 채택한다.
   - "사회를 타파하는 영웅이 아닌, 안위를 위해 도망치고 생존하는 소시민"이라는 테마를 통해, 플레이어의 선택(어떤 동료를 잃고 어떻게 도망쳤는가)이 로그에 축적되어 나만의 비정한 생존기를 완성하도록 유도한다.
   - 이미지 : "임무 완료. 다음 탐사 브리핑이 발송되었습니다. 출발 기한: 즉시" 텍스트 띄우기

## Ⅱ. 게임 소개

### 1) 시놉시스 및 세계관
플레이어는 '괴이탐사국' 소속 조사원으로서, 여러 괴이가 출몰하는 4번 균열을 탐사한다.
탐사 과정에서 용병을 모집하고 팀을 정비하며, 전투와 사건을 통해 탐지된 괴이를 격리해나간다.
조사관은 균열 내의 괴이를 격리해나가며 최종적으로는 균열을 폐쇄하는 것을 목표로 한다.

세계관은 다크 판타지 톤을 기반으로 한다. 괴이탐사국은 균열 내 괴이를 관리하는 비밀 조직이며, 조사관은 본인의 의사와 상관없이 반복적인 탐사를 수행한다. 임무를 완료하고 균열을 폐쇄해도 자유는 주어지지 않는다. 탐사국 수첩에는 "임무 완료. 영혼석 회수량: 정상. 다음 탐사 브리핑이 발송되었습니다. 출발 기한: 즉시"라는 통보만이 찍힐 뿐, 조사관은 다시 균열로 향한다. 추후 확장할 스토리 서사에서는 노드 진행 중 획득한 오브젝트와 텍스트 정보를 통해 이 반복의 배경을 조금씩 드러낸다.

## Ⅲ. 시스템 설계

### 1) 덱 시스템
- 역할 기반 스택 카드(딜러/탱커/서포터): 카드 클릭 시 직업별 공용 스택에 수치 누적, 발라트로식 토글 선택(들어올림·확대 트윈)
  - 이미지1 : 스택카드 이미지
- 드로우 페이즈 재드로우 + 덱 고갈 처리: 탈진 데미지, 리셔플 없음
  - 움짤 : 드로우 이미지
- 동료 사망 시 손패 처리: 하스스톤 "주문 제작 카드" 방식의 지연 파괴
- 데이터 주도 설계: CardData(ScriptableObject) + DeckBuilder + skills.json
- 카드 비주얼: nikoichu 픽셀 시트 기반 역할 배경(딜=빨강/탱=파랑/힐=초록) + 직업 아이콘(검/방패/하트)
  - 이미지1 : 카드 비주얼

### 2) 전투 시스템
- 덱빌딩 × 오토배틀러 하이브리드: 플레이어가 카드로 스택을 쌓으면, 동료·적이 배치 순서대로 스킬 자동 발동
  - 움짤 : 배치에 따른 전투 스킬 사용
- 드로우 → 카드 플레이 → 동료 행동 → 적 행동의 명확한 흐름
- 역할별 스킬 우선순위(딜=데미지/탱=실드/서포터=힐, 위기 상황에 서포터가 자동으로 힐 우선 → 판단 보조) + 코스트 차감
- 적 AI: 예측 가능하지만 변수 있는 패턴(가중치 룰렛 기반 스킬 선택) + 보스 상태 머신(강제 발동·까마귀 소환·순간이동·수확/흡혈)
- 자동 타게팅(전열 우선/최저 HP)·미행동 보상 및 배치 재정렬
- 데이터 주도: JsonUtility

### 3) 스트레스 시스템
전투 피해·이벤트로 누적되는 정신 압박 자원. 단계에 따라 디버프가 적용되어 전투 외적 긴장감을 만든다.

| 단계 | 상태 | 효과 |
| --- | --- | --- |
| 1단계 | 안정 | 기본 상태, 페널티 없음 |
| 2단계 | 압박 | 압박 디버프 적용 (세부 수치 기입) |
| 3단계 | 패닉 | 역할별 중증 디버프 적용 (세부 수치 기입) |

- 회복 수단: 화톳불(휴식), 교회(스트레스 회복) 노드
- 이미지1 : 스트레스 단계별 HUD 표시

### 4) 이중 재화 구조

| 재화 | 획득처 | 사용처 | 성격 |
| --- | --- | --- | --- |
| 영혼석 | 적 처치, 전투 보상 | 용병 모집·합성(용병소), 교회 서비스 | 탐험 내 단기 재화 — 런 종료 시 정산 |
