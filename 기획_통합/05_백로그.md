## 1. 코어루프 / 메타 / 로그북 확장

### 1-1. 코어루프 확장 (프로토타입 이후)
- 전투/노드 루프에 패시브/덱/동료 구성 조정 요소 본격 추가
- 성향/복잡한 시너지 시스템 확장 (세부 규칙은 별도 문서로 분리 예정)

### 1-2. 로그북 / 단서 수집 UI (정식 버전 후보)
- MVP: 노드/환경 오브젝트 텍스트 단서를 팝업/기록 형태로만 제공 ([00 §8](00_게임_개요_MVP_서사.md))
- 정식: 로그북/기록 조각 수집 UI → 수집→조합→추론 구조 / 단계형 메타 지표(시스템 경고·사념 단계)

### 1-3. 플레이 로그 기반 서사 ⭐
- 승패가 아닌 **"어떻게 생존했는가"** 의 기록 축적(잃은 동료, 피한 노드, 스트레스 한계 도달 등)을 로그북 조각으로 저장
- 종료 후 로그 기반 **나만의 생존기** 완성 → 다회차 유도. 테마: "모두가 영웅이 되는 건 아니다. 누군가는 그저 살아남기 위해 발버둥칠 뿐."

### 1-4. 스트레스 시스템 서사 확장 (정식 후보) ⭐
- MVP: 수치 패널티로 전투 리스크 조절
- 정식: 동료가 '인격 조각'으로서 **괴이 현상**을 일으키는 서사 장치 — 환각(아군 오인 공격/허상 타격), 도주(전투 이탈), 배신(아군 대상 스킬). 동료=현상의 일부 설정과 결합.
- ⚠️ 이 중 **환각(아군 오인 공격)** 은 [08 §4 패닉 확장](08_밸런스_난이도_아키타입.md)에서 '오발' 패닉 결과로 MVP 스코프 편입 제안됨. 나머지(도주/배신)는 정식 유지.

### 1-5. 성향 기반 전략 다변화 ⭐
- 성향 조합에 따라 디메리트 발동 → 이로운 효과로 전환하는 시너지 (예: 신중+과감 → 특정 조건 보너스 스택). 모집 단계에서 성향 고려 편성 유도.

### 결정 필요(체크)
- [ ] MVP 오브젝트 텍스트: "팝업만" vs "기록(간단 로그)"까지?
- [ ] 마석을 MVP에서 숨길지 vs "미사용 재화"로 노출할지 → (현재: 마석 메타 성장 구현됨, [03 §4](03_노드_용병소_보상_메타.md))
- [ ] 플레이 로그 서사 MVP 반영 범위 (단순 기록만? 조합/추론은 정식?)

## 2. 동료 확장 (성향 / 직업 / 모집 / 합성 / 성급)

> 원칙: [02_동료_적_데이터 §4](02_동료_적_데이터.md)에는 MVP에서 바로 구현/검증할 규칙만 남긴다.

### 2-1. 성향 설계안 (초안)
- 한탕주의자 `−5` 또는 `+5` / 안전제일 `−1 ~ +3` / 기회주의자 `−3 ~ +4` / 낙천주의 `−5 ~ +5`

**성향 시너지 초안** (동일 성향 2인 배치 시 발동, 추가 1인마다 % 증가)
- 한탕주의자: 전투 후 골드 `±N%` / 안전제일: 전투 후 골드 `+N%` / 기회주의자: 종료 후 남은 체력 비례 골드 `+N%` / 낙천주의: 전투 후 스트레스 감소 `N%`

### 2-2. 직업 설계안 (초안)
- 딜러: 캐스터·오펜서 / 탱커: 디펜더·어택커 / 서포터: 프리스트·샤먼

**직업 시너지 초안** (동일 직업 2인 배치 시 발동)
- 딜러: 오펜서=단일 딜↑ / 캐스터=범위 딜↑
- 탱커: 디펜더=전체 체력↑(실드형 그래픽 후보) / 어택커=본인 체력↑
- 서포터: 샤먼=적 받는 피해↑ / 프리스트=아군 받는 피해↓

### 2-3. 모집 / 용병소 확장안
- 교체/편성 변경은 용병소 노드에서만 / 모집 동료는 먼저 장바구니(임시 덱) → 노드 벗어나면 리셋 / 대기석 기본 9칸

### 2-4. 합성 / 승급 (초안)
- 같은 역할군 + 다른 성향 3개 → 상위 성급 **동일 역할, 랜덤 성향**
- 다른 역할군 + 같은 성향 3개 → 상위 성급 **랜덤 역할, 동일 성향**
- 다른 역할군 + 다른 성향 3개 → 상위 성급 **랜덤 동료**
- 같은 역할군 + 같은 성향 3개 → 상위 성급 **동일 역할·성향**

### 2-5. 성급 설계안 (초안)
- 1성: 스펙시트 기반 스택
- 2성: 1성 대비 데미지 계수 ×1.25, 체력 +40%
- 3성: 2성 대비 데미지 계수 ×1.25, 체력 +40%

### 결정 (확정)
- [x] MVP에서 성향/직업은 용어/데이터 필드만 남김
- [x] MVP에서 모집/합성은 흐름만 얇게 (합성=배제)

## 3. 패시브 시스템 (초안 + 정리)

> 주의: 마석 메타 성장으로 **동료 시그니처 패시브/스킬 해금은 이미 MVP 구현됨** ([03 §4](03_노드_용병소_보상_메타.md)). 아래는 그 외 미채택·확장 패시브 아이디어 보관.

### 3-1. 패시브 분류 체계
- 전투 보상형 / 전투 상시형 / 모집 제어형 / 런 방향성 선택형 / 직업 해금형

### 3-2. 아이디어 모음
- **전투 보상**: 전투 후 영혼석/체력/스트레스 회복 N%↑
- **전투 내**: 시작 시 체력 N%↑ / 아군 피해 N%↑ / 받는 피해 N%↓
- **모집**: 특정 역할군/성향 모집 확률↑

### 3-3. 런 방향성 선택 패시브
- 이번 런 운영 방향을 미리 선언하는 메타 선택지. 게임 시작 메인 화면 또는 이전 런 종료 후 다음 런 준비 단계에서 선택. 동일 카테고리 효과는 상호 배타(충돌 항목 UI 비활성), 런 종료까지 유지.
- 선택지 예: 전투 추적(이벤트 전투 확률↑) / 회피 경로(전투 확률↓) / 인력 수급(용병소 확률↑) / 독자 생존(용병소 확률↓)

### 3-4. 동료 3성 달성 해금 패시브 (초안)
- **캐스터**: 매직 미사일 타겟↑ / 파이어볼 데미지↑ / 매직 미사일 처치 시 연속 발동
- **오펜더**: 발도 데미지↑ / 발도 연속 콤보(콤보당 +10%, 타 스킬 사용 시 리셋) / 일섬 데미지↑
- **디펜더**: 배치 최전열 고정 / 방어 준비 실드↑ / 전투 태세 본인 받는 피해↓ + 링크(모든 아군 피해 30%씩 분담)
- **어택커**: 무모한 강타 데미지↑ / 불굴 회복↑ + 링크(10%씩 분담) / 무모한 강타 본인 받는 피해↓ + 발동 시 최전열 이동
- **프리스트**: 별부름 회복↑ / 기원 회복↑ / 기원 발동 시 본인 받는 피해↓

### 3-5. 검토 포인트 / 레퍼런스
- 동료 고정 특성 vs 직업 공용 vs 모집 시 랜덤 부여 / 상시 vs 조건부 / 역할 스택·스트레스·행동 순서와의 연결.
- 레퍼런스: 스킬 노드 방식 = 패스 오브 엑자일 / 스킬 패널 방식 = 로스트아크 아크 패시브.

### 3-6. 추후 개발 아이템 관리 표
| 항목 | 설명 | 상태 | 다음 액션 |
|---|---|---|---|
| 패시브 스킬 구조 | 동료/직업군 패시브 방식 | (마석 메타로 일부 구현) | 추가 패시브 MVP 포함 여부 결정 |
| 패시브 UI 노출 | 전투/편성 화면 노출 범위 | 미결정 | UI 초안 후 재검토 |
| 런 방향성 선택 패시브 | 조우 경향 사전 선택 메타 | 규칙 초안 존재 | 메인 화면 선택 UI·비활성화 구체화 |
| 성향/시너지 확장 | 복잡한 시너지 구조 | 후순위 | MVP 이후 판단 |
| 성장/해금 트리 | 장기 성장 구조 | 후순위 | 프로토타입 안정화 후 검토 |

## 4. 동료 서사 확장 (B안 / C안 — 정식 버전 검토)

> [00 §7](00_게임_개요_MVP_서사.md)에서 A안(비인간적 구현체)을 MVP 확정. 아래는 보류된 대안.

- **B안**: 스토리 유지 / 동료를 누적형 생존자로 변경
- **C안**: 핵심 동료만 누적, 나머지는 임시 — 절충안
- 결합 검토 요소: 동료 개인 스토리 / 마을 복귀 후 대화 이벤트 / 특정 동료의 시간선·기억·균열 경험 / 플레이어-동료 관계 변화 / "함께 살아남아 온 사람들" 감각

## 5. 기타 MVP 제외 / 후순위
- 복잡한 성향 시스템 / 다중 시너지 조합 확장 / 상위 성장·승급 세부 분기 / 패시브 해금 트리 / 메타 성장 확장
- (스토리) 로그북 수집→조합→추론 / 단계형 메타 지표 / 코드네임 기반 숨은 설정(MVP는 '암시'까지) / NPC 신뢰도·대화 분기 기반 진실 접근
- 교회 노드 / 엘리트 전투 노드 / 마석 치환 비율(영혼석 n개 → 마석 1개)
