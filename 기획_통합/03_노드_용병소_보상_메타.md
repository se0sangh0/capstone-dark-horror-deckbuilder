## 1. 맵 노드 설계

### 1-1. 정식 버전 기준 (10층 분기) 진행

| 항목      | 값           | 비고             |

**노드 타입 비율(초안)**: 전투 70% / 이벤트 30%(용병소·교회·엘리트 랜덤) / 보스 10층 고정. (밸런스 테스트 후 조정)

## 2. 용병소 시스템 명세 (정식 버전)

용병소는 탐색 중 등장하는 **이벤트 노드**로, 파티가 전투를 이어가기 위한 동료를 모집·교체하는 장소다. 핵심 3가지는 ① 사망으로 생긴 빈 슬롯 복구 ② 파티 조합 조정 ③ 새 동료 영입이다. 정식 버전에서는 성급·성향·후속 성장 요소와 연결될 수 있도록 후보와 비용을 데이터로 관리한다.

### 2-1. 범위

**포함**: 진입 / 후보 동료 목록 / 고용 / 후보 리롤 / 파티 편집 진입 / 빈 슬롯 보충 / 소울스톤 차감 / 성급별 비용 표시
**후속 확장**: 해고 보상 반환 / 스킬 재롤 / 전직 / NPC 대화 분기 / 복합 성향 시너지

### 2-2. 기본 규칙

**진입**: 이벤트 노드 클릭 시 `currentView = 'mercenary'` 전환 → 전용 UI.

**후보 표시**: 진입 시 후보 동료 **3인 고정** 표시(`reserves`/별도 후보 풀). 각 후보는 이름·직업·역할·모집 비용·성향 표시, 한 화면 비교 가능. (추후 패시브로 대기석 슬롯 증가 가능)

**고용**:
- 대기석 동료 선택 → 고용, 소울스톤이 모집 비용만큼 차감.
- 모집 비용은 [02_동료_적_데이터 §2](02_동료_적_데이터.md)의 `starGrade`와 성급별 기본 비용을 사용한다: 1성 30 / 2성 75 / 3성 180.
- 후보의 성급과 비용은 함께 표시하며, 성급에 따른 스탯·스킬 메리트는 [05_백로그](05_백로그.md)의 성급 설계와 동기화한다.
- 파티 4명 미만이면 빈 슬롯 우선 채움. 4명이면 교체 모드 전환.
- 후보 대기열 **9칸**.

**리롤**:
- 비용 지불해 후보 목록 재생성, 기존 후보는 폐기되고 새 3인으로 교체.
- 리롤 비용은 해당 노드 내에서만 누적. 최초 **영혼석 2**, 두 번째부터 직전 비용 +1씩 (2→3→4…).
- 노드를 벗어나면 누적 초기화. 무한 반복 가능(밸런스 시 상한 가능).

**파티 편집**:
- 전투 중이 아닐 때만 가능. 현재 파티 4칸 + 대기열 동료 목록 함께 표시.
- 위치 순서 변경 / 대기열 동료로 교체 / 빈 슬롯 즉시 배치 가능.
- 만석이면 기존 1명 ↔ 대기열 1명 교체. 편집 즉시 반영.
- 현재 덱의 성향·역할 구성 표시. (추후 직업/성향 시너지 대시보드 확장)

### 2-3. 흐름

```text
진입:  event 노드 클릭 → onNavigate('mercenary') → currentView='mercenary' → MercenaryOfficePanel
고용:  후보 선택 → 모집 → 비용 확인 → (부족=실패 / 충분=차감) → 획득 → (빈슬롯=즉시 합류 / 만석=교체 대상 선택)
리롤:  리롤 → 비용 확인 → (부족=실패 / 충분=차감) → 후보 3인 재생성
교체:  만석 고용 → 교체 대상 선택 → 기존 제거 → 신규 합류 → 목록 갱신
```

### 2-4. 예외 처리
- **영혼석 부족**: 고용/리롤 미실행, 명확한 실패 메시지.
- **파티 만석**: 자동 합류 X, 반드시 교체 대상 선택.
- **빈 슬롯**: 전투 사망 빈 슬롯은 용병소에서만 복구, 있으면 교체보다 즉시 채우기 우선.
- **중복 직업**: 허용.
- **후보 수 부족**: 기본 후보군 사용, 정식 버전은 항상 3명 보이도록 보정.
- **구매 가능 후보 보장**: 현재 보유 영혼석 이하의 모집 비용을 가진 후보를 최소 1명 포함한다. 3인 모두 구매 불가 상태로 생성되면 후보 1인을 교체해 선택 가능한 후보를 보정한다.

### 2-5. UI 구성
- 상단: 현재 소울스톤 / 파티 상태
- 탭: 파티 모집 / 파티 구성 / 동료 성장 (후속 확장)
- 중앙: 선택 메뉴 내용 / 우·하단: 고용·리롤·닫기 / 부가: 선택 후보 상세
- 피드백: 비용 부족=빨강 경고 / 고용 성공=알림 / 리롤=목록 즉시 갱신 / 교체=파티 즉시 반영

### 2-6. 데이터 테이블 (예시)

**리롤 비용 상태**: `rerollBaseCost(2)`, `rerollIncrement(+1)`, `rerollCount`, `effectiveRerollCost`
**후보 데이터**: `allyId`, `displayName`, `jobClass`, `role`, `starGrade`, `maxHp`, `stressResist`, `recruitCost`, `skill1`, `skill2`
**UI 상태**: `isOpen`, `selectedCandidateIndex`, `rerollCount`, `canRecruit`, `canReroll`

### 2-7. 밸런스 기준
- 용병소는 보상 노드가 아니라 **"복구 노드"** — 손해 일부 회복 가능하나 무조건 이득은 아님.
- 고용은 일정 비용 요구, 리롤은 선택적 소비(노드 내 반복 억제 수준으로 증가).
- 후보 3인 중 최소 1명은 현재 파티에 의미 있는 선택지가 되도록 구성. 너무 강한 후보 연속 방지.

## 3. 보상 시스템 명세

> 확정 구조 (2026-05-26). ⚠️ 영혼석 드롭 수치는 임시값 — 적 수 확정·밸런스 후 조정.

| 항목 | 내용 |
|---|---|
| 보상 종류 | 영혼석만 (카드 추가 없음) |
| 지급 방식 | 적 처치 시 바닥에 오브젝트 드롭 → 자동 수거(연출용) |
| 지급 시점 | 처치 즉시 |

### 3-1. 시작 영혼석 / 드롭량

- **런 시작 시 보유 영혼석: 20개.**

| 적 | 드롭량 | 비고 |
|---|---|---|
| 고블린 | 8개 | 일반(약) |
| 약탈자 | 12개 | 일반(강) |
| 거두는 자 | 20개 | 보스 고정 |

**일반 전투 조합 참고(3마리 기준)**: 고블린 3 = 24 / 고블린 2+약탈자 1 = 28 / 약탈자 3 = 36

### 3-2. 정식 런 수지 기준

정식 버전은 층별 인카운터와 이벤트 선택에 따라 수입·지출이 달라지므로 고정 시퀀스 대신 아래 산식으로 관리한다.

```text
런 종료 영혼석 = 시작 영혼석 20
              + 처치한 적의 soulStoneReward 합계
              - 모집·리롤 지출
              + 이벤트 선택 결과
```

| 항목 | 정식 기준 |
|---|---|
| 시작 영혼석 | 20 |
| 일반 적 보상 | 고블린 8 / 약탈자 12 등 적 데이터별 합산 |
| 엘리트 보상 | 개체별 20~22 등 적 데이터별 합산 |
| 보스 보상 | 거두는 자 20 / 기록관 30 |
| 모집 비용 | 1성 30 / 2성 75 / 3성 180 |
| 리롤 비용 | 2부터 시작, 노드 내에서 1씩 증가 |

> 정식 10층에서는 전투·엘리트·이벤트 방문 수가 런마다 달라진다. 특정 층에서 모집이 반드시 가능하다고 가정하지 않고, 후보 구매 가능 보정과 이벤트의 코스트 없는 선택지로 자원 고갈을 방지한다.

### 3-3. 연출 (영혼석 드롭 오브젝트)
- 적 처치 위치에 영혼석 스폰 → 약 0.5초 후 자동 수거 애니(UI 방향으로 빨려듦). 플레이어 인터랙션 없음. Unity **Object Pooling** 권장.

### 3-4. 조정 대상
- 정식 인카운터별 영혼석 기대값과 엘리트 드롭량은 [08_밸런스_난이도_아키타입](08_밸런스_난이도_아키타입.md)의 조합표와 함께 플레이테스트한다.
- 오브제(유물)는 엘리트 처치 10% 드롭, 보스 클리어 시 마석 교환·계승 흐름으로 관리하며 상세 규칙은 [09_오브제_유물_시스템](09_오브제_유물_시스템.md)을 따른다.

## 4. 마석 메타 성장 명세 (정식 버전)

> 작성 2026-06-01 / 재설계 2026-06-02 / 상태: **설계 확정 — 구현 진행**. 결정 기반: 로그라이크 메타 루프 전환 / 전투 관여형 패시브 / 시그니처 스킬 해금.

**마석(Magic Stone)** 은 런을 넘어 유지되는 **영구 메타 재화**. 마석으로 **영구 패시브/스킬**을 해금하며 효과는 이후 모든 런에 상시 적용. 마을 시스템은 시간상 보류하고 **로그라이크 메타 루프**로 대체.

### 4-1. 런 루프 (2026-06-02 핵심 변경)

기존: 보스 클리어 → 엔딩 → 메인 메뉴 / 전멸 → 메인 메뉴.
변경: **보스 클리어·전멸 모두 동일 루프**
1. **리셋**: 예비대(대기석) + 활성 파티(기본 파티) + 영혼석 기본값(20) 리셋.
2. **마석 유지**: 마석은 리셋하지 않고 누적. (별도 클리어 보너스 없음 — 노드 보상으로만: Combat +10 / Elite +20 / Boss +30)
3. **패시브 해금 화면**: 첫 배틀 노드 진입 **전** 마석 상점 표시 (초록 시작 노드와 동일 패널 재사용).
4. **새 런 시작**: 노드맵 재생성 → 첫 배틀 노드부터.

> 메인 메뉴(`GameStartScene`)는 최초 실행/튜토리얼 진입 용도로만 유지.

### 4-2. 카테고리 A — 동료 시그니처 패시브 (전투 관여형, 풀+랜덤 배정)

스탯/재화 증가가 아니라 **전투 메커니즘에 관여하는 상시 능력**(롤 패시브 / 포켓몬 특성형).
- 각 동료는 **3개 패시브 풀** (5동료 × 3 = 15종). 개별 해금(마석) → 그 동료의 "해금된 풀"에 추가.
- **배정**: 동료 인스턴스 생성되는 **런 시작 시 1회**, 해금된 풀에서 무작위 1개를 `activePassiveId`로 배정(전투마다 재배정 안 함). 해금된 게 없으면 패시브 없음.
- **표시**: 카드에 현재 활성 패시브 표시. **전투 적용**: `user.activePassiveId == <id>`로 발동 판정.

| 동료 | ID | 패시브 | 효과 (정식 기본) | 비용 |
|---|---|---|---|---|
| 캐스터 | `pasv_caster_chain` | 비전 연쇄 | 매직미사일로 적 처치 시 다른 적 1명에게 동일 피해 1연쇄(턴당 1회) | 80 |
| 캐스터 | `pasv_caster_amp` | 주문 증폭 | 캐스터 모든 데미지 +15% | 80 |
| 캐스터 | `pasv_caster_exec` | 멸절 | 광역 데미지 사용 시 HP 최저 적에게 +50% 추가 단일타 | 90 |
| 오펜더 | `pasv_offender_combo` | 거합 집중 | 동일 대상 연속 단일타 +20%/스택(최대 +60%, 대상 바뀌면 리셋) | 80 |
| 오펜더 | `pasv_offender_execute` | 처형인 | HP 30% 이하 적 단일 공격 시 +50% | 80 |

### 4-3. 카테고리 B — 동료 시그니처 스킬 해금

각 동료의 시그니처(고코스트) 스킬을 마석으로 해금. 미해금 시 스킬 풀에서 제외, 해금 시 풀에 추가(기존 "4개 풀 중 2개 랜덤" 체계 유지).

|---|---|---|---|

> 일반 스킬은 항상 풀 포함(해금 불필요). 적용 지점: 동료 스킬 배정부(`skillPool` 2-of-4 추출) 직전, `MetaPassiveManager.IsSkillUnlocked(skillId)` false 인 시그니처 스킬 제외.

### 4-4. 경제 / 영속성

- 획득: 노드 보상 — Combat +10 / Elite +20 / Boss +30. 별도 클리어 보너스 없음.
- 총 해금 비용: 패시브 5종(80+80+100+90+80=430) + 스킬 5종(60×5=300) = **730 마석**.
- **정식 10층 계획값**: 전투·엘리트 노드 수에 따라 **80~120 마석/런**을 가정하며, 전체 해금까지 약 **7~10회 성공 런**이다. 실제 방문 노드 비율과 오브제 교환량에 따라 플레이테스트 후 조정한다.

| 데이터 | 키 | 형식 |
|---|---|---|
| 마석 잔액 | `ManaStone` | int |
| 각 해금(패시브/스킬) | 위 표의 ID | int 0/1 |

> 해금 상태 PlayerPrefs 영속. 디버그 초기화: `MetaPassiveManager.ResetAll`.

### 4-5. UI — 마석 상점
- 진입: 노드맵 초록 시작 노드(상시) + 런 루프 첫 배틀 전 화면(자동). 동일 `MagicStoneShopPanel` 재사용.
- 구성: 보유 마석 + 카드 10종(패시브 5 + 스킬 5) — 스크롤/2열 그리드. 각 카드: 이름/효과/비용 + 상태 버튼(해금/마석부족 비활성/해금완료).

### 4-6. 폐기/대체
- (폐기) 초안 보상형 패시브 3종(`meta_soul_gain` 영혼석+25% / `meta_post_heal` 전투후 회복 / `meta_calm` 스트레스 회복 2배) — 전투 관여형 + 스킬 해금으로 전면 대체.
- (폐기) 마석→영혼석 10:1 변환.
