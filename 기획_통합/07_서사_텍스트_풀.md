# 07. 서사 텍스트 풀 (인게임 문구 마스터)

> **상태**: 🟡 제안 초안 v0.1 (2026-07-21 작성) — **팀 리뷰/확정 필요**
> **작성 배경**: 00 스토리보드에 "노드마다 한 줄 암시 텍스트"라고 명세되어 있으나 실제 텍스트 리스트가 없었음. 전부 텍스트라 구현 비용은 낮고 세계관 정체성 완성 효과가 큼.
> ⚠️ **이 문서가 인게임 서사 문구의 마스터다.** 노드 진입/전투/사망/패닉/보스 시스템 메시지는 여기서 관리한다.
> **선행 문서**: [00_게임_개요 §6 서사, §8 오브젝트 텍스트](00_게임_개요_MVP_서사.md) · **연계**: [06_이벤트_노드](06_이벤트_노드.md) · [04_튜토리얼 §3 오프닝](04_튜토리얼.md)

## 1. 톤 규칙 (모든 텍스트 공통)

1. **탐사국 화법** = 감정 배제·절차·문서체. 사람을 부품으로 취급 (SCP 재단 톤, [04 §3](04_튜토리얼.md)). 예: "요원 소실. 기록 말소 처리."
2. **환경 화법** = 짧고 감각적. 정답을 말하지 않고 **의심의 잔상**만 남긴다 (00 §8 원칙). 마지막 문장에서 살짝 어긋난다.
3. 거대한 고유명사/코드네임은 직접 명명하지 않는다. 암시로만.
4. 길이: 노드 진입 = 1~2문장 / 시스템 메시지 = 1문장 / 컷 연출 = 2~3문장.
5. **수집 강제 아님** — 읽지 않아도 진행 가능. 스킵 가능.
6. 반복 노출되는 문구(전투 시작 등)는 여러 개를 풀에서 랜덤으로 뽑아 반복감을 줄인다.

## 2. 노드 진입 텍스트 (타입별 풀)

> 노드 진입 시 1개 랜덤 표시. 층 진행에 따라 톤이 무거워지도록 전반(1~3층)/후반(4~6층) 분리.

### 2-1. 전투 노드 — 진입

**전반 (1~3층)**
1. "적대 개체 감지. 교전을 허가한다."
2. "이 구역은 아직 '정리'되지 않았다."
3. "공기 중 오염도 상승. 무언가 이쪽을 알아차렸다."
4. "익숙한 냄새다. 어디서 맡았는지는 기억나지 않는다."

**후반 (4~6층)**
5. "개체 수가 기록과 맞지 않는다. 매번 그랬듯이."
6. "여기서 싸운 적 있다. 이긴 기억은 없다."
7. "저것들은 당신을 적으로 보지 않는다. 아직 오지 않은 동료로 본다."

### 2-2. 화톳불 노드 — 진입

1. "잠시. 여기서는 아무것도 당신을 세지 않는다."
2. "불을 쬔다. 그림자가 인원수보다 하나 많다."
3. "회복 절차를 개시한다. 무엇으로부터의 회복인지는 명시되지 않았다."
4. "숨을 고른다. 다음 숨을 셀 수 있는 곳은 여기가 마지막일지도 모른다."

### 2-3. 용병소 노드 — 진입

1. "인력 수급소. 지원자는 언제나 충분하다. 그게 문제다."
2. "여기 모인 것들은, 한때 당신 같은 무언가였다."
3. "명단은 매번 새로 채워진다. 빈자리가 생기는 속도만큼."

### 2-4. 보스 노드 — 진입

1. "최종 회수 지점. 이 앞으로는 기록이 없다."
2. "낫질 소리가 들린다. 벨 것이 없는데도."
3. "여기서 무언가가 당신을 기다린다. 오래, 아주 오래전부터."

### 2-5. 시작/노드맵 — 진입 (런 시작 시 1회)

1. "탐사 개시. 오늘도, 어제처럼."
2. "출동 명령 수신. 발신인란은 비어 있다."
3. (2회차 이상) "또 왔다. 아니, 떠난 적이 없었다."

## 3. 전투 중 시스템 메시지

### 3-1. 동료 사망 (전원 🧠 +20 트리거 동시)

> 탐사국 화법. 개인을 지운다.

1. "요원 소실. 기록 말소 처리."
2. "개체 1 이탈. 대체 인력은 수급소에서 보충하라."
3. "손실 확인. 명단에서 해당 항목을 삭제했다."
4. (희귀/랜덤 1할) "…이름이 뭐였더라. 아무도 적어두지 않았다."

### 3-2. 미행동 보상 발생

1. "행동 보류. 다음 차례 우선권 확보."
2. "숨을 아꼈다. 대신 앞으로 나섰다."

### 3-3. 탈진 (덱 고갈, 전원 5 데미지)

1. "보급 중단. 전원 탈진 판정."
2. "카드가 바닥났다. 몸이 대신 값을 치른다."

### 3-4. 전투 승리 / 패배

**승리**
1. "구역 정리 완료. 회수분을 수거하라."
2. "적대 개체 전멸. 이 결과는 기록되지 않는다."

**패배 (전멸)**
1. "탐사대 전멸. 다음 탐사대가 이미 편성되었다."
2. "임무 실패. 실패라는 표현은 보고서에 쓰지 말 것."

## 4. 스트레스 / 패닉 메시지

> 스트레스 시스템은 이 게임의 핵심 차별점(00 §2). 수치 변화에 텍스트를 붙여 "세계가 사람을 망가뜨린다"를 체감시킨다.

### 4-1. 압박 진입 (51 도달, 동료별 1회)

1. "[동료]의 손이 떨린다. 아직은, 쥘 수 있다."
2. "[동료]의 시선이 자꾸 뒤를 향한다. 거기엔 아무것도 없다."

### 4-2. 패닉 발동 (100 도달)

**공포 경직 (해당 턴 행동 불가)**
1. "[동료]가 얼어붙었다. 눈앞의 적보다 무서운 걸 본 얼굴로."

**과호흡 (스택 요구량 +1)**
1. "[동료]의 호흡이 무너졌다. 간단한 동작 하나가 버겁다."

> 패닉 결과 확장(오발/폭주 등)은 [08_밸런스_난이도 §4](08_밸런스_난이도_아키타입.md) 제안 참조. 확장 시 이 절에 텍스트 추가.

## 7. 텍스트 배치 매핑 (구현 참고)

> 각 텍스트가 어느 코드 트리거에 연결되는지. 오디오 트리거표([03 §5](03_노드_용병소_보상_메타.md))와 같은 방식으로 관리.

| 분류 | 표시 시점 | 코드 위치(추정) | 비고 |
|---|---|---|---|
| 노드 진입 텍스트 | 노드 진입 | `Node/NodeSystem.cs` | 타입별 풀에서 랜덤, 층 분기 |
| 동료 사망 | UnitDied 이벤트 | `FellowData.Hp.cs` | 스트레스 +20과 동시 |
| 미행동/탈진 | 결과 처리 | `BattleManager.Phases.cs` | |
| 압박/패닉 | 스트레스 임계 도달 | `BattleManager` 스트레스 처리부 | 동료별 1회 |
| 보스 전용 | 보스 스킬 시전 | `BattleManager.EnemyAction.cs` | 스킬ID→텍스트 매핑 |
| 층 전환 | 노드 완료 | `NodeSystem.cs` | |

> **구현 방식 제안**: `NarrativeTextSO`(분류 enum + string[] 풀)를 두고 `NarrativeManager.Get(category, floor)`로 랜덤 반환. 오디오의 SoundDatabase와 동일 패턴 → 기획자가 SO만 채우면 코드 수정 없이 문구 교체 가능.
