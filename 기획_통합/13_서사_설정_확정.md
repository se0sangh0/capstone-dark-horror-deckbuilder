## 1. 핵심 반전 한 줄

> **당신은 차원을 지키는 조사관이 아니다. 남의 차원에서 영혼을 수탈해 오는 침략군이다.**

## 2. 진실 층위표 (`FILTERED` 기본 인게임 vs 실제)

플레이어(와 모든 요원)는 탐사국이 만든 **`FILTERED` 인식**으로 게임을 시작한다. 게임의 모든 텍스트·UI는 기본적으로 `FILTERED` 층위로 쓰고, 실제 세계의 모습은 `LEAK`(오염·암시 텍스트)와 `TRUE_VIEW`에서만 드러낸다.

| 요소 | `FILTERED` 기본 인게임 인식 | 실제 |
|---|---|---|
| 균열 | 비현실이 침범한 이상 지대 | **원래 존재하던 타 차원과 연결된 통로** — 새 차원이 아니다 |
| 탐사자(주인공) | 차원을 지키는 이레귤러 — 괴이를 격리하는 조사관 | **그 차원 입장에서 외세의 침략군** |
| 영혼석 | 회수 대상 자원 | **그 차원의 영혼을 수탈한 것** |
| 영혼석의 용도 | 상납 → 마석 보상 | **재인식장치·세뇌장치의 동력원** — 수탈이 세뇌를 굴리고, 세뇌가 수탈을 지속시키는 자기 순환 |
| 마석 | 영혼석과 다른 상위 재화 | **구분은 유저 UI상의 것일 뿐, 실제 단위는 동일하게 영혼석** — 탐사국이 수탈물 일부를 "보상"으로 돌려주며 재화처럼 보이게 한 것 |
| 괴이 | 격리 대상 위협 | **그 차원을 지키는 존재들** — 침략군에 맞서는 수호자 |
| 수확자(거두는 자) | 최상위 위험 개체 | **농경사회의 토착신** — 재인식장치가 꺼진 눈으로 보면 신앙의 대상. 낫·추수밭·까마귀는 괴물의 상징이 아니라 풍요신의 도상 |
| 동료 | 전투 구현체 — 탐사자의 잔재 (구 A안) | **수탈된 현지 영혼이 영혼석에 반응해 재구성된 것** (2026-07-27 확정) — 플레이어는 빼앗은 영혼을 병사로 부리고 있다 |
| 브리핑 | 복귀 절차 | 기억 교정 (기존 확정 유지) |
| 교회 | 균열 내 안식처 | **❓ 맥거핀 — 답을 정하지 않는다 (확정)**. 미등록 구조물이라는 위화감만 유지, 운영 주체는 팀도 확정하지 않음 |

## 3. 시스템과의 정합 (설정이 기존 시스템을 설명하는 지점)

- **재인식 장치([10])**: 단순 오염 리셋 장치가 아니라 **세뇌 유지 인프라의 말단**. 오염도 = 세뇌가 벗겨져 실제가 보이기 시작하는 정도 → 동료 모자이크(1단계)는 "검열", 얼굴 가죽(2단계)은 세뇌 아래의 실체에 근접. 10 문서는 백로그지만 설정상 핵심 장치이므로, 구현 전에도 **텍스트 암시로는 존재**한다.
- **영혼석 경제**: 회수 → 상납 → 마석 보상 루프 전체가 수탈 파이프라인. "마석=영혼석" 확정으로 [05 §5](05_백로그.md)의 "마석 치환 비율" 미결에 서사적 답이 생김 (치환이 가능한 이유: 애초에 같은 것).
- **보스전 배경**([디자인_UI/01 §3] 개방형 목석 성소): `FILTERED`에서는 거두는 자가 만든 뿌리·뼈·마른 짚의 둥지처럼 보이지만, `TRUE_VIEW`에서는 탐사국의 침입으로 훼손된 **현지 생활·제의·피난 공간**이다.
- **동료 사망 시 "균열이 울었다"**(07 §3-1 희귀 문구): 균열 쪽 존재들이 동료(구현체)와 무관하지 않다는 기존 암시가 설정과 연결됨.

## 3B. 런 차원 테마 (2026-07-27 확정 방향)

**런마다 균열이 연결되는 차원(테마)이 다르다** — 고대 말기 농경 세계라면 목석 성소와 부족 전사풍, 무협 항전 세계라면 민초·임협풍으로 **동료·환경·괴이의 스타일이 그 차원을 따른다.**

- 서사 정합: 동료 = 그 차원에서 수탈된 현지 영혼이므로, **동료의 외형·이름이 차원 테마를 따르는 것이 설정의 직접 증거**가 된다 (최초 차원에서는 부족 전사·수렵민·제의 담당자풍, 무협 차원에서는 무장한 민초·임협풍).
- 소급 정합: 톤앤매너의 "여러 시대·장르가 봉합된 미궁"([디자인_UI/00]), 이미지 프롬프트의 다세계 봉합 벽 — 이미 시각 방향이 이 설정과 일치.
- 현행 해석: 현재 동료 6종(캐스터/오펜더/디펜더/어택커/프리스트/샤먼)과 서양풍 이름 테이블([02 §6])은 **"고대 말기~중세 초기 농경 신앙 차원"**의 첫 세트로 재해석한다. 기존 판금 기사·후기 교회풍 초상은 역할 참고 자료이며 최종 시대 외형은 다시 맞춘다. 샤먼도 현재 범위에 포함되며, 상세 능력치와 스킬 수치만 미결이다.
- 확장 구조: 차원 테마 1개 = {동료 스타일 세트 + 이름 테이블 + 환경 배경 + 괴이(그 차원의 수호자)} — 테마별 세트가 콘텐츠 확장의 단위가 된다. 기획 후보는 **초기 농경 신앙 / 무협 변경 항전 / 일본 신사 토착신 / 현대 경계도시**로 넓게 유지하되, 실제 제작 수는 인력과 아트 리소스에 맞춰 축소할 수 있다.
- 테마 배정 방향: **최초 진입 테마는 고대 말기~중세 초기 농경 신앙 세계로 고정**한다. 추가 테마가 실제로 제작된 이후의 런은 구현된 테마 풀에서 무작위로 배정하는 것을 목표로 한다.
- 파생 원칙: 오프닝에서 동료 배치 보고서를 사용할 경우 사진란은 **공란**으로 둔다. 다만 새 오프닝 핵심은 실패 요원 보고서와 현 플레이어 투입 통보이며, 동료 배치 보고서의 최종 포함 여부는 미결이다.
- ⚠️ 아트 비용 주의: 테마 1개당 `FILTERED` 초상·배경·적 스프라이트 세트가 우선 필요하다. `TRUE_VIEW` 대체 에셋 범위, 추가 테마 수·제작 순서, 랜덤 중복 방지와 가중치는 §5 미결이다.

### 3B-0. 실제 세계 원형과 인게임 표현 층위

§3B-5에 정리한 문화·생활·수호자 설정은 **해당 세계의 실제 기준**이다. 기본 플레이 화면에 실제 세계가 그대로 노출되는 것이 아니라, 탐사국의 재인식 필터가 의미와 외형을 침략자에게 유리하게 왜곡한다.

| 표현 층위 | 플레이어에게 보이는 것 | 제작·사용 기준 |
|---|---|---|
| `TRUE_BASELINE` 실제 원형 | 세뇌가 없을 때 존재하는 정상 사회·주민·수호자·토착신 | 세계관 설정과 진실 시야 디자인의 원본. 일반 런에서는 직접 노출하지 않음 |
| `FILTERED` 기본 인게임 | 사람이 괴이로, 방어시설이 적대 의식장으로, 생활 공간이 버려진 위험 구역으로 보임 | 일반 런의 기본 배경·적·보스·동료 에셋 |
| `LEAK` 인식 누출 | FILTERED 위로 실제 표정·간판 의미·생활 흔적·보호 행동이 순간적으로 겹침 | 오염·회차 단서용 오버레이, 짧은 프레임, 대체 문구 |
| `TRUE_VIEW` 진실 시야 | 괴물화가 해제되고 실제 주민·수호자와 플레이어가 남긴 피해가 드러남 | 재인식 거부·엔딩 게이트·내부 스포일러 장면 |

**공통 왜곡 규칙**

- 사람이 사는 공간은 `폐허·격리구역·적대 거점`으로 보이게 한다.
- 피난·봉쇄·경계 표식은 `제물 의식·감금·공격 준비`로 오독하게 한다.
- 주민의 생활 도구와 방어 장비는 고문 도구·저주 도구·괴이의 신체 일부처럼 과장한다.
- 현지 수호자는 역할과 실루엣을 유지하되 얼굴·행동 목적·상징 의미를 괴물 쪽으로 바꾼다.
- 탐사국이 만든 파괴와 영혼 수탈 흔적은 현지 괴이가 일으킨 재난처럼 보이게 한다.
- 왜곡해도 차원 테마의 시대·재질·문화 실루엣은 식별 가능해야 한다.

**동료 인식 규칙**

- 실제 원형은 해당 세계의 주민·전사·의례 담당자다.
- 기본 인게임에서는 탐사국이 재구성한 `안전한 전투 구현체`로 보이며, 얼굴·이름·개인 흔적이 검열되고 역할 실루엣만 선명해진다.
- LEAK에서는 검열 아래 실제 표정이나 생활복이 한 프레임씩 비치고, TRUE_VIEW에서는 영혼석 파편 안에 원래 주민의 형상이 드러난다.

**리소스 우선 원칙**

- `FILTERED` 세트를 실제 플레이용 기본 에셋으로 먼저 제작한다.
- `TRUE_VIEW`는 동일 구도·실루엣을 재사용하고 보스 대체 외형, 동료 얼굴·초상, 핵심 표식·소품, 색·조명 오버레이부터 교체한다.
- 모든 환경을 완전히 두 벌 제작하는 방식은 기본 전제가 아니다. 엔딩 핵심 장면 외의 전면 교체 범위는 [15 D6](15_미결_안건표.md)에서 결정한다.

### 3B-1. 테마와 무관하게 고정되는 축

차원 테마는 콘텐츠 표현과 일부 전투 변형의 축이며, 코어 규칙을 다시 정의하는 축이 아니다. 아래 항목은 모든 테마에서 동일하게 유지한다.

| 고정 축 | 모든 테마의 공통 계약 |
|---|---|
| 파티·덱 | 파티 1~4명(최대 4인), 동료당 시작 덱 10장, 동료당 손패 슬롯 1칸 |
| 내부 직업 ID | 캐스터·오펜더·디펜더·어택커·프리스트·샤먼은 데이터 연결용 내부 ID로 유지 |
| 역할 가독성 | 딜러·탱커·서포터의 실루엣과 전투 목적은 외형이 바뀌어도 식별 가능해야 함 |
| 전투 문법 | 딜러·탱커·서포터 공용 역할 스택 3종과 배치 순서 기반 자동 행동 유지 |
| 재화 의미 | 영혼석은 런 내 재화, 마석은 반복 런으로 획득해 계정 공용 영구 스탯 강화에 소비하는 영속 재화 |
| 서사 구조 | `FILTERED` 인식과 실제의 이중 해석, 현지 수호자가 괴이로 보이는 구조 유지 |
| UI 의미색 | HP·스트레스·오염·버프·디버프의 공통 의미색은 테마 장식색보다 우선 |

테마에 따라 바꿀 수 있는 축은 동료의 인게임 표시 직업명·외형·이름·문화권, 스킬명·아이콘·VFX, 환경·괴이·음향, 현지 수호자의 정체와 단서 표현이다. 내부 직업 ID는 UI에 그대로 노출하지 않는다. **최초 초기 농경 신앙 테마 고정과 이후 구현 테마 중 랜덤이라는 방향은 확정**했으며, 추가 테마 목록·실제 제작 수·랜덤 규칙·제작 순서와 스킬의 기계적 변형 상한은 [15 D6](15_미결_안건표.md)에서 관리한다.

### 3B-2. 동료 스킬 변형 단계

| 단계 | 허용 범위 | 문서화·검토 기준 |
|---|---|---|
| L1 표현 변형 | 내부 직업 ID와 효과·비용·위력은 같고 표시 직업명·스킬명·아이콘·VFX·설명만 테마에 맞게 변경 | 최초 구현의 확정 계약 |
| L2 역할 등가 변형 | 역할 목적과 비용·위력 예산을 유지하면서 대상·상태 효과·조건을 변경 | 테마 팩 단위 검토와 밸런스 검증 필요 |
| L3 고유 메커니즘 | 스택 종류, 행동 순서, 카드·재화 경제 등 코어 규칙에 영향을 줌 | 별도 시스템 안건으로 승인 후 반영 |

최초 구현에서는 **L1을 현행 계약**으로 사용한다. L2는 제안안, L3는 미결 안건으로 취급한다. 따라서 컨셉 아트와 초기 콘텐츠 문서는 L1을 기준으로 제작하며, L2·L3 효과를 확정 사양처럼 기재하지 않는다.

### 3B-3. 차원 테마 콘텐츠 팩 계약

차원 테마를 추가할 때는 아래 정보를 하나의 콘텐츠 팩으로 작성한다. 이는 내부 빈칸 체크리스트가 아니라, 서사·아트·전투 데이터가 서로 다른 테마를 가리키지 않도록 하는 **공통 명세**다.

| 구성 | 필수 명세 |
|---|---|
| 테마 정체성 | 안정적인 `themeId`, 공개 명칭, `TRUE_BASELINE` 한 줄 정의, `FILTERED` 한 줄 정의, `TRUE_VIEW`에서 드러날 의미 |
| 시각 문법 | 핵심 재질 3종, 대표 장식색 1종, 금지 모티프와 시대 혼합 허용 범위 |
| 환경 | 실제 공간의 용도, `FILTERED` 왜곡 결과, `LEAK`·`TRUE_VIEW`에서 교체할 핵심 표식과 차원 봉합 흔적 |
| 동료 | 실제 출신·역할 실루엣, 이름 규칙, `FILTERED` 검열 방식, `LEAK`·`TRUE_VIEW` 얼굴/초상, 각 스킬의 L1·L2·L3 변형 단계 |
| 적·괴이 | 실제 방어 역할과 지키던 대상, `FILTERED`에서 보이는 괴이 외형과 적대 행동의 오독 방식 |
| 보스 | 현지 사회·신앙에서의 실제 역할, `FILTERED` 괴물 도상, `TRUE_VIEW`에서 실제 정체와 피해가 드러나는 연출 |
| 서사 단서 | T0·T1·T2에서 공개할 정보와 초반에 직접 노출하지 않을 진실 |
| 음향 | 환경·전투·보스 모티프와 다른 테마에서 재사용하지 않을 핵심 음색 |
| 인식 레이어 | `TRUE_BASELINE` 원형, `FILTERED` 기본 에셋, `LEAK` 오버레이, `TRUE_VIEW` 대체 대상 |
| 데이터 연결 | 표시 이름과 분리된 `themeId + roleId + variantId` 식별자 |

현행 초기 농경 신앙 세트는 이 계약을 처음 채우는 기준 예시다. 이후 테마는 첫 세트의 이름과 외형만 교체하는 방식이 아니라, 동일한 공통 명세를 독립적으로 작성해야 한다.

### 3B-4. 메타 성장 연동 안전 원칙

- 마석 메타 성장은 동료·스킬 해금과 분리된 **계정 공용 영구 스탯 강화 축**이다.
- 강화 데이터는 `statUpgradeId`로 식별하고, 테마의 `themeId + roleId + variantId`와 결합하지 않는다.
- 어떤 테마 팩도 마석 강화가 0인 상태에서 기본 런에 진입할 수 있어야 한다.
- 마석 강화는 특정 테마 진입이나 특정 동료 사용에 필요한 조건으로 사용하지 않는다.
- 강화 스탯 목록·레벨당 효과·비용 곡선·최대 레벨·환불 여부는 [15 H1](15_미결_안건표.md)에 남긴다.

##### A-0. 최초 구현 동료 역할 세트

**동료 `FILTERED` 공통 원칙 — 절제된 오버레이 방식**

- 실제 인물의 복식·체형·생활 장비와 기본 실루엣을 그대로 유지한다. 기본 동료 에셋에는 신체 융합·괴물 해부학·비대칭 돌연변이를 사용하지 않는다.
- 정체성 검열은 벗길 수 있는 가면·천·그림자·모자이크 중 하나로 제한한다. 탐사국 표식은 작은 식별 번호표와 소형 청록 영혼석 결합부만 덧붙이며 실제 장비를 다른 무기로 재설계하지 않는다.
- 왜곡의 중심은 관리국식 표시 직업명·스킬명·설명문, 표적선·격리선·원소 흔적 같은 UI·VFX, 제한적인 색보정이다. `TRUE_VIEW`에서는 같은 자세와 실루엣에서 얼굴 검열·번호표·결합부·오버레이만 제거한다.
- 신체 융합과 과도한 괴물화는 적·보스 또는 별도로 명시한 고오염 단계에만 사용한다. 이 원칙은 `FILTERED`와 `TRUE_VIEW`가 동일한 기본 몸체 에셋을 공유하도록 해 제작 부담도 줄인다.

**캐스터 `FILTERED` 외형 — 점토 절기 인장을 쓴 원소술사**

- 빛바랜 직조 망토를 두른 가는 인간 실루엣을 유지해 후열 딜러로 읽히게 한다.
- 얼굴에는 절기·바람·서리·강우를 뜻하는 작은 구멍과 선이 새겨진 **금 간 원형 점토 인장 가면**이 덧씌워진다. 별자리 배열은 가까이 보았을 때만 알아볼 수 있는 보조 문양으로 제한한다. 구멍과 균열 안쪽에서 탐사국의 청록빛이 새어 나오지만, 가면은 얼굴과 융합되지 않은 탈착식 검열물이다.
- 실제 목제 관측봉·청동 고리·매듭끈의 형태와 재질은 유지한다. 불씨·냉기·바람의 원소 무장 인상은 관측봉 주변의 제한적인 VFX와 관리국 UI 설명으로만 만든다.
- 가슴과 관측봉에는 탐사국 식별표와 청록 영혼석 결합부가 덧붙어 현지인이 아니라 전투 구현체처럼 보인다.
- `TRUE_VIEW`에서는 얼굴 가면·식별표·청록 결합부·원소 VFX가 사라지고 평범한 인간 얼굴과 별·바람의 방향을 재던 동일한 관측 도구가 드러난다.
- 마법사 뾰족모자·후기 중세 로브·정밀 천문기계·스팀펑크 톱니는 사용하지 않는다.

인게임 표시 직업명은 **원소술사**를 사용한다. 별자리보다 공격형 캐스터 가독성을 우선하며, 불·냉기·바람 계열 광역 공격과 보호막을 포괄하는 이름으로 운용한다. `캐스터`는 데이터 연결용 내부 ID로만 남는다.

**원소술사 성별·연령 변형**

- 실제 출신은 남성형·여성형 모두 존재하며 연령은 **30~50대의 성인·중년** 범위로 제한한다.
- `FILTERED`에서는 얼굴 인장과 직조 망토가 신체 특징을 가리므로 공용 전투 스프라이트 1종을 사용한다.
- `TRUE_VIEW`에서는 얼굴 인장이 사라지는 장면을 위해 남성형·여성형 얼굴 초상 2종을 제작한다. 연령 차이는 주름·머리색·피로한 눈매의 제한된 변주로 처리하고 별도 연령대 스프라이트를 만들지 않는다.
- 이름과 대명사는 실제 배정된 성별형을 따르며, 전투 기능·스탯·스킬 구성에는 차이가 없다.

**오펜더 `TRUE_BASELINE` 실제 역할 — 큰짐승 사냥꾼**

- 야생림과 경작지 경계에서 멧돼지·늑대 등 큰짐승의 흔적을 읽고, 주민·가축·작물을 보호하는 공동체 사냥 담당자다.
- 긴 사냥창으로 돌진을 받아내거나 한 대상을 고정한 뒤, 무거운 사냥칼로 마무리한다. 여러 적을 제압하기보다 위험한 한 대상을 추적해 결정타를 가하는 오펜더의 단일 강공격 역할과 연결한다.
- 사냥은 생계와 방어를 위한 노동이며 전리품 과시나 쾌락적 살육으로 묘사하지 않는다. 가죽·뼈·고기는 공동체에서 모두 사용한다.
- 디펜더·어택커처럼 전열을 유지하거나 아군을 보호하는 탱커가 아니라, 위험 대상을 빠르게 제거하는 근접 딜러다.

**오펜더 `FILTERED` 외형 — 가죽 봉인 추적자**

- 수선한 가죽 망토는 어깨에 걸친 실제 복식 그대로 유지한다. 신체와 융합하지 않으며 빠르고 날카로운 근접 딜러의 가는 윤곽을 바꾸지 않는다.
- 얼굴에는 꿰맨 가죽 가면과 그 아래 달린 작은 짐승 턱뼈 장식이 덧씌워진다. 둘 다 얼굴을 대체하는 해부학적 변형이 아니라 벗길 수 있는 관리국 검열물이다.
- 실제 긴 사냥창과 흔적 표시용 매듭끈의 형태는 유지한다. 창의 작은 검은 철 보강재·청록 결합부와 관리국 표적선 VFX가 평범한 사냥 도구를 관통 집행 장비처럼 오독시킨다.
- 무거운 사냥칼은 과장된 처형검이 아니라 짧고 두꺼운 마무리용 칼로 유지해 단일 대상 결정타 역할을 드러낸다.
- `TRUE_VIEW`에서는 가죽 가면·뼈 장식·식별표·청록 결합부·표적선이 사라지고, 같은 망토와 사냥창·사냥칼을 든 인간 사냥꾼이 드러난다.
- 거대한 뿔, 해골 투구, 근육질 야만전사, 대형 양손도끼, 전리품을 과시하는 장식은 사용하지 않는다.

**프리스트 `TRUE_BASELINE` 실제 역할 — 성소 치유사**

- 성소 한편에서 약초를 말리고 연고·찜질천을 만들며, 깨끗한 물과 붕대로 환자·부상자·산모를 돌보는 공동체의 치료 담당자다.
- 짧은 기도와 회복 의례를 사용하지만 기적을 과시하는 고위 사제나 교단 성직자가 아니다. 실제 치료는 약초 지식·위생·휴식·공동체 돌봄이 중심이다.
- 단일·전체 회복은 한 사람의 상처를 집중 치료하거나 물·붕대·약포를 여러 사람에게 나누는 행동으로, 공격 기술은 환자를 위협하는 대상을 쫓아내는 성소 방어 행동으로 해석한다.
- 영혼·토착신과 직접 교섭하거나 저주를 다루는 샤먼, 별·바람으로 절기를 관측하는 캐스터와 역할을 분리한다.

**프리스트 `FILTERED` 외형 — 약포 베일과 치료용 천 마스크**

- 실제 성소 치유사의 가벼운 치료복, 약초 꾸러미·연고 단지·약포 천·붕대·나무 물그릇·작은 성소 방울의 형태와 재질을 그대로 유지한다.
- 소박하고 짧은 약포 베일이 머리카락과 이마를 가리고, 약초 얼룩이 밴 치료용 천 마스크가 코와 입을 덮는다. 눈은 베일 아래 좁은 그늘 사이로 보이며 베일과 마스크는 신체와 융합되지 않은 탈착식 검열물이다.
- 약가방 끈에는 작은 탐사국 번호표를, 성소 방울 고리에는 소형 청록 영혼석 결합부를 부착한다. 치료 도구를 기계 장치나 마법 무기로 확대·변형하지 않는다.
- 치료·방어 행동은 관리국식 표시 직업명·스킬명, 치료 대상 프레임·안정화 수치·위협 제거 표식 같은 UI·VFX로 재분류한다.
- `TRUE_VIEW`에서는 약포 베일·천 마스크·번호표·청록 결합부·관리국 오버레이만 사라지고, 같은 치료복과 도구를 지닌 인간 성소 치유사가 드러난다.
- 긴 장례 베일, 후기 교단 복식, 얼굴 전체를 감싼 붕대, 신체 봉합, 기계식 의료 장비는 사용하지 않는다.

인게임 표시 직업명은 **치유사**를 사용한다. 실제 역할인 성소 치유사의 핵심 기능을 숨기거나 과장하지 않고 짧게 줄인 이름이다. 이 직업은 외형과 명칭을 크게 왜곡하는 대신 치료 대상 프레임·안정화 수치·위협 제거 표식, 관리국식 스킬명과 설명문에서 재인식 필터를 드러낸다. `프리스트`는 데이터 연결용 내부 ID로만 남는다.

**치유사 성별·연령 변형**

- 실제 출신은 남성형·여성형 모두 존재하며 연령은 **20~60대 성인·중년·노년 초입** 범위로 제한한다.
- `FILTERED`에서는 짧은 약포 베일과 치료용 천 마스크가 머리·얼굴 특징을 가리므로 공용 전투 스프라이트 1종을 사용한다.
- `TRUE_VIEW`에서는 베일과 마스크가 사라지는 장면을 위해 남성형·여성형 얼굴 초상 2종을 제작한다. 연령 차이는 주름·머리색·손의 약초 얼룩과 피로한 눈매의 제한된 변주로 처리하고 별도 연령대 스프라이트를 만들지 않는다.
- 이름과 대명사는 실제 배정된 성별형을 따르며 전투 기능·스탯·스킬 구성에는 차이가 없다.

**샤먼 `TRUE_BASELINE` 실제 역할 — 영혼 중재자**

- 조상·들판·가정의 작은 영들에게 공동체의 사정을 전하고, 반복되는 악몽·금기 위반·경계의 불안정이 생겼을 때 원인을 듣고 관계를 회복하는 영적 교섭 담당자다.
- 재와 향초 연기, 매듭끈, 작은 조상표, 경계석 가루와 소박한 방울을 사용한다. 영을 지배하거나 소환해 공격하는 전투 마법사가 아니라 말·표식·공물로 양쪽을 중재한다.
- 치유사가 몸의 상처와 질병을 직접 돌본다면 영혼 중재자는 불안·금기·경계 문제를 다룬다. 절기 관측자의 기상·농경 판단과도 구분한다.
- 전투 기능은 **지속 피해·적 디버프·아군 버프의 3축**으로 구성한다. 실제로는 해로운 연결을 묶거나 침입자의 움직임을 경고하고 우호적인 영의 도움을 청하는 매듭·재·연기 의례가 관리국 필터에서 피해·약화·강화 주술로 오독된 것이다. 축별 스킬 개수·상세 효과·수치는 [02](02_동료_적_데이터.md)의 미결 상태를 유지한다.

**샤먼 `FILTERED` 외형 — 잿빛 두건과 매듭 장막**

- 실제 영혼 중재자의 가벼운 복식, 작은 연기 그릇·매듭끈·조상표·경계석 가루 주머니·방울·공물 접시의 형태와 재질을 그대로 유지한다.
- 짧은 잿빛 두건이 머리카락과 머리 윤곽을 가리고, 두건 가장자리의 여러 가닥 매듭끈이 눈과 코 앞에 장막처럼 늘어진다. 입은 드러내 인간형을 유지하며 두건과 장막은 신체와 융합되지 않은 탈착식 검열물이다.
- 재 주머니에는 작은 탐사국 번호표를, 연기 그릇 가장자리에는 소형 청록 영혼석 결합부를 부착한다. 매듭끈을 촉수로, 연기를 생체 기관이나 거대한 영체로 바꾸지 않는다.
- 영적 중재 행동은 관리국식 표시 직업명·설명문, 구속선·상태 기록·지속 피해 계수 같은 UI·VFX로 적대적 약화 주술처럼 재분류한다.
- `TRUE_VIEW`에서는 잿빛 두건·매듭 장막·번호표·청록 결합부·관리국 오버레이만 사라지고, 같은 복식과 의례 도구를 지닌 인간 영혼 중재자가 드러난다.
- 거대한 토템, 짐승 해골 투구, 뿔, 촉수형 매듭, 얼굴과 붙은 목패, 과도한 유령 군집은 사용하지 않는다.

인게임 표시 직업명은 **주술사**를 사용한다. 실제로는 영들과 공동체 사이의 관계를 회복하던 중재자지만, 재인식 필터와 탐사국 분류는 매듭·재·연기 의례를 지속 피해·적 약화·아군 강화 전투 주술로 오독한다. 혼합형 서포터가 즉시 읽혀야 하며 `샤먼`은 데이터 연결용 내부 ID로만 남는다. 축별 스킬 개수·상세 효과·비용·수치는 아직 확정하지 않는다.

**주술사 성별·연령 변형**

- 실제 출신은 남성형·여성형 모두 존재하며 연령은 **20~60대 성인·중년·노년 초입** 범위로 제한한다.
- `FILTERED`에서는 잿빛 두건과 매듭 장막이 머리·얼굴 특징을 가리므로 공용 전투 스프라이트 1종을 사용한다.
- `TRUE_VIEW`에서는 두건과 장막이 사라지는 장면을 위해 남성형·여성형 얼굴 초상 2종을 제작한다. 연령 차이는 주름·머리색·재가 밴 손과 침착한 눈매의 제한된 변주로 처리하고 별도 연령대 스프라이트를 만들지 않는다.
- 이름과 대명사는 실제 배정된 성별형을 따르며, 추후 확정할 전투 기능·스탯·스킬 구성에는 차이를 두지 않는다.

**주술사 전투 구조 — 3축 혼합형**

- 필수 기능 범주는 **지속 피해 / 적 디버프 / 아군 버프** 3종이다.
- 세 범주를 모두 정식 스킬 구성에 포함하되, 범주별 스킬 개수나 동일 범주의 중복 편성 수는 아직 정하지 않는다.
- 아군 버프 축의 핵심 기능은 **대상 동료의 다음 행동 위력 강화**다. 다음 행동에서 발생하는 공격·실드·회복 수치를 모두 강화 대상으로 삼되 강화율·대상 범위·버프 소모 시점은 아직 정하지 않는다.
- 적 디버프 축의 핵심 기능은 **대상 적의 다음 공격 위력 감소**다. 매듭으로 힘을 묶는 표현을 사용하되 감소율·대상 범위·공격으로 인정하는 행동·디버프 소모 시점은 아직 정하지 않는다.
- 지속 피해 축은 **같은 종류끼리도 상한 없이 중첩할 수 있다**. 서로 다른 종류 역시 한 대상에게 함께 공존하며 턴 종료에 모든 지속 피해를 처리한다. 같은 종류도 적용할 때마다 **독립 인스턴스**로 생성하며, 각 인스턴스는 해당 스킬의 고정 틱 피해값과 남은 틱 횟수를 따로 보유하고 개별 만료한다. 따라서 피해를 하나로 합산하거나 지속시간을 공유하지 않으며, 카드 비용·사용 기회·개별 만료 외에 종류별 또는 대상별 강제 상한을 두지 않는다.
- 지속 피해 틱은 **아군과 적의 행동이 모두 끝난 전투 턴 종료 시점**에 일괄 처리한다. 새로 부여된 지속 피해도 **부여된 같은 전투 턴의 종료 시점부터 첫 틱**이 발생한다.
- 카드와 상태 툴팁의 `지속 N턴`은 적용 턴 종료의 첫 틱을 포함한 **총 N회 피해**를 뜻한다. 각 틱을 처리한 뒤 남은 턴을 1씩 줄이므로 남은 턴 표시는 남은 틱 횟수와 항상 같다.
- UI에서는 같은 종류의 독립 인스턴스를 **종류별 아이콘 하나로 묶고**, 아이콘에 인스턴스 수와 다음 틱 시점에 들어갈 총피해를 표시한다. 툴팁에서는 각 인스턴스의 고정 피해와 남은 틱을 확인한다. 아이콘 내부 배치와 툴팁 형식은 제작 단계에서 확정한다.
- 이 단계에서는 주술사의 전투 개념 명세를 완료한다. 구체 상태이상, 대상 범위, 스킬별 지속 턴·고정 틱 피해값, 버프·디버프의 세부 소모 규칙, 비용·위력, 시그니처 스킬과 UI 세부 배치는 추후 설계와 플레이테스트에서 확정한다.
- 순수 DoT 딜러나 순수 행동 제어 캐릭터로 고정하지 않으며, 세 축 중 하나의 개수를 미리 우세하게 배정하지 않는다.

##### A-1. 최초 구현 공간 흐름

탐사국은 지정 좌표의 토착신을 **선발 조사대를 전멸시키고 차원 봉합을 방해하는 최상위 괴이**로 규정한다. 플레이어는 주민을 추격하는 것이 아니라 이 좌표를 향해 `야생림 → 협곡 → 경작지 → 성소` 순서로 이동하며, 현지인과의 전투는 그 과정에서 발생하는 침략 행위다.

| 공간 | `TRUE_BASELINE` 실제 원형 | `FILTERED` 기본 인게임 | 전투·이벤트 역할 | 실제를 암시하는 단서 |
|---|---|---|---|---|
| 야생림 진입부 | 마을에서 멀리 떨어진 채집 원정지. 플레이어의 균열 진입이 작은 분화구와 검게 탄 나무를 남김 | 숲은 비교적 정상으로 보이지만, 균열이 만든 피해는 토착신의 오염 흔적으로 안내됨 | 첫 전투는 채집민에 대응하는 고블린만 등장 | 전투 후 찢어진 바구니에서 평범한 약초·열매·땔감이 쏟아짐 |

##### A-3. 어린 토착신과 보스전

- 실제 토착신은 해진 의례복과 짚 망토를 두르고 작은 수확 낫을 든 **농촌 아이 형상**이다. 외형은 연약하지만 눈빛과 말투에는 오랜 세월의 피로가 남아 있다.
- 토착신은 즉시 공격하지 않고 주민들 앞을 막아선 뒤, 지치고 절박한 말투로 돌아가라는 마지막 기회를 준다. `FILTERED`에서는 이 경고가 포효·저주·섬멸 선언으로 들린다.
- `FILTERED` 보스는 거대한 허수아비형 `거두는 자`다. 작은 낫은 거대한 사신의 낫으로, 보호 자세는 공격 자세로 과장된다.
- 보스 체력 50%에서 `수확`을 사용할 때, 거두는 자의 내부에 작은 낫을 든 어린 신의 실루엣이 한 프레임 겹치는 `LEAK`를 표시한다.
- 일반 승리에서는 어린 신의 영혼 전체가 영혼석으로 추출된다. 유혈 없이 몸이 마른 곡식과 빛의 입자로 무너지며, 성소 일부만 붕괴하고 자연은 즉시 말라 죽지 않는다.
- 실제로는 피난실의 주민들이 나와 어린 신의 흔적을 수습하고 애도한다. `FILTERED`에서는 주민이 완전히 사라지고 비어 있는 둥지만 남으며, 탐사국 UI가 `핵심 개체 제거 완료`를 표시한다.

```text
└── [누르지 않는다] ── 재인식이 꺼진 시야로 보스 스테이지 진입
        ↓
    **해당 회차의 보스**가 괴물이 아닌 본모습으로 —
    **자신의 세계에 대한 자비를 빈다**
    (고정 수확자 아님 — 그 런의 차원 테마(§3B)에 배정된 보스.
     모든 보스 = 자기 차원의 수호존재이므로 누구든 이 장면이 성립한다)
        ↓
    ┌── [전투를 이어간다] → 엔딩 A (알고도 거둔 자)
    └── [전투를 포기한다] → 엔딩 B (은퇴 — 개인적 해방)
```

**설계 의도**
- 그동안 매번 눌러온 [동의] 버튼(10 §3-1 "순응의 체험")이 쌓은 관성이 그대로 최종 선택의 무게가 된다 — 시스템 반복이 곧 서사 빌드업.
- 재인식이 꺼진 상태의 보스전이므로, 이 진입에서만 **동료 외형(오염 단계)·보스 외형·텍스트가 `TRUE_VIEW`로 표시**된다 — §3B 차원 테마와 §2 층위표의 회수 지점.
- "전투를 포기한다"가 게임오버가 아니라 **엔딩**이라는 역전 — 이기는 것이 항복이고, 지는 것이 해방.

**하위 미결**: 해금 조건, 엔딩 A/B의 세부 내용·연출·명칭, 거부 진입 보스전 밸런스, 보스별 자비 연출, 포기 선택지 노출 시점과 포스트엔딩 배치는 [15 D](15_미결_안건표.md)에서 관리한다.

## 4. 기존 텍스트 재독해 (설정 확정으로 이중 의미가 성립하는 예)

> 이미 작성된 문구들이 진실 층위에서 다시 읽힌다 — 후반 회차 플레이어의 "두 번째 독해"를 위한 자산. 신규 텍스트 작성 시에도 이 이중성 기준을 따른다.

| 기존 텍스트 | 표면 독해 | 진실 독해 |
|---|---|---|
| "저것들은 당신을 적으로 보지 않는다. 아직 오지 않은 동료로 본다." (07 §2-1) | 괴이의 기괴한 인식 | 침략군도 언젠가 이 차원에 남는다 / 수탈당한 영혼의 동류가 된다 |
| "출입 금지. 현실 안정화 구역." / "안정화가 아니라, 가림막이다." (00 §8-1) | 위험 구역 경고 | 재인식장치의 가동 구역 — 보이면 안 되는 것을 가리는 곳 |

## 5. 남은 미결 (이 설정 위에서 결정할 것)

**확정된 기준**
- 동료의 실체는 수탈된 현지 영혼의 재구성이다. 00 §7의 `탐사자의 잔재`는 표면 층위 설명으로만 유지한다.
- 자각에서 이탈까지의 구조는 `재인식 거부 → 진실 시야 보스전 → 자비를 비는 보스 → 전투 지속/포기 분기`다.
- 주인공의 구체적인 순번은 정하지 않는다. 누적 수치는 플레이어 기억보다 크다는 모호성만 유지한다.

추가 차원 테마의 실제 제작 수·랜덤 규칙·스킬 변형 상한, 스트레스의 설정상 재해석과 수확자 외 괴이의 토착 정체는 [15 D](15_미결_안건표.md)에서 관리한다.
