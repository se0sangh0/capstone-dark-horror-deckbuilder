## 1. 핵심 반전 한 줄

> **당신은 차원을 지키는 조사관이 아니다. 남의 차원에서 영혼을 수탈해 오는 침략군이다.**

## 2. 진실 층위표 (표면 인식 vs 실제)

플레이어(와 모든 요원)는 **세뇌된 표면 인식**으로 게임을 시작한다. 게임의 모든 텍스트·UI는 기본적으로 표면 층위로 쓰고, 진실은 균열(오염·암시 텍스트)로만 샌다.

| 요소 | 표면 (세뇌된 인식) | 실제 |
|---|---|---|
| 균열 | 비현실이 침범한 이상 지대 | **원래 존재하던 타 차원과 연결된 통로** — 새 차원이 아니다 |
| 탐사자(주인공) | 차원을 지키는 이레귤러 — 괴이를 격리하는 조사관 | **그 차원 입장에서 외세의 침략군** |
| 영혼석 | 회수 대상 자원 | **그 차원의 영혼을 수탈한 것** |
| 영혼석의 용도 | 상납 → 마석 보상 | **재인식장치·세뇌장치의 동력원** — 수탈이 세뇌를 굴리고, 세뇌가 수탈을 지속시키는 자기 순환 |
| 마석 | 영혼석과 다른 상위 재화 | **구분은 유저 UI상의 것일 뿐, 실제 단위는 동일하게 영혼석** — 탐사국이 수탈물 일부를 "보상"으로 돌려주며 재화처럼 보이게 한 것 |
| 괴이 | 격리 대상 위협 | **그 차원을 지키는 존재들** — 침략군에 맞서는 수호자 |
| 수확자(거두는 자) | 최상위 위험 개체 | **농경사회의 토착신** — 재인식장치가 꺼진 눈으로 보면 신앙의 대상. 낫·추수밭·까마귀는 괴물의 상징이 아니라 풍요신의 도상 |
| 동료 | 전투 구현체 — 탐사자의 잔재 (구 A안) | **수탈된 현지 영혼이 영혼석에 반응해 재구성된 것** (2026-07-27 확정) — 플레이어는 빼앗은 영혼을 병사로 부리고 있다 |
| 브리핑 | 복귀 절차 | 기억 교정 (기존 확정 유지) |
| 교회 | 균열 내 안식처 | **❓ 맥거핀 — 답을 정하지 않는다 (확정)**. 미등록 구조물이라는 위화감만 유지, 운영 주체는 팀도 확정하지 않음 |

## 3. 시스템과의 정합 (설정이 기존 시스템을 설명하는 지점)

- **재인식 장치([10])**: 단순 오염 리셋 장치가 아니라 **세뇌 유지 인프라의 말단**. 오염도 = 세뇌가 벗겨져 실제가 보이기 시작하는 정도 → 동료 모자이크(1단계)는 "검열", 얼굴 가죽(2단계)은 세뇌 아래의 실체에 근접. 10 문서는 백로그지만 설정상 핵심 장치이므로, 구현 전에도 **텍스트 암시로는 존재**한다.
- **영혼석 경제**: 회수 → 상납 → 마석 보상 루프 전체가 수탈 파이프라인. "마석=영혼석" 확정으로 [05 §5](05_백로그.md)의 "마석 치환 비율" 미결에 서사적 답이 생김 (치환이 가능한 이유: 애초에 같은 것).
- **보스전 배경**([디자인_UI/01 §3] 지하의 마른 추수밭 + 무너진 예배당): 토착신 설정과 정확히 일치 — 수확자의 영역은 전장이 아니라 **버려진 신전이자 농지**.
- **동료 사망 시 "균열이 울었다"**(07 §3-1 희귀 문구): 균열 쪽 존재들이 동료(구현체)와 무관하지 않다는 기존 암시가 설정과 연결됨.

## 3B. 런 차원 테마 (2026-07-27 확정 방향)

**런마다 균열이 연결되는 차원(테마)이 다르다** — 중세 차원이면 중세풍, 무협 차원이면 무협풍으로 **동료·환경·괴이의 스타일이 그 차원을 따른다.**

- 서사 정합: 동료 = 그 차원에서 수탈된 현지 영혼이므로, **동료의 외형·이름이 차원 테마를 따르는 것이 설정의 직접 증거**가 된다 (중세 차원에서 얻은 동료는 기사풍, 무협 차원에서는 협객풍).
- 소급 정합: 톤앤매너의 "여러 시대·장르가 봉합된 미궁"([디자인_UI/00]), 이미지 프롬프트의 다세계 봉합 벽 — 이미 시각 방향이 이 설정과 일치.
- 현행 해석: 현재 동료 5종(캐스터/오펜더/디펜더/어택커/프리스트)과 서양풍 이름 테이블([02 §6])은 **"중세(판타지) 차원" 테마 세트**로 재분류.
- 확장 구조: 차원 테마 1개 = {동료 스타일 세트 + 이름 테이블 + 환경 배경 + 괴이(그 차원의 수호자)} — 테마별 세트가 콘텐츠 확장의 단위가 된다. 테마 후보: **중세(현행) / 무협 / 일본식 / 현대식** (2026-07-27 언급). 무협 세트(샤먼 백로그와 결합 후보) 등은 정식 버전 스코프.
- 파생 확정: 오프닝 동료 배치 보고서(11 S02)의 사진란은 **공란**(B안) — 테마 배정 전 시점에 특정 초상을 노출하지 않기 위함이기도 함.
- ⚠️ 아트 비용 주의: 테마 1개당 초상·배경·적 스프라이트 세트가 필요 — 테마 수·순서는 §5 미결.

## 3C. 엔딩 분기 구조 (2026-07-27 확정)

자각 → 이탈은 별도 컷씬이 아니라 **재인식 장치([10])의 선택지 하나가 열리는 것**으로 구현한다.

```text
[N번째 회차 — N 미정] 재인식 장치 발동
   ↓
기존: [동의 버튼]만 존재 ("거부 항목은 존재하지 않는다")
   → 이번엔 처음으로 [누르지 않는다] 선택지가 노출된다
   ↓
┌── [동의] ──────────── 기존 루프 계속 (언제든 되돌아갈 수 있음)
│
└── [누르지 않는다] ── 재인식이 꺼진 시야로 보스 스테이지 진입
        ↓
    **해당 회차의 보스**가 괴물이 아닌 본모습으로 —
    **자신의 세계에 대한 자비를 빈다**
    (고정 수확자 아님 — 그 런의 차원 테마(§3B)에 배정된 보스.
     모든 보스 = 자기 차원의 수호존재이므로 누구든 이 장면이 성립한다)
        ↓
    ┌── [전투를 이어간다] → 엔딩 A (알고도 거둔 자)
    └── [전투를 포기한다] → 엔딩 B (은퇴 — 개인적 해방)
```

**설계 의도**
- 그동안 매번 눌러온 [동의] 버튼(10 §3-1 "순응의 체험")이 쌓은 관성이 그대로 최종 선택의 무게가 된다 — 시스템 반복이 곧 서사 빌드업.
- 재인식이 꺼진 상태의 보스전이므로, 이 진입에서만 **동료 외형(오염 단계)·보스 외형·텍스트가 진실 층위로 표시**된다 — §3B 차원 테마와 §2 층위표의 회수 지점.
- "전투를 포기한다"가 게임오버가 아니라 **엔딩**이라는 역전 — 이기는 것이 항복이고, 지는 것이 해방.

**하위 미결**: 해금 조건, 엔딩 A/B의 세부 내용·연출·명칭, 거부 진입 보스전 밸런스, 보스별 자비 연출, 포기 선택지 노출 시점과 포스트엔딩 배치는 [15 D](15_미결_안건표.md)에서 관리한다.

## 4. 기존 텍스트 재독해 (설정 확정으로 이중 의미가 성립하는 예)

> 이미 작성된 문구들이 진실 층위에서 다시 읽힌다 — 후반 회차 플레이어의 "두 번째 독해"를 위한 자산. 신규 텍스트 작성 시에도 이 이중성 기준을 따른다.

| 기존 텍스트 | 표면 독해 | 진실 독해 |
|---|---|---|
| "저것들은 당신을 적으로 보지 않는다. 아직 오지 않은 동료로 본다." (07 §2-1) | 괴이의 기괴한 인식 | 침략군도 언젠가 이 차원에 남는다 / 수탈당한 영혼의 동류가 된다 |
| "출입 금지. 현실 안정화 구역." / "안정화가 아니라, 가림막이다." (00 §8-1) | 위험 구역 경고 | 재인식장치의 가동 구역 — 보이면 안 되는 것을 가리는 곳 |
| "그 낫은 수확용이 아니다. 거둔다는 건, 끝이 아니라 다시 심는다는 뜻이다." (07 §2-4) | 보스의 위협 | 토착신의 본질 — 순환과 풍요 |
| "영혼석 상납은 인류의 의무." (00 §8-1 칠판) | 선전 문구 | 수탈의 제도화 |
| "까마귀가 운다. 숫자를 세는 울음이다." (07 §5) | 불길한 연출 | 거둬간 것(빼앗긴 영혼)의 수를 세고 있다 |
| 보고서의 "회수량: 정상" (12 §3) | 실적 보고 | 수탈량 검수 |

## 5. 남은 미결 (이 설정 위에서 결정할 것)

**확정된 기준**
- 동료의 실체는 수탈된 현지 영혼의 재구성이다. 00 §7의 `탐사자의 잔재`는 표면 층위 설명으로만 유지한다.
- 자각에서 이탈까지의 구조는 `재인식 거부 → 진실 시야 보스전 → 자비를 비는 보스 → 전투 지속/포기 분기`다.
- 주인공의 구체적인 순번은 정하지 않는다. 누적 수치는 플레이어 기억보다 크다는 모호성만 유지한다.

런 차원 테마 상세, 스트레스의 설정상 재해석과 수확자 외 괴이의 토착 정체는 [15 D](15_미결_안건표.md)에서 관리한다.

## 6. 노출 정책 (스포일러 관리)

1. **인게임**: 진실은 직접 서술하지 않는다 — 기존 원칙(정답이 아니라 의심의 잔상) 유지. 회차가 쌓일수록 §4의 이중 의미가 "두 번째 독해"로 열리는 구조.
2. **발표/공개 자료**: 표면 층위까지만 — "다크 호러 세계관, 조사관의 루프, 위화감의 축적". 반전 자체는 "숨겨진 진실이 설계되어 있다" 수준으로만 언급.
3. **팀 내부**: 신규 텍스트·이벤트·적 작성자는 이 문서를 먼저 읽고, 표면/진실 이중 의미가 성립하게 쓴다.
4. 이 문서는 README 문서 지도에 **"서사 설정(내부)"로만 표기**하고 내용 요약을 싣지 않는다.
