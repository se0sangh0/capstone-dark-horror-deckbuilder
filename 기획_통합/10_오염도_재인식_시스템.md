## 1. 정의 · 위상

**오염도**는 스트레스와 구분되는 **런 단위 누적 재화**다.

| | 스트레스 | 오염도 |
|---|---|---|
| 귀속 | 동료 개인 (0~100) | **플레이어(런) 공용** (0~3) |
| 의미 | 몸과 정신이 망가진다 | **인식과 존재가 오염된다** |
| 해소 | 화톳불/교회/승리 회복 | 자연 회복 없음 — **재인식 장치 강제 리셋만** |
| 임계 | 100 = 패닉 (전투 내) | **3 = 강제 이벤트** (노드 레벨) |

- 획득: 텍스트 이벤트의 특정 선택지(현재 EVT-18/19, 각 +1). 향후 괴이 스킬·오브제 코스트로 확장 가능(§8).
- 상한: 3 도달 즉시 강제 이벤트 예약 — 초과 적립 없음.

## 2. 시각 단계 (동료 외형 변화)

오염도가 오를수록 **동료 일러스트(초상/전투 카드)가 변형**된다. 플레이어에게 수치보다 먼저 "무언가 잘못되고 있다"를 시각으로 전달하는 장치.

| 오염도 | 동료 외형 | 의도 |
|---|---|---|
| 0 | 정상 | — |
| 1 | 동료 일러스트에 **모자이크** 처리 (부분/약하게) | 인식이 흐려지기 시작 |
| 2 | **얼굴 가죽** — 이목구비가 지워지고 맨가죽만 남은 얼굴 | 구현체의 '얼굴'이 인식에서 벗겨짐 |
| 3 | (강제 이벤트 발동 — §3) | — |

- 서사 정합: 동료는 구현체([00 §7])다. 오염도는 **탐사국이 걸어둔 "동료를 사람으로 인식하게 하는 암시"가 벗겨지는 정도** — 오염될수록 플레이어의 눈에 구현체의 실제에 가까운 모습이 보인다. 모자이크는 시스템(탐사국)의 검열 연출로 읽힌다.
- 구현: 초상 위 셰이더/오버레이 2종 (모자이크 / 얼굴 마스킹). 원본 일러스트 교체 없이 레이어로 처리.
- ⚠️ 확인 필요: "얼굴 가죽"의 구체 비주얼 (이목구비 삭제 vs 가죽 질감 오버레이) — 기획자 컨펌.

## 3. 강제 이벤트 — 재인식 장치 노드

오염도 3 도달 시, **다음에 진입하는 노드가 무엇이든 "재인식 장치" 노드로 교체**된다 (전투/화톳불/보스 예외 여부는 §8 미결).

### 3-1. 연출 시퀀스

```text
[노드 진입]
   ↓
구둣발 소리 (가까워짐) — SFX 신규
   ↓
화면 암전
   ↓
붉은 배경 + 검은 음영의 캐릭터 (정체 불명 — 탐사국 요원 암시)
   ↓
[버튼] 입력 대기 — 플레이어가 직접 눌러야 진행 (순응의 체험)
   ↓
오염도 0 리셋 + 동료 외형 정상화
   ↓
노드맵 복귀 (해당 노드는 소모됨)
```

- 검은 음영 캐릭터는 대사 없음(또는 최소한의 한 줄 — §5 텍스트 초안). 정체는 끝까지 밝히지 않는다.
- **버튼을 플레이어가 누르게 하는 것이 핵심** — 기억 교정을 "당하는" 게 아니라 "스스로 수락"하게 만들어, 후반 자각 플롯([00 §6-3])의 죄책감 재료로 쌓는다.
- 🔴 이 [동의] 버튼은 특정 회차에 **[누르지 않는다] 선택지가 처음 열리며 엔딩 분기의 관문**이 된다 — 구조는 [13 §3C](13_서사_설정_확정.md) (내부 문서) 확정. 본 시스템 착수 시 함께 구현 범위 판단.

### 3-2. 리셋 페널티 — 보상 감소

리셋될 때마다 **이후 런의 보상이 감소**한다 (누적).

| 런 내 리셋 횟수 | 보상 감소 (제안값) |
|---|---|
| 1회 | 이후 영혼석·마석 보상 −10% |
| 2회 | −25% |
| 3회~ | −40% |

> ⚠️ 감소율은 제안값 — 런 경제([03 §3]) 기준 밸런스 테스트 필요. 감소 대상 범위(영혼석만 vs 마석 포함)도 §8 미결.

### 3-3. 오버플로우 에러 — 강제 클리어

**한 노드 내에서 리셋이 3회 이상** 진행되면:

- 다이제틱 **"OVERFLOW ERROR"** 연출 (시스템 붕괴 — 화면 글리치/에러 텍스트)
- 해당 노드는 **강제 클리어 처리** (전투 중이면 전투 종료, 보상은 §3-2 감소율 적용)

> 서사 의도: 재인식(교정)을 한 자리에서 반복하면 시스템 쪽이 먼저 한계에 도달한다 — "관리하는 쪽도 완벽하지 않다"는 균열의 순간. 탐사국 시스템의 실체를 노출하는 희귀 연출로, 다회차 떡밥 가치가 높다.
> ⚠️ **성립 조건 공백**: 현재 오염도 획득원은 이벤트 노드 선택지(+1)뿐이라 "한 노드 내 리셋 3회"(= 노드 안에서 오염도 +9)가 도달 불가능. **전투 중 오염도를 올리는 괴이**(08 §3 신규 적 확장 시) 또는 노드 내 반복 획득원이 생겨야 유효해지는 규칙 — 선행 콘텐츠와 함께 활성화 (§8).

## 4. 루프 내 위상 (요약 다이어그램)

```text
이벤트 선택 (오염도 +1) ──> 1: 모자이크 ──> 2: 얼굴 가죽 ──> 3: 임계
                                                              ↓
                              다음 노드 → [재인식 장치]로 교체
                                                              ↓
                          구둣발 → 암전 → 붉은 화면 → [버튼]
                                                              ↓
                          오염도 0 / 외형 정상화 / 보상 −N% 누적
                                                              ↓
                          (한 노드 내 3회 반복 시 OVERFLOW → 강제 클리어)
```

- 전략적 의미: 오염도는 **"공짜보다 좋은 선택지"의 숨은 가격**이다. 이벤트에서 오염도 선택지가 즉물적으로 이득이어도, 쌓이면 노드 하나를 재인식에 빼앗기고 보상이 깎인다 → 리스크-리턴 저울에 장기 축 추가.

## 5. 텍스트 초안 (07 연계 — 확정 시 [07_서사_텍스트_풀](07_서사_텍스트_풀.md)로 이관)

**오염도 상승 시 (1회 표시)**
1. (1 도달) "동료의 얼굴이 잠시 흐릿했다. 눈을 비비자 돌아왔다. 비빈 건 눈인데."
2. (2 도달) "동료가 웃었다. 어디로 웃었는지는, 보이지 않았다."

**재인식 장치 — 진입/버튼/완료**
1. (구둣발) "…구둣발 소리. 이 구역에, 당신들 말고는 없어야 한다."
2. (붉은 화면 — 버튼 위) "재인식 절차를 시작합니다. 동의 버튼을 누르십시오. *(거부 항목은 존재하지 않는다.)*"
3. (완료) "재인식 완료. 동료들의 얼굴이 또렷하다. 처음부터 그랬던 것처럼."

**OVERFLOW ERROR**
1. "OVERFLOW ERROR — 재인식 한도 초과. 해당 구역 기록을 폐기합니다." / 화면 구석, 지워지다 만 한 줄: "…폐기된 기록은 어디로 가는가"

## 6. 데이터 / 구현 훅 (추정)

| 항목 | 내용 |
|---|---|
| 오염도 값 | 런 상태 int (0~3), `ResetRunState()` 시 0 초기화 |
| 리셋 카운트 | 런 단위 int (보상 감소율 계산) + 노드 단위 int (오버플로우 판정) |
| 외형 오버레이 | 동료 초상 위 모자이크/얼굴 마스킹 레이어 2종 — 좌패널·전투 카드·파티 편집 전 노출처 적용 |
| 노드 교체 | `NodeSystem` 진입 분기 — 오염도 3이면 타입 무시하고 재인식 장치 뷰 |
| 연출 | 암전+붉은 배경 전용 패널 (BattleResultScreen 스타일 재사용 가능) + 구둣발 SFX ([03 §5 오디오 표]에 SfxId 추가 필요) |
| 보상 감소 | 영혼석/마석 지급부에 배율 적용 |

## 7. 다른 시스템과의 연결

- **획득처**: [06 EVT-18/19](06_이벤트_노드.md) 각 +1. 이벤트 신규 작성 시 "오염도 +1" 선택지는 §4 전략 의미를 고려해 **즉시 이득이 확실한 선택지에만** 붙인다.
- **적 확장**: [08 §3] 신규 괴이 중 "오염도를 올리는 적"이 생기면 §3-3 오버플로우 규칙이 활성화됨 — 적 씨앗 작성 시(08 §3 A안 노트) 후보로 고려.
- **서사**: [00 §6] 기억 교정·가스라이팅 플롯의 **시스템화** — 텍스트로만 암시하던 것을 플레이어가 버튼으로 체험.

## 8. 미결 관리

얼굴 가죽 비주얼, 보스 노드 교체 예외, 보상 감소율·대상, 오버플로우 성립 조건, 오염도 표시 방식과 리셋 페널티 서사는 백로그 착수 시 [15 G](15_미결_안건표.md)에서 결정한다.
