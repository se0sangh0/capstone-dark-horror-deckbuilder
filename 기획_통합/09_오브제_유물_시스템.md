## 1. 개요 · 위상

**오브제**는 엘리트 처치로 얻는 **플레이어 귀속 유물**이다. 전투마다 덱의 **랜덤 카드 1장에 부착**되어, 그 카드를 플레이하는 순간 부가 효과를 발동한다. 전투가 끝나면 부착이 풀리고, 다음 전투에서 다시 무작위 카드에 붙는다.

### 1-1. 기존 시스템과의 차이 (왜 카드가 아니라 오브제인가)

| | 08 §6-2 보상 카드 (기각) | **본 문서 오브제** |
|---|---|---|
| 덱 변화 | 덱에 새 카드 **추가** (덱 비대화) | 덱 크기 불변, 기존 카드에 **효과만 부착** |
| 귀속 | 카드 = 덱 소유 | **플레이어(런) 귀속** — 동료 사망/교체 무관 |
| 부여 대상 | — | 동료가 아니라 **랜덤 카드**에 매 전투 재배정 |
| 스택 차별점 | 카드 종류 늘어 희석 위험 | 카드 3종 체계 **유지** |
| 획득 | 전투마다 3택1 | **엘리트 10% 드롭** (희소) |

> **마석 시그니처 패시브([03 §4-2](03_노드_용병소_보상_메타.md))와의 구분**: 마석 패시브는 **동료**에 붙는 영구 상시 능력(런 시작 시 배정). 오브제는 **플레이어**에 붙어 **덱의 카드**를 통해 발동하는 전투 단위 효과. 귀속 대상·발동 방식·획득처가 모두 다르다.

## 2. 코어 메커니즘

### 2-1. 라이프사이클

```text
[엘리트 처치] ──10%──> [오브제 획득] ── 플레이어 보관함에 누적
                                         │
       ┌─────────────────────────────────┘
       ▼
[전투 진입 · 덱 생성] ── 보유 오브제 각각을 덱의 서로 다른 랜덤 카드 1장에 부착
       │                (부착 카드는 시각 마킹 — 레퍼런스: 하스스톤 주문제작카드, 01 §1-5)
       ▼
[부착 카드 플레이] ── 카드 기본 스택 생성 + 오브제 효과 1회 발동
       ▼
[전투 종료] ── 부착 전면 해제
       ▼
[다음 전투] ── 덱 재생성 시 다시 랜덤 카드에 재부착 (직전과 다른 카드일 수 있음)
```

### 2-2. 부착 규칙

- 부착은 **덱 생성 시점**(전투 진입, 배치 확정 후 덱 자동 등록 — [01 §2-2](01_전투_카드_스트레스.md))에 1회 실행.
- 오브제 N개 보유 시 **서로 다른 카드 N장**에 각각 1개씩 부착(한 카드에 중복 부착 없음). 덱 40장이므로 N은 항상 덱 크기 미만.
- 부착 카드가 **어느 역할(딜러/탱커/서포터)인지는 무작위**. 효과는 기본적으로 스택 타입과 무관하게 작동하도록 설계(일부 오브제는 "부착된 스택 타입"을 조건으로 삼음 — §5 참조).
- 부착 카드는 UI에서 구별 표시(마킹 아이콘 + 툴팁으로 오브제 효과 노출).

### 2-3. 발동 규칙

- 부착 카드가 **플레이되는 순간** 효과 발동. 카드의 기본 동작(성향 기반 스택 생성)은 그대로 유지되고, 그 **위에** 오브제 효과가 얹힌다.
- 발동은 **전투당 부착 1장 = 최대 1회**(그 카드를 뽑아 써야 발동). 뽑지 못하거나 안 쓰면 그 전투엔 미발동.
- 여러 오브제 보유 시 각 부착 카드가 각자 발동.

> ⚠️ **발동 신뢰도 이슈**: 마킹 카드가 40장 중 1장이라 짧은 전투(고블린×2, ~3턴)에선 못 뽑을 수 있음. → §7 미결에 "오프닝 손패 보장 배치" 등 튜닝 옵션.

### 2-4. 귀속 · 지속

- 오브제는 **런(플레이어)에 귀속**. 부착된 카드를 만든 동료가 사망/교체되어도 오브제는 유지되고, 다음 전투에 남은 덱의 다른 카드로 재부착.
- 파티 전멸(런 실패) 시: [03 §4-1 런 루프](03_노드_용병소_보상_메타.md)의 리셋 대상 — **소멸**(마석은 유지, 오브제는 미계승). 단 보스 클리어 시 "계승" 선택분은 예외(§3).

## 3. 보스 클리어 시 선택 (마석 교환 vs 계승)

보스 노드 클리어 후 런 루프([03 §4-1](03_노드_용병소_보상_메타.md)) 진입 **전**, 보유 오브제마다 택1:

| 선택 | 효과 | 비고 |
|---|---|---|
| **① 마석 교환** | 오브제 → 마석 N개(§5 개별 교환가) 즉시 환전, 오브제 소멸 | 영구 재화([03 §4](03_노드_용병소_보상_메타.md))로 전환 — 안정적 |
| **② 계승** | 오브제를 다음 런으로 가지고 감(마석처럼 리셋 예외) | 누적 시 강력하나 파워 인플레 → 마석 교환이 밸브 |

- **런 루프 리셋 예외 목록 갱신 필요**: [03 §4-1](03_노드_용병소_보상_메타.md)의 "리셋: 예비대+파티+영혼석" 항목에 "**단, 계승 선택 오브제는 유지**"를 추가한다.
- 밸런스 의도: 계승 누적으로 강해지되, 마석 교환을 택하면 즉시 메타 성장(패시브/스킬 해금)으로 환원 → **"이번 판 강화 vs 영구 성장"** 의 반복 선택지.

## 4. 밸런스 프레임 · 효과 어휘

### 4-1. 강도 기준

- 발동 빈도가 낮으므로(전투당 최대 1회, 그마저 확률적) **이벤트 1회 효과보다 다소 강해도** 됨.
- 강효과에는 **소소한 코스트/조건**을 붙여 균형(예: 스택 +5 ↔ 다음 턴 손패 −1).
- 계승 누적이 상한을 뚫지 않도록, 개별 오브제는 "전투를 뒤집는" 수준이 아니라 "한 판단을 유리하게" 수준으로.

### 4-2. 허용 효과 어휘

| 범주 | 예시 수치 |
|---|---|
| 스택 보너스 | 부착 카드 스택 +2~+5 / 크로스 스택 +1~+3 / 3종 동시 소량 |
| 성향 개입 | 부착 카드 성향 굴림 → 고정값 / 하한 보장 / 재굴림 |
| 드로우 | 카드 +1~+2 추가 드로우 |
| 스트레스 | 전원 −5~−10 / 1명 −10~−20 / 사망 시 +20 1회 무효 |
| 생존 | 최저 HP 아군 회복 +10~+20 / 실드 +10~+25 |
| 미행동 연계 | 미행동 동료에게 스택 우선권·보너스 / 미행동 수 비례 |
| 조건부 배수 | "이번 턴 첫 카드" · "부착 스택 타입 일치" 시 효과 2배 |

> 직접 데미지/즉시 힐 남발은 지양 — 오브제는 **스택·자원·리스크를 비트는** 도구이지 딜/힐 소스가 아니다(그건 동료 스킬의 몫).

### 4-3. 아키타입 매핑 원칙 ([08 §5](08_밸런스_난이도_아키타입.md))

모든 오브제는 "지원 아키타입"과 "견제/불리 아키타입 또는 리스크"를 명기한다. 특정 아키타입만 과보상하지 않도록 A~E에 고르게 분포시킨다.

- **플레이버**: *"초침이 12를 가리킬 때마다 누군가의 목숨이 걸려 있었다. 지금은 그냥, 네가 원할 때 한 번 더 째깍거릴 뿐."*
- **지원**: A 도박 / **견제·리스크**: C 미행동(미행동 동료 없으면 재굴림 상실, −5 확정 위험)

#### OBJ-03 부서진 주사위 `objet_shattered_dice`
- **효과**: 부착 카드의 성향 굴림을 2회 수행해 원하는 값 선택. 발동과 동시에 손패에서 무작위 카드 1장 버림.

- **지원**: A 도박 / **견제·리스크**: C 미행동(손패 소모로 장기전 카드 고갈 가속)

#### OBJ-04 젖은 붕대 뭉치 `objet_sodden_bandages`

- **발동조건**: 무조건 (미행동 동료 없으면 −2만 적용)

- **지원**: C 미행동 / **견제·리스크**: A 도박(즉시 스택 확보 저해, 미행동 강제)
- **마석 교환가**: 20 · **난이도**: 중

#### OBJ-05 녹슨 열쇠고리 `objet_rusty_keyring`
- **효과**: 카드 1장 추가 드로우 + 현재 스택 보유량이 가장 낮은 동료에게 스택 +2. 다음 턴 개시 시 손패 최대 −1.

- **지원**: C 미행동 · E 균형 / **견제·리스크**: A 도박(손패 −1로 도박 타이밍 선택지 제한)

## 7. 미결 / 결정 필요

- [ ] **엘리트 노드 의존성**: 획득처가 엘리트인데 엘리트 노드는 백로그(03 §1-3)이고 MVP 6층 시퀀스엔 없음. → (A) 오브제는 엘리트 노드 편입과 함께 정식 스코프로, (B) MVP 시연용으로 일반 전투 소량 확률 등 대체 획득처 임시 허용 중 택1.

- [ ] **마석 교환가 범위**(15~30 제안)와 노드 보상 마석(Combat +10/Elite +20/Boss +30, 03 §4-4)의 균형.
- [ ] 여러 오브제가 같은 전투에서 동시 발동 시 연출/로그 처리.
