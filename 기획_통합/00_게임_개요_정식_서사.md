## 1. 한 줄 요약

> **관리되는 자들의 세상에서, 당신은 살아남기 위해 앞으로 나아가야 한다.**

다크 호러 세계관의 **로그라이크 덱빌딩 오토배틀러**. 
주인공은 괴이탐사국 소속 조사관으로, 균열 지대에서 영혼석을 회수하는 루프를 반복하며 자신에게 걸린 암시와 시스템의 실체를 자각해간다.

탐험 위에, **카드로 공용 스택을 만들고 동료가 순서대로 소모해 싸우는** 덱빌딩 오토배틀러.

## 2. 장르 정체성 & 핵심 차별점

**"카드를 플레이하면 동료가 자동으로 싸운다"**

- 로그라이크 덱빌딩 + 오토배틀러 혼합 장르
- 다크 호러 세계관 기반
- 스택 시스템이 핵심 차별점: 카드 → 공용 스택 → 동료 자동 행동

| 요소 | 일반 덱빌딩 | 이 게임 |
|---|---|---|
| 카드 역할 | 직접 공격/효과 | 스택(자원) 생성 전용 |
| 전투 수행 | 플레이어 직접 | 동료 자동 행동 |
| 불확실성 | 카드 드로우 | 성향 기반 스택 수치 |
| 감정 자원 | 없음 | 스트레스 (0~100) |

### 감정 자원: 스트레스

- 단순한 디버프가 아니라 **"이 세계가 사람을 망가뜨린다"는 세계관 표현
- 전투 리스크를 높이고, 플레이어 결정을 흔드는 핵심 변수
- 스트레스 100 시 패닉 발동 → 전투 흐름 붕괴 가능성
- (상세 수치는 [01_전투_카드_스트레스 §4 스트레스](01_전투_카드_스트레스.md))

## 3. 코어루프 명세 (2026-03-15 확정)

### 전체 루프
1. 노드 선택 → 2. 동료 배치 → 3. 턴 시작 (손패 리셋) → 4. 카드 플레이 → 5. 자동 전투 → 6. 결과 처리 → 7. 노드 보상 → 8. 다음 노드

**핵심**: 전투 전 배치 → 공용 스택 생성 → 자동 행동 → 결과

```text
[노드 선택]
     ↓
[동료 배치] — 전열/후열 위치 확정, 전투 중 변경 불가
     ↓
[턴 시작] — 손패 리셋, 카드 3종류 제공
     ↓
[카드 플레이] — 딜러/탱커/서포터 스택 생성
     ↓
[공용 스택 소모] — 스택 자동 분배 → 동료 자동 행동
     ↓
[전투 결과] — 스트레스 증감/보상 처리
     ↓
[다음 노드] — 완료 시 종료
```

### 확정 규칙 (요약)

**손패**
- 매 턴 리셋, 사용 장수만큼 재드로우
- **손패 = 배치된 동료 수와 동일** (4인 배치 → 손패 4장)
- 탈진(덱 고갈) 시 번 데미지 (전원 5 데미지)

**공용 스택**
- 딜러/탱커/서포터 3종, 상한 없음, 전투 종료 시 자동 초기화
- 부족 시 동료 행동 스킵 후 미행동 보상 진행

**동료 행동**
- 전투 전 배치 순서 확정 (전투 중 변경 불가)
- **우선순위**: 배치 순서 → 미행동자 우선 재정렬
- 미행동 보상: 해당 스택 +1, 다음 턴 순서 우선
- 예시: `1-2-3-4` → 3 미행동 → 다음 턴 `3-1-2-4`
- 3,4 미행동 시 `4-3-1-2` (미행동한 순서대로 정렬)

> 전투 세부 규칙(타겟팅·사망 처리·예외 처리)은 [01_전투_카드_스트레스 §1 전투 시스템](01_전투_카드_스트레스.md) 참조.

### 재화

| 재화 | 용도 | 위치 | 비고 |
|------|------|------|------|
| 영혼석 | 모집/부활/회복 | 탐험 노드 | 현행 구현 |
| 마석 | 메타 성장(영구 패시브/스킬 해금) | 런 보상 | 현행 구현 — [03_노드_용병소_보상_메타 §4 마석](03_노드_용병소_보상_메타.md) |

## 4. 정식 버전 범위 정의 (2026-07-24 기준)

> 현재 기획·밸런스·콘텐츠 추가는 **10층 분기형 정식 버전**을 기준으로 한다.

### 핵심 구성

| 카테고리 | 정식 버전 기준 | 세부 |
|---|---|---|
| 카드 | 역할 3종 기반 | 딜러·탱커·서포터 스택 생성, 성향에 따른 수치 변동 |
| 동료 | 기본 5종 + 샤먼 확장 | 파티 최대 4명, 용병소에서 모집·교체 |
| 적 | 일반·엘리트·보스 로스터 | [02_동료_적_데이터 §7](02_동료_적_데이터.md) 수치 마스터 참조 |
| 맵 | 10층 분기 | 층마다 3개 노드 중 1개 선택 |
| 이벤트 | 용병소·교회·텍스트 이벤트·엘리트 | 노드 가중치에 따라 등장 |
| 메타 | 마석 영구 성장 | 패시브·시그니처 스킬 해금 |

> 카드의 역할별 기본 구조와 덱 자동 구성은 [01_전투_카드_스트레스](01_전투_카드_스트레스.md), 적 조합과 위협 곡선은 [08_밸런스_난이도_아키타입](08_밸런스_난이도_아키타입.md)에서 관리한다.

### 노드 구조

| 노드 | 정식 버전 역할 |
|---|---|
| 전투 | 일반·엘리트 적과의 전투, 카드·스택·자동행동 루프 진행 |
| 용병소 | 영혼석을 사용한 동료 모집·교체·파티 편집 |
| 교회 | 체력 회복·스트레스 관리·사망 동료 복구 |
| 화톳불 | 9층 고정 정비 노드, 보스 진입 전 회복 |
| 보스 | 10층 고정, 거두는 자 또는 대체 보스 루트 |
| 텍스트 이벤트 | 선택지 기반 리스크-리턴과 세계관 암시 |

### 정식 버전 진행 규칙

- 총 10층, 각 층 3개 분기 중 1개 선택.
- 1층 시작 노드, 9층 화톳불, 10층 보스 노드는 고정.
- 전투·이벤트 노드는 사전 정의 가중치로 생성하며 같은 유형의 연속 등장을 제한한다.
- 정식 버전의 전투 조합·적 편입 순서·보상은 [03_노드_용병소_보상_메타](03_노드_용병소_보상_메타.md)와 [08_밸런스_난이도_아키타입](08_밸런스_난이도_아키타입.md)을 따른다.
- 로그북·동료 개인 서사·복합 성향 시너지는 정식 버전 이후의 후속 확장으로 관리한다.

## 6. 서사 / 세계관

### 6-1. 세계관 한 줄
> 비현실이 현실이 되어버린 뒤틀린 세계에서, 당신은 살아남기 위해 앞으로 나아가야 한다.

초능력이 현실이 된 반작용으로 비현실이 침범해 뒤틀린 세계. 현실의 규칙이 무너진 **"지구 2.0"**. 괴이, 오염, 비논리적 공간, 기억과 시간의 변화가 일상화된 세계.

### 6-2. 플레이어의 위치
- 괴이탐사국 소속 조사관이자 생존자
- 균열 지대를 탐사하며 영혼석을 회수하는 현장 인력
- 영혼석을 상납하고 마석을 받아 강화한 뒤 다시 탐사하는 루프를 반복
- 이 구조를 "당연한 생존 방식"으로 받아들이도록 가스라이팅/암시된 상태

### 6-3. 메인 플롯 흐름 (생존 / 순응 / 자각 / 이탈)

```text
[전반] 루프를 당연하게 반복 — 영혼석 회수 생존 직관
     ↓
[중반] 탐사 기록과 균열의 이상 현상에서 위화감 시작
     ↓
[후반] 영혼석 회수와 탐사 시스템의 본질, 자신에게 걸린 암시를 자각
     ↓
[결말] 세계를 구하는 것이 아니라, "은퇴"라는 개인적 해방
     ↓
[포스트 엔딩] 또 다른 탐사대원이 같은 임무를 반복 — 시스템은 계속된다
```

### 6-4. 프롤로그 초안

> 우리는 언제나 미궁을 떠돈다.
> 해가 지면 밤이 찾아오고, 봄이 오면 꽃이 피듯이.
> 우리에게 미궁이란 그러한 존재였다.
>
> 나아가고, 탐사하고, 해결하면
> 불합리한 규칙 속에서도, 반복되는 괴이들 앞에서도
> 늘 내일이 찾아왔다.
>
> 그렇기에 나는 오늘도 미궁을 떠돈다.
> 내일을 찾아서가 아니라, 그것이 당연하기 때문에.
>
> 언제부터 그랬는지는, 기억나지 않는다.

### 6-5. 엔딩 초안

> "임무 완료. 영혼석 회수량: 정상.
> 다음 탐사 브리핑이 발송되었습니다."
>
> 출발 기한 : 즉시 *(강조 표시)*

## 7. 동료 구조의 서사 정합성 (✅ 2026-04-08 A안 확정)

**선택 안: A안 — 기존 시스템 유지 / 동료를 인간이 아닌 존재로 재해석**

- 동료는 던전(균열) 내에서만 동작하고, 루프 종료 시 리셋되는 기존 시스템을 **그대로 유지**한다.
- 동료는 **비인간적 전투 구현체**로 설정 — 던전에 남은 탐사자의 잔재, 다른 시간선에서 밀려온 가능성의 파편, 영혼석에 반응해 일시적으로 형체를 얻는 전투 구현체.
- 런타임 시 `AllyNameGenerator`로 이름이 자동 생성되며, 루프 종료 시 리셋에 서사적 정당성을 부여한다.
- 동료 개인 서사 누적 / 마을 복귀 후 대화 등은 [05_백로그](05_백로그.md)의 후속 확장으로 관리한다.

**핵심 질문 결론**
1. 동료는 사람인가, 구현체인가? → **구현체 (확정)**
2. 관계를 쌓는 존재여야 하는가? → 현재는 시스템 중심, 누적형 관계는 후속 확장
3. 스토리 정서 vs 시스템? → **전투·런 진행과 서사 암시를 함께 유지**
4. 마을/복귀 콘텐츠? → 백로그 이관
5. 프로토타입과 정식 방향 차이? → 베타 단계에서 재검토

> B안(누적형 생존자) / C안(절충안)은 [05_백로그](05_백로그.md)에 보존.

## 8. 오브젝트 텍스트 / 암시

> 현재는 **텍스트 중심으로** 세계관/암시/위화감을 강화한다. 로그북/분석 UI 없이도 **노드/환경 오브젝트 상호작용 → 짧은 팝업 텍스트**가 동작하며, 로그북과 분석 UI는 후속 확장으로 연결할 수 있다. 거대한 고유명사/코드네임은 직접 명명하지 않고 암시로만 남긴다. **수집 강제 아님** — 읽지 않아도 진행 가능. 텍스트는 '정답'이 아니라 **의심을 남기는 잔상**.

> 🟡 아래 오브젝트 텍스트는 **정적 배치용**이다. 노드 진입/전투/사망/패닉 등 **동적 인게임 문구**는 [07_서사_텍스트_풀](07_서사_텍스트_풀.md)(문구 마스터), 이 암시를 **선택지로 겪게 하는** 이벤트는 [06_이벤트_노드](06_이벤트_노드.md)로 확장 제안됨.

### 8-1. 환경/시설 오브젝트 텍스트 (10개 샘플)

1. **[찢어진 표지판]** "출입 금지. 현실 안정화 구역." / 덧칠: "안정화가 아니라, *가림막*이다."
2. **[뒤집힌 교실 칠판]** "영혼석 상납은 인류의 의무." / 문장 끝이 떨려 있다 — '손이 아닌 것'으로 쓴 듯.
3. **[끊긴 방송 장치]** 잡음 사이 반복: "…기억은 기록을 따른다. 기록은…"
4. **[관측소 벽면의 균열]** 벽이 '안쪽'으로 갈라져, 틈에서 **낯선 실내 공기**가 새어 나온다.
5. **[찢어진 보고서 조각]** 날짜가 두 개 — 하나는 오늘, 다른 하나는 **아직 오지 않은 내일**.
6. **[폐허가 된 휴게실]** 컵라면이 식어 있는데, 김이 난다. 아주 미세하게, 계속.
7. **[금속판에 남은 문양]** 낯익은 로고 같은데 기억이 안 난다. 볼수록 **눈을 속이는 블러**처럼.
8. **[고장난 출입 단말기]** "사용자: 조사관(당신의 이름) — 상태: *이미 종료됨*"
9. **[피난 안내도]** 출구가 지워지고, 화살표가 모두 한 곳을 가리킨다. "상납소".
10. **[현장 기록기]** 녹음 파일 제목 자동 생성: "제 1회 복귀 브리핑" — 파일이 이미 7개다.

### 8-2. 마을/탐사국 선전물 텍스트 (3개 샘플)

1. **[포스터: 의무]** "상납은 구원이 아니다. 상납은 *질서*다." / 작은 글씨: "질서에서 벗어난 자는 보호 대상이 아니다."
2. **[포스터: 보상]** "마석은 당신의 용기만큼 지급된다." / 낙서: "용기가 아니라 *순응*만큼."
3. **[안내문: 복귀 브리핑]** "복귀 후에는 반드시 브리핑을 수강하십시오." / "…기억 혼선이 아니라, *기억 교정* 같은 느낌."

### 8-3. 1막 '기시감 사건' (초기 회차 1회성 연출)
- **트리거(추천)**: 특정 노드(예: 첫 전투 후 첫 휴식/관측소)에서 1회만 발생.
- **[기시감]** 처음 들어온 방인데, 바닥에 네가 아직 흘리지 않은 피가 말라 있다.
- **[기록 불일치]** "조사관은 오늘, 여기서 망설였다. 그리고 다시 같은 선택을 했다."
