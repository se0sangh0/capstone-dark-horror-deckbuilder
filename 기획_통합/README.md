## 왜 이 폴더가 있나

기존 `기획/` 폴더(코어·시스템·서사·MVP·백로그)에 문서가 파편화되어 사람·AI 모두 일부를 놓치기 쉬웠습니다. 이를 주제별 현행 명세와 제안 초안으로 재구성했으며, 2026-08-01에 이 구조를 Notion으로 이전했습니다. 기존 `기획/` 폴더와 이 통합본은 이전 기록으로 남아 있습니다.

> ⚠️ 현재 **수치 마스터**는 Notion의 [02. 동료 · 적 · 데이터](https://app.notion.com/p/3af6aef5baac811fbd82cfda158e3760)입니다. 이 로컬 사본을 수정하지 마세요.
> **기획 우선 원칙**: 현재 구현 코드와 내용이 다르면 Notion 기획을 기준으로 삼습니다. 구현 완료 여부와 코드 차이는 [HANDOFF.md](../HANDOFF.md)에서 추적합니다.
> 시스템 기획의 문장 형식과 문서 버전 판정은 Notion의 [문서 작성·버전 관리 규칙](https://app.notion.com/p/3af6aef5baac813898bce156f2b6768f)을 따릅니다.

## 문서 상태를 읽는 법

문서 상태는 아래 다섯 축을 서로 독립적으로 판단한다. 한 축의 `확정`이 다른 축의 구현 완료나 수치 확정을 뜻하지 않는다.

| 축 | 의미 |
|---|---|
| 기획 상태 | 규칙·콘텐츠 방향의 확정 정도: 확정 / 부분 확정 / 초안 / 백로그 / 운영 |
| 현재 범위 | 현재 통합 기획에 포함되는 정도: 포함 / 일부 포함 / 미포함 |
| 구현 상태 | 기획 문서에서 판정하지 않으며 [HANDOFF.md](../HANDOFF.md)에서만 추적 |
| 수치 상태 | 확정 / 초안 / 미정. 파생 수치보다 [02](02_동료_적_데이터.md)의 마스터 값을 우선 |
| 미결 관리 | 팀 결정이 필요한 항목의 단일 목록은 [15_미결_안건표](15_미결_안건표.md) |

`정식 버전`은 10층 반복 런이라는 제품 목표를 가리키는 말이며, 그 표현만으로 기획·수치·구현이 모두 확정되었다는 뜻은 아니다.

## 정리 시 반영한 주요 사항

- **수치 일원화**: 원본의 08/09/10 문서는 이미 수치 관리를 중단하고 데이터 허브(07)를 참조하던 상태 → 02 문서로 흡수.
- **튜토리얼 현행화**: 보스 노드 제거(2026-06-13) 등을 현행 기획 기준으로 본문에 반영하고, 초기 "교전 수칙 6조" 연출안은 참고 섹션으로 보존.
- **기준 분리 명시**: 정식 10층 분기 맵과 현재 통합 기획 범위를 구분해 표기. 구현 상태는 HANDOFF에서만 추적.
- **마석 메타 성장 분리**: 반복 런에서 마석을 모아 계정 공용 스탯을 영구 강화한다. 동료·스킬·차원 테마 해금과는 분리하고 상세 항목·비용은 03·15에서 관리.

> 통합 과정에서 누락/오역이 의심되는 부분은 각 문서 상단의 **통합 출처** 경로에서 원본을 대조할 수 있습니다.
