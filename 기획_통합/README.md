## 왜 이 폴더가 있나

기존 `기획/` 폴더(코어·시스템·서사·MVP·백로그)에 문서가 파편화되어 사람·AI 모두 일부를 놓치기 쉬웠습니다. 이를 주제별 현행 명세와 제안 초안으로 재구성하고, 이후 구현 변경도 이 통합본에 반영합니다. 기존 `기획/` 폴더는 통합 전 원본으로 남아 있습니다.

> ⚠️ **수치 마스터는 [02_동료_적_데이터](02_동료_적_데이터.md)** 입니다. 동료 스탯·스킬 power·코스트 배율·적 HP 등 모든 수치는 여기서 시작해 수정하세요.

## 정리 시 반영한 주요 사항

- **수치 일원화**: 원본의 08/09/10 문서는 이미 수치 관리를 중단하고 데이터 허브(07)를 참조하던 상태 → 02 문서로 흡수.
- **튜토리얼 현행화**: 보스 노드 제거(2026-06-13) 등 최신 구현 기준을 본문으로, 초기 "교전 수칙 6조" 연출안은 참고 섹션으로 보존.
- **기준 분리 명시**: 정식 10층 분기 맵과 현재 구현 범위를 구분해 표기. 튜토리얼 고블린 HP 65 안은 현행이 아닌 초기 참고안으로 보존.
- **마석 메타 성장 반영**: 2026-06-02 재설계(로그라이크 루프 + 패시브/스킬 해금)를 03 문서에 정리.
