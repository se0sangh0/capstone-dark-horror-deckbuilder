## 1. 튜토리얼 명세 (현행 / 2026-06-13 갱신)

튜토리얼은 신규 플레이어가 전투 기본 흐름(드로우 → 카드 사용 → 스킬 자동 발동 → 적 행동 → 미행동 보상)을 한 번 경험하고 본 게임에 진입하도록 하는 가이드. 텍스트·하이라이트 기반의 가벼운 일회성 가이드로 구현하며, 복잡한 분기·연출은 본편과 분리한다.

### 1-1. 트리거 / 진입 조건

- **자동 실행(최초)**: 실행 시 `PlayerPrefs` 완료 플래그 확인 → 없거나 false면 메인 메뉴 → 튜토리얼 자동 시작. 진입 시 우측 상단 **[튜토리얼 스킵]** 상시 노출.
- **수동 재진입**: 플래그 true면 메인 메뉴 [시작하기] 옆 **[처음이신가요?]** 노출 → 클릭 시 재진입(플래그 유지).
- **PlayerPrefs 키**: `tutorial_completed` (0=미완료 / 1=완료). 완료(스킵 포함) 시 1.

### 1-2. 시나리오 구성

**파티 (고정 3인 + 빈 슬롯 1)**

| 슬롯 | 직업 | 역할 |
|---|---|---|
| 0 | 캐스터 | Dealer |
| 1 | 프리스트 | Support |
| 2 | 디펜더 | Tank |

**적 (고정)**: 고블린 1마리. 학습용으로 HP/공격력을 본 게임 기본값 그대로 쓰거나 살짝 낮춰 빠르게 종료(별도 데이터 조정 가능).

**학습 항목(피드백 단계)** — 순서대로 가이드 메시지·하이라이트:
1. **카드 드로우** — "턴이 시작되면 동료 수만큼 카드가 손패에 들어옵니다."
2. **스킬 자동 사용** — "카드는 스택에 영향을 줍니다. 동료는 자신의 역할 스택을 기반으로 발동 가능한 가장 높은 코스트 스킬을 자동으로 사용합니다."
3. **적 스킬 타격** — "적도 자신의 차례에 행동합니다. 피격 시 HP / 스트레스 변화를 확인하세요."
4. **미행동 보상** — "이번 턴에 행동하지 않은 동료는 다음 턴에 스택 +1 보상과 행동 순서 우선권을 얻습니다. 단, 먼저 피격되는 리스크도 같이 있습니다."

> 모든 피드백은 하이라이트(외곽선 강조) + 짧은 텍스트 한 줄, [확인]/[다음]으로 진행.

### 1-3. 종료 조건 (2026-06-13 — 보스 노드 제거)
- 노드 흐름: **전투(고블린) → 랜덤 노드(용병소 고정) → 화톳불**. 화톳불 **[다음 층]** 클릭 → 튜토리얼 완료 → 플래그 = 1 → 시작 화면(`GameStartScene`) 복귀.
- 또는 [튜토리얼 스킵] → 동일하게 플래그 = 1 후 시작 화면 복귀.
- (구버전) 보스 노드 전멸 종료 연출은 폐지.

### 1-4. UI
- 메인 메뉴: [시작하기] + [처음이신가요?](`tutorial_completed=1`일 때만).
- 튜토리얼 전투 화면: 기본 전투 레이아웃 + 우측 상단 [튜토리얼 스킵] 상시 + 하단/중앙 가이드 메시지 패널([다음]) + 하이라이트 오버레이.

### 1-5. 예외 처리
- **스킵**: 어느 단계서든 가능, 즉시 종료 + 플래그 저장.
- **튜토리얼 중 사망**: 일반 전투처럼 처리하되 패배 시 자동으로 처음부터 재시작(메뉴 복귀 X). [스킵]으로는 언제든 탈출.
- **데이터 충돌**: 시작 시 기존 런 데이터(파티/덱) 임시 격리, 종료 시 복원. (또는 별도 슬롯, 결과 본 게임 미반영)

### 1-6. QA 체크리스트
- [ ] 최초 실행 시 자동 진입? / 우측 상단 스킵 상시 노출? / 스킵 시 `tutorial_completed=1` 저장?
- [ ] 재실행 시 자동 진입 안 함? / 메뉴 [처음이신가요?] 노출 및 재진입 동작?
- [ ] 3인 파티(캐스터/프리스트/디펜더) + 고블린 1마리 정상 생성?
- [ ] 4단계 학습 피드백(드로우/스킬 자동/적 타격/미행동 보상) 순서대로 표시?
- [ ] 패배 시 자동 재시작/종료 흐름 정상? / 종료 후 본 게임 데이터 영향 없음?

### 2-1. 안내 문구 수정 (가장 자주) ⭐

## 3. 오프닝 연출 (세계관 각인)

> 괴이탐사국 내부는 **극도로 체계화·문서화된 무기질적 공간**(SCP 재단 톤). 요원조차 부품처럼 취급, 감정 배제·절차만 존재. 첫인상에서 "너를 사람으로 보지 않는다"를 각인. 전문 읽기 약 2분 / 스킵 약 20초. 최초 실행 시에만, 이후 [처음이신가요?]로 재진입.

**시퀀스**: S#1 기동 명령서(약 40초, 타자기 출력 + 붉은 [기밀] 도장) → S#2 동료 배치 보고서(약 30초, 인사기록카드) → S#3 작전 개시(약 10초, "작전 개시. 교전을 허가한다." → 전투 페이드 인).

**디자인 가이드**: 타자기 폰트·고정폭, 검은 바탕 + 흰/회색 + 붉은 강조, 한 글자씩 타자 출력 + 문서 간 파일 넘김 효과, 타자기/종이 소리(무음 허용), 아무 키나 누르면 즉시 스킵.

## 4. 교전 수칙 연출안 (초기 설계 자료 — 참고용)

> ⚠️ 아래는 `코어/01_튜토리얼.md`의 초기 상세 설계(괴이탐사국 "근무규칙 괴담" 6수칙 + 단일 고블린 3턴 전투)다. **현행 구현(§1, 7개 안내 문구)과 다르며**, 연출 톤·문구·밸런스 검증 흐름의 참고 자료로 보존한다.

### 4-1. 학습 목표 (우선순위)
| 우선순위 | 학습 목표 | 설계 방향 |
|---|---|---|
| ★★★ | 카드 → 스택 → 스킬 자동 발동 | 직접 체험 + 시각 강조 |
| ★★☆ | 미행동 = 전략적 선택 | "일부러 한 턴 쉬어보라" 체험 유도 |
| ★☆☆ | 스킬 사용 순서 | 툴팁 한 줄, 본 게임에서 자연 학습 |

원칙: 패러다임 전환 지점("카드 썼는데 왜 내가 공격을 안 하지?") 집중 / 체험 > 설명 / 3순위는 과감히 생략.

### 4-2. 교전 수칙 6조 (요지)
- **제1조 손패 보급**: 매 턴 배치 요원 수만큼 카드 보급. 덱 소진 시 전원 5 탈진. 덱 재보급 없음.
- **제2조 전술 카드 운용**: 카드는 공격 수단이 아니라 스택 생성. 효과는 요원 성향에 따라 매번 달라진다. 불확실성에 적응하라.
- **제3조 요원 자동 교전**: 스택 축적 시 발동 가능한 가장 높은 등급 스킬 자동 사용. 발동 가능 스킬 없으면 미행동(제5조).
- **제4조 적대 개체 대응**: 적도 행동. 피격 순서 = 배치 순서(전열부터). 방어 태세 고려.
- **제5조 행동 보류**: 미행동 요원은 다음 턴 스택 +1 + 순서 전방 재조정. 단 전방은 피격 우선순위↑.
- **특별 조항(종료)**: "오늘의 교전은 기록되지 않는다. 내일도 당신은 출동할 것이다." → 페이드 아웃 → 메인 메뉴.

### 4-3. 검증된 3턴 전투 설계 (참고 밸런스)
- **파티**: 디펜더(200, 방어 준비 cost2 전체 실드20) / 캐스터(100, 매직 미사일 cost1 단일15) / 프리스트(100, 축성 cost1 단일힐12) / 오펜더(150, 일섬 cost5 단일50). 각 1스킬, 랜덤 OFF.
- **적**: 고블린 HP **65** / ATK 10 (튜토리얼 전용 보정값 — 매직미사일 15 + 일섬 50 = 정확히 65, 3턴 내 처치 보장).
- **흐름**: 턴1(디펜더 방어 준비 발동 / 나머지 −카드로 미행동) → 턴2(미행동 보상으로 캐스터·프리스트 발동 / 디펜더·오펜더 −카드로 자연 미행동) → 턴3(오펜더 일섬으로 처치).
- **승리 보장**: 고블린 65 고정, 디펜더 maxHp200+실드로 절대 사망, 의도와 다르게 써도 고정 드로우+미행동 보상으로 복원, 전멸 직전이면 자동 재시작.
