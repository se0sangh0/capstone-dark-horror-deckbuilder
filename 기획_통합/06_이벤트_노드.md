## 1. 개요

**`?` 노드 선택지 이벤트**는 짧은 상황 텍스트 + 선택지 2~3개 + 즉시 결과로 구성되는 1회성 이벤트다.

- 역할 ①: 영혼석/스트레스/HP/동료를 코스트로 쓰는 **리스크-리턴 선택**을 전투 밖에서 제공
- 역할 ②: 00 §8 오브젝트 텍스트의 세계관 암시를 **플레이어의 선택**과 결합 (읽는 암시 → 겪는 암시)
- 역할 ③: 반복 런마다 다른 이벤트 조합을 제공해 **반복감 완화**

## 2. 발생 방식 — 확정과 미결 구분

**확정**
- 선택지 이벤트는 10층 맵에서 `?` 아이콘으로 표시되는 전용 노드에 진입했을 때 발생한다.
- 각 이벤트는 짧은 상황 텍스트, 2~3개 선택지, 즉시 결과로 구성하며 런 안에서 중복 노출하지 않는다.
- 선택지가 없는 짧은 서사 문구는 노드 완료 후 다음 노드 선택 전의 **막간 텍스트**로 표시하며, `?` 노드 콘텐츠와 섞지 않는다.
- 튜토리얼에서는 본편 선택지 이벤트를 생성하지 않는다.

**미결**
- 발생 확률, 런당 상한, 층별 가중치와 19종 중 1차 편입 범위는 미결이다.

> 종전의 `텍스트 이벤트 가중치 30`은 `?` 노드 생성 가중치의 비교용 초안으로만 본다. 수치 결정은 [15 B2~B3](15_미결_안건표.md)에서 관리한다.

## 3. 공통 규칙

1. **소프트락 방지**: 모든 이벤트에 코스트 없는 선택지(지나친다/무시한다)를 반드시 1개 포함. 자원이 0이어도 진행 가능해야 한다.
2. **자원 범위**: 영혼석 ±5~15 / 스트레스 ±5~25 / HP −10~−20 (런 경제 기준: 시작 20, 전투 보상은 처치 적의 `soulStoneReward` 합산 — [03 §3](03_노드_용병소_보상_메타.md))
3. **결과 즉시 적용** + 결과 텍스트 1줄 표시. 지연 효과는 "다음 전투 시작 시 스택 +N" 1종만 허용 (기존 스택 시스템 재사용).
4. **확률 표기**: 다크 호러 톤 유지를 위해 인게임에는 % 미표기, 선택지에 자원 아이콘 힌트만 표시. (⚠️ 팀 결정 항목 — 명시 표기가 편의성은 높음)
5. **선택지 결과에 확률이 있는 경우** 좋은 결과/나쁜 결과 텍스트를 반드시 분리 작성한다.
6. UI: 별도 일러스트 없이 **텍스트 패널 + 선택지 버튼** 골격 (튜토리얼 모달/BattleResultScreen 스타일 재사용).

### 3-1. 일본 신사 토착신 테마 이벤트 운용

일본 테마의 큰 축은 **신사에 깃든 토착신과 마을 경계**다. 요괴·귀신은 토착신과 같은 존재로 뭉뚱그리지 않고, 그 세계에 함께 사는 권속·전령·망자·잔류 기억·독립된 괴이로 사용한다.

| 레퍼런스 씨앗 | 선택 구조 예시 | 설계 의도 |
|---|---|---|
| 여우불·키츠네 | 따라간다 / 공물을 건넨다 / 불을 끈다 | 호의와 기만을 동시에 가진 거래 |
| 백귀야행 | 숨는다 / 행렬의 규칙을 따른다 / 길을 가로지른다 | 통행 금기를 지킬지 시험 |
| 원한을 남긴 유레이 | 유품을 돌려준다 / 사연을 듣는다 / 외면한다 | 망자의 부탁과 현재 자원의 충돌 |
| 츠쿠모가미 | 낡은 물건을 수리한다 / 교환한다 / 빼앗는다 | 오래 사용한 물건에 대한 태도 |
| 누리카베 등 길막이 괴이 | 우회한다 / 예를 갖춘다 / 힘으로 부순다 | 공간 규칙을 이해하는 선택 |

- 각 존재는 `금기 또는 규칙 1개 + 대가 1개 + 규칙을 지켰을 때의 호의 1개`를 가진다.
- 모든 요괴·귀신을 전투 적이나 악한 존재로 처리하지 않는다. 플레이어의 선택과 세뇌된 인식 때문에 충돌이 발생할 수 있다.
- 토착신과 직접 연결된 이벤트는 신사의 경계가 약해지는 징후나 보스의 진실을 암시해야 한다.
- 위 표는 테마 전용 이벤트의 **레퍼런스 씨앗**이며, 현행 19종에 몇 개를 추가·변형할지는 [15 B2](15_미결_안건표.md)와 [15 D6](15_미결_안건표.md)에서 결정한다.

### 3-2. 초기 농경 신앙 테마 전용 이벤트

#### 비어 있는 경작지 `evt_harvest_guardians`

> 주민이 모두 떠난 경작지. 허수아비와 경계석은 숲을 향하고 있고, 까마귀만이 성소로 이어지는 길을 지킨다.

| 선택지 | 확정 결과 | 수치 |
|---|---|---|
| 우회한다 | 전투 없이 통과 | 없음 |
| 조사한다 | 숲 방향의 경계물과 성소로 이어지는 피난 발자국을 발견. 허수아비와 까마귀가 평범한 농지 수호물로 보이는 짧은 `LEAK` 재생 | 보상·스트레스 변화 미정 |
| 제거한다 | 소형 수확 수호자 1체와 까마귀 권속 전투로 전환 | 전투 보상 미정 |

- 실제로는 허수아비·경계석·까마귀에 깃든 토착신의 권속이 피난길을 지키고 있다.
- `FILTERED`에서는 상호작용하기 전까지 비어 있는 농지로 보이며, 제거 선택 후 수확 괴이로 인식된다.
- 공통 규칙의 무비용 선택지는 `우회한다`가 담당한다.
- 이 이벤트는 공통 19종 인덱스와 분리된 최초 테마 전용 명세다. 7~8층 경작지 배경 풀에서 사용하며, 구체적인 보장 횟수와 수치는 [15 B2~B3](15_미결_안건표.md)에서 결정한다.

### 4-B. 명세

### EVT-01 식어 있는 야영지 `evt_cold_camp`

> 누군가 급히 떠난 흔적. 식은 컵라면에서, 아주 미세하게, 아직 김이 난다.

| 선택지 | 결과 |
|---|---|
| 물자를 챙긴다 | 💎 +10, 전원 🧠 +10 — *"누군가의 몫이었다. '였다'라고 믿기로 했다."* |
| 흔적을 조사한다 | 50%: 전원 🧠 −5 + 암시 텍스트 1건 — *"떠난 게 아니라, 데려가진 것이다."* / 50%: 전원 🧠 +15 — *"라면 위로 김이 멈췄다. 방금까지 누가 보고 있었다는 뜻이다."* |
| 지나친다 | 변화 없음 |

- **의도**: 가장 기본형(이득+스트레스 vs 도박 vs 무시). 첫 이벤트로 노출되기 좋은 저위험 구조.
- **서사 연계**: 00 §8-1 ⑥ 폐허가 된 휴게실. / **구현 난이도**: 하

### EVT-02 임시 상납소 `evt_field_altar`

> 피난 안내도의 화살표가 전부 이곳을 가리키고 있었다. 접수구 위에 적힌 글씨 — "상납은 질서다."

| 선택지 | 결과 |
|---|---|
| 영혼석을 바친다 (💎 −10) | 전원 🧠 −20 — *"이상하리만큼 마음이 편해졌다. 그게 제일 이상했다."* |
| 접수구를 뒤진다 | 50%: 💎 +15 — *"앞사람의 상납분이다. 장부에는 이미 '수령 완료'라고 적혀 있었다."* / 50%: 전원 🧠 +15, 랜덤 1명 ❤️ −15 — *"접수구 안쪽에서, 손이 아닌 것이 손목을 잡았다."* |
| 무시한다 | 변화 없음 |

- **의도**: 상납 시스템을 직접 체험시키는 이벤트. "상납하면 편안해진다" = 암시/가스라이팅 테마의 기계적 구현.
- **서사 연계**: 00 §8-1 ⑨ 피난 안내도, §8-2 ① 포스터: 의무. / **구현 난이도**: 하

| 빛을 받아들인다 | ① 전원 ❤️ 70% 이상: 💎 +10 — *"빛이 당신들을 비추더니 이내 만족한 듯 사라진다. 바닥에 영혼석 한 줌이 남았다."* / ② ❤️ 30% 이하 동료 있음: 해당 동료 ❤️ +20, 🧠 +10 — *"빛이 상처 속으로 스며든다. 살점이 꿈틀거리며 아문다. 회복은 끝났지만, 그 눈동자에 빛 한 점이 남았다."* / ③ 파티 3인 이하: 랜덤 1성 동료 예비대 합류, 최저 ❤️ 동료 ❤️ −10 — *"빛이 응축되며 형체를 갖춘다. 인간도 짐승도 아닌 무언가. 그 옆에 섰던 동료의 얼굴이 파리해졌다. 빛이 나눠 들어간 것이다."* |
| 밀쳐낸다 | 전원 🧠 +5 — *"빛은 한 번 깜빡이더니 소리 없이 꺼졌다. 눈을 깜빡일 때마다 각막 뒤에서 무엇이 남아 움직이는 기분이다."* |
| 지나친다 | 변화 없음 — *"빛은 여전히 가장 약한 그림자를 응시하고 있다. 아니, 그냥 빛일 뿐이다."* |

- **의도**: 유일한 **파티 상태 조건부** 이벤트 — 같은 선택이 파티 상태(HP/인원)에 따라 다른 결과가 된다. 플레이어가 자기 파티 상태를 정직하게 평가하게 강제.
- **서사 연계**: 약한 생명에 기생해 구현체로 태어나는 빛 — 동료 탄생 원리의 또 다른 단면.
- **구현 난이도**: 중 (조건 분기 ①→②→③ 우선순위 판정 필요: ②가 ①보다 우선, ③은 인원 조건 시 최우선 등 판정 순서 확정 필요)
- ⚠️ 미결: 분기 우선순위(②빈사 > ③인원 부족 > ①건강 제안) 팀 확정 필요.

### EVT-18 언덕의 보물상자 `evt_hill_chest` (✍️ 기획자 발안 2026-07-27)

> 목적지로 향하던 중, 언덕 한 구석에 커다란 보물상자가 놓여 있는 것을 발견한다. 주변에는 누군가 버리고 간 듯한 부서진 방패와 부러진 창대가 널브러져 있다 — 버려진 것치고는, 상자를 지키듯 둘러서 있다.

| 선택지 | 결과 |
|---|---|
| 상자를 열어본다 | 오브제 **「되돌아오지 않는 메아리」**([09 OBJ-16](09_오브제_유물_시스템.md)) 획득, 오염도 +1 — *"상자 안에는 언제부터 방치됐는지 모를 시체들이 뒤엉켜 있었다. 구역질을 참으며 뒤진 끝에, 당신은 그것을 꺼냈다. 시체들은 전부, 빈손이었다."* |
| 무시하고 지나간다 | 변화 없음 — *"상자는 언덕에 남았다. 뒤돌아봤을 때, 뚜껑이 조금 더 열려 있었다."* |

- **의도**: **오브제 획득 이벤트 최초 사례** — 엘리트 드롭([09 §1](09_오브제_유물_시스템.md)) 외 대체 획득처. 확정 획득 대신 '오염도'라는 확정 코스트를 지불하는 교환 구조.
- **서사 연계**: 부서진 방패·창대 = 먼저 열어본 자들의 흔적. 빈손의 시체들 = 그들이 꺼낸 것은 어디로 갔는가 하는 잔상.
- **구현 난이도**: 중 (오브제 지급 연동 + 오염도 신규 재화 — §7 미결)

### EVT-19 발신불명의 메시지 `evt_unknown_coordinates` (✍️ 기획자 발안 2026-07-27)

> 조사 노트에 정체불명의 좌표가 스스로 기록되고 있다. 좌표가 가리키는 지점은, 지금 있는 곳에서 그리 멀지 않다.

| 선택지 | 결과 |
|---|---|
| 좌표를 따라간다 | 💎 +10, 오염도 +1 — *"숲길을 헤치고 나온 당신 앞에, 동료와 똑같이 생긴 존재가 목을 매단 채 죽어 있다. 널브러진 소지품에서 영혼석을 챙겼다. 노트의 좌표는, 다음 줄을 적기 시작했다."* |
| 갈 길을 서두른다 | 변화 없음 — *"궁금증을 눌러두고 발걸음을 재촉했다. 그날 밤, 노트의 좌표는 지워져 있었다. 잉크 자국도 없이."* |

- **의도**: 소량 영혼석 vs 오염도 교환의 저난이도 선택. "누가 좌표를 보내는가"라는 의문을 다회차 떡밥으로 남긴다.
- **서사 연계**: 동료와 똑같이 생긴 존재 = **구현체 설정([00 §7])의 정면 목격** — 동료가 유일한 존재가 아니라는 가장 직접적인 암시. EVT-13(두 개의 진입 기록)과 짝을 이루는 "기록이 스스로 움직인다" 계열.
- **구현 난이도**: 하
- 🔧 검수 조정: 원안 "영혼석 +1"은 런 경제 스케일(고블린 드롭 8, 모집 30~40)과 불일치 → **+10**으로 조정. 원안 유지 원하면 팀 확정 시 되돌릴 것.

## 5. 데이터 구조 (구현 참고)

```
EventDefinition (SO)
├── string id                    // evt_cold_camp
├── string title
├── string bodyText
├── EventChoice[] choices (2~3)
│    ├── string label
│    ├── CostType costType / int costAmount     // None / SoulStone / Hp / Stress
│    ├── EventOutcome[] outcomes (1~2)
│    │    ├── int weightPercent                 // 합 100
│    │    ├── EffectType / int value / Target   // SoulStone / Stress / Hp / RecruitRandom / NextBattleStack / RerollAffinity
│    │    └── string resultText
├── int minFloor / int maxFloor                 // 발생 층 제한 (EVT-08: 5~9층 가중)
└── bool consumed                               // 런 내 1회
```
